대상 페이지: $ARGUMENTS

아래 순서를 지켜 영상 한 편의 대본을 만든다. 각 단계의 결과를 다음 단계에 넘기고, 중간에 문제가 보이면 멈추고 사용자에게 알린다.

1. researcher 에이전트로 대상 페이지를 읽고 핵심 3가지와 출처를 정리한다.
2. scriptwriter 에이전트에게 그 정리만 넘겨 장면표를 쓰게 한다. 장면표 작성 기준은 make-short 스킬을 따른다.
3. reviewer 에이전트로 장면표를 대상 페이지와 비교해 원본에 없는 말을 찾는다.
4. 검토 결과를 목록으로 사용자에게 보여 주고, 고칠 곳은 사용자의 결정을 받은 뒤 고친다.
