disable-model-invocation: true
argument-hint: [페이지 경로]

대상 페이지: $ARGUMENTS

1. 페이지에서 한 가지 생각과 끝에 남길 행동 하나를 고른다.
2. 장면표를 쓴다. 장면마다 원본 페이지의 근거 위치를 적는다.
3. 원본에 없는 말은 넣지 않는다. 지어낸 숫자는 화면에 "예시"라고 쓴다.
4. 한 화면의 글은 35자 이하. 첫 5초 안에 무엇을 알게 되는지 보여 준다.
