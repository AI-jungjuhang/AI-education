---
name: make-short
description: Use when turning one book page into a vertical short video scene list under 60 seconds.
disable-model-invocation: true
argument-hint: [page path]
---

Target page: $ARGUMENTS

1. Pick one idea from the page and one action for viewers to take away.
2. Write a scene list. For each scene, note where in the original page it comes from.
3. Don't add anything that isn't in the page. Label any made-up numbers on screen as "example."
4. Keep on-screen text short. Show what viewers will learn within the first 5 seconds.
5. Don't add an ending scene or a preview of the next episode.
