    Glossary¶

    AppendixFor looking things up2026-11-09

    Words from this book, in A to Z order. Each meaning is a plain version of how this book explains it. The page on the right has the full story. ★ marks deeper topics.

    Word Plain meaning In this book
    Agent An AI that picks its own steps, uses tools, looks at results, and keeps working Ch. 14 What is an agent?
    Alignment Getting AI to act the way people really want Ch. 20 Alignment
    Attention The part that lets each token decide "where should I look?" and pull in that information Ch. 11 Attention
    Autoregressive generation ★ Picking one token, adding it to the input, and picking the next, over and over Ch. 1 Next word, Ch. 12 Long answers
    Benchmark A shared test for comparing AI models with the same questions Ch. 21 Benchmark traps
    Benchmark leakage (contamination) ★ Test questions slipping into the training data, which inflates scores Ch. 21 Benchmark traps
    Chain of thought Having the model write out in-between steps before it answers Ch. 20 Reasoning models
    Circuit ★ A path where features link up to do one calculation Ch. 19 Circuits
    CLAUDE.md A file of notes and rules that Claude Code reads at the start of every chat Ch. 16 CLAUDE.md
    Compaction Swapping a long chat for a summary so work can go on Ch. 23 Saving memory space
    Constitutional AI, RLAIF ★ AI judging AI using a list of principles people wrote, so it learns from that Ch. 20 Alignment
    Context rot ★ Accuracy and recall dropping as the input gets longer Ch. 11 Context window
    Context window How much text a chatbot can see at once, counted in tokens. The chatbot's desk Ch. 11 Context window, Ch. 23 What fills it
    Effort level The dial for how long Claude thinks before it answers Ch. 23 Effort level
    Embedding Turning a token into a list of numbers (a point on a map) Ch. 10 Tokens to numbers
    Emergent abilities ★ Abilities said to appear in big models but not small ones. Some argue it's a side effect of how they're measured Ch. 20 Scaling
    Feature ★ A pattern inside a model that tends to light up together and matches an idea people understand Ch. 19 Features
    Few-shot ★ Showing a few examples so the AI copies the shape you want Ch. 2 Role, format, examples
    Fine-tuning Training a pretrained model further, for example on answers people wrote Ch. 9 Learning from people
    Gradient descent ★ Learning by nudging the numbers inside a model a little, based on how wrong it was Ch. 9 Pretraining
    Hallucination Making up something that sounds right and saying it with confidence Ch. 1 Hallucination, Ch. 21 Measuring it
    Head (attention head) ★ One of several attention processes running side by side Ch. 11 Attention
    Held-out test ★ Test questions you don't look at while fixing, saved for the final check Ch. 15 Evaluate
    Hook A script Claude Code runs automatically at set moments, like after every file edit Ch. 17 Hook basics
    Interpretability ★ Research that tries to look inside a model, like a microscope Ch. 19 Why look inside?
    Jailbreak Trying to get an AI to break the rules it was given Ch. 14 Failures and safeguards
    Logits ★ The raw scores, before they're turned into chances Ch. 12 Temperature
    Masking Stopping later tokens from affecting earlier ones Ch. 11 Attention
    MCP (Model Context Protocol) A shared standard for connecting AI to outside tools and data Ch. 13 MCP, Ch. 17 MCP
    Multimodal ★ Handling images and sound, not just text Ch. 4 Kinds of AI
    Parameters The numbers (dials) inside a model that change as it learns. The "70B" in a model's name is how many Ch. 9 Parameters
    Plugin A folder that bundles skills, helpers, hooks, and MCP so you can install and share them Ch. 18 Plugins
    Pretraining The first stage, where a model learns by guessing the next token across huge amounts of text Ch. 9 Pretraining
    Prompt What you give an AI: your question and instructions Ch. 2 Give context
    Prompt injection ★ Hidden instructions in pasted or fetched text that the chatbot ends up following Ch. 2 Templates, Ch. 14 Failures and safeguards
    RAG (retrieval-augmented generation) Finding related text first and having the AI answer while looking at it Ch. 13 Search
    Reasoning model A model trained to think for longer before answering Ch. 20 Reasoning models
    Reinforcement learning Teaching by rewarding good actions so they happen more Ch. 9 Learning from people, Ch. 20 Reasoning models
    RLHF ★ Reinforcement learning from human feedback Ch. 9 Learning from people
    Sampling How the next token is picked from the score sheet Ch. 12 Sampling
    Sandbox A walled-off test space where mistakes can't cause harm outside Ch. 13 Running code, Ch. 14 Failures and safeguards
    Scaling laws Findings that models improve in a steady pattern as model size, data, and computing grow Ch. 9 Parameters, Ch. 20 Scaling
    Score sheet The chance given to each possible next word, for how well it fits Ch. 1 Next word
    Skill A folder of instructions Claude loads when a matching job comes up Ch. 17 Skill anatomy
    Softmax The math that turns scores into chances that add up to 1 Ch. 11 Attention, Ch. 12 Temperature
    Subagent A helper with its own context window that Claude can hand a job to Ch. 17 Subagents
    Sycophancy Giving answers that match what the user thinks rather than the facts Ch. 3 Second opinion
    Temperature How much picking from the score sheet favors the top choices Ch. 12 Temperature
    Token A piece of text the chatbot reads. Not always a letter or a word Ch. 1 Tokens
    Transformer A model design where attention blocks and MLP blocks take turns, many times over Ch. 11 One transformer layer
    Vector Several numbers grouped in one row. The point that stands for a token's meaning Ch. 10 Tokens to numbers
    Workflow An AI job where the order of steps is set in advance Ch. 14 What is an agent?
