# 도구를 연결하는 표준: MCP

<p class="ep-meta"><span>13장 · 13.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - **MCP(Model Context Protocol)**는 AI 애플리케이션을 외부 시스템(파일, 데이터베이스, 도구)에 연결하는 ==공통 규격==이다.
    - USB-C 포트처럼 한 규격으로 여러 기기를 연결하는 것과 같다.
    - 연결은 곧 **권한을 주는 일**이라서, 어디까지 허용할지 정하는 일이 중요하다.

## 1. USB-C 포트

예전에는 휴대폰마다 충전기 모양이 달라서 여행 갈 때 충전기를 여러 개 가져가야 했어요. USB-C라는 공통 규격이 생기면서 하나로 해결됐죠.

AI도 비슷한 문제가 있었어요. 챗봇이 캘린더, 메모 앱, 데이터베이스에 연결하려면 서비스마다 따로 연결 방법을 만들어야 했어요. **MCP는 이 연결에 공통 규격을 주려는 시도예요.**

!!! tip "10살 눈높이 한 줄 요약"
    MCP는 AI의 **USB-C 포트**예요. 한 규격으로 여러 도구를 꽂을 수 있어요.

## 2. MCP 공식 문서가 말하는 것

MCP 공식 문서는 이렇게 소개해요. MCP는 **AI 애플리케이션을 외부 시스템에 연결하는 오픈소스 표준**이에요. 이걸 쓰면 Claude나 ChatGPT 같은 AI 애플리케이션이

- **데이터 소스**(내 컴퓨터의 파일, 데이터베이스),
- **도구**(검색 엔진, 계산기),
- **작업 흐름**(특수한 프롬프트)

에 연결해서 중요한 정보에 접근하고 일을 할 수 있어요. 문서는 MCP를 "AI 애플리케이션을 위한 USB-C 포트"에 비유해요.

문서가 드는 활용 예는 이래요. 에이전트가 구글 캘린더와 노션에 접근해서 더 개인화된 비서가 되기, Claude Code가 Figma 디자인으로 웹 앱 만들기, 기업 챗봇이 여러 데이터베이스에 연결해서 대화로 분석하기, AI가 Blender에서 3D 디자인을 만들고 3D 프린터로 출력하기 등이에요.

## 3. 누구에게 좋은 점이 있을까

| 누구 | 좋은 점 (문서의 설명) |
|---|---|
| 개발자 | AI 앱이나 에이전트를 만들 때 연결 개발 시간과 복잡성이 줄어요 |
| AI 앱·에이전트 | 데이터와 도구, 앱의 생태계에 접근해서 능력이 늘어요 |
| 일반 사용자 | 필요하면 내 데이터에 접근하고 내 대신 행동하는 더 유능한 AI를 쓸 수 있어요 |

문서에 따르면 MCP는 Claude, ChatGPT, Visual Studio Code, Cursor 등 여러 클라이언트와 서버에서 지원돼요.

## 4. 연결은 권한을 주는 일

도구를 연결하면 챗봇이 **내 데이터를 읽거나 내 대신 행동**할 수 있게 돼요. 편리한 만큼 위험도 커져요.

- **읽기와 쓰기를 구분하세요.** 캘린더를 보기만 할지, 일정을 만들거나 지울 수도 있게 할지가 달라요.
- **필요한 만큼만 허용하세요.** "모든 파일" 대신 "이 폴더 하나"처럼요.
- **믿을 수 있는 곳의 연결만 쓰세요.** 누가 만든 연결인지 모르면 쓰지 마세요.
- **승인 요청을 읽으세요.** 챗봇이 "이 작업을 해도 될까요?"라고 물으면 내용을 읽고 승인하세요.
- **되돌릴 수 없는 일은 사람이 직접 하세요.** 삭제, 결제, 외부 발송 같은 일이에요.

!!! note "★ 한 걸음 더 (심화)"
    - MCP 문서에는 **보안(Security)** 항목이 따로 있어요. 외부 연결은 프롬프트 인젝션(2장)의 통로가 될 수 있어요. 연결된 도구가 가져온 글에 숨은 지시가 들어 있을 수 있기 때문이에요. 이 책에서는 보안 문서의 내용까지 확인하지 못했어요.
    - 문서는 "로컬(내 컴퓨터) MCP 서버"와 "원격 MCP 서버"에 연결하는 방법을 나누어 설명해요. 내 컴퓨터의 서버는 내 파일에 닿고, 원격 서버는 외부 서비스에 닿아요. 위험의 종류가 달라요.
    - 표준이 있다는 것은 도구를 바꿔 끼우기 쉽다는 뜻이기도 해요. 어떤 AI를 쓰든 같은 연결을 재사용할 수 있어요.

## 직접 해보기

내가 쓰는 AI 서비스에 "연결", "커넥터", "앱", "확장" 같은 메뉴가 있는지 찾아보세요.

1. 어떤 연결을 제공하나요? (캘린더, 파일 저장소, 메모 등)
2. 연결할 때 어떤 권한을 요구하나요? (읽기만? 쓰기도?)
3. 연결을 끊는 방법은 어디에 있나요?

실제로 연결하지 않아도 돼요. 연결 화면의 권한 설명을 읽어 보는 것만으로 충분한 연습이에요.

## 오늘 바로 써먹기

1. **연결 전에 권한 목록을 읽으세요.** 읽기만으로 충분한지 따져 보세요.
2. **작은 범위부터 시작하세요.** 폴더 하나, 캘린더 하나로 시험해 보세요.
3. **쓰지 않는 연결은 끊으세요.** 권한은 쓰지 않을 때도 열려 있어요.
4. **중요한 계정은 따로 두세요.** 회사 계정이나 결제 관련 연결은 신중하게요.
5. **승인 창을 습관적으로 누르지 마세요.** 작업 내용이 내가 원한 것인지 확인하세요.

## 자주 하는 오해

- "MCP는 AI 모델의 이름이다" → 모델이 아니라 연결 규격이에요.
- "표준이니 안전하다" → 규격이 있다고 연결된 내용과 서버가 안전한 건 아니에요.
- "연결하면 챗봇이 알아서 다 해 준다" → 어떤 일을 어떻게 하는지는 연결된 도구와 내 승인에 달려 있어요.
