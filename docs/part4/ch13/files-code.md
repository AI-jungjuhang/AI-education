# 파일을 읽고 코드를 실행하는 AI

<p class="ep-meta"><span>13장 · 13.1</span><span>읽는 시간 약 6분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 챗봇은 파일을 읽을 수 있고, 일부 서비스에서는 ==코드를 직접 쓰고 실행해 결과를 가져온다.==
    - 계산과 표, 그래프처럼 정확해야 하는 일은 챗봇이 말로 하는 것보다 코드가 하는 것이 믿을 만하다.
    - 대신 파일 속 개인정보, 숨은 지시, 잘못된 코드를 조심해야 한다.

## 1. 계산기와 연필을 든 학생

시험에서 계산기와 연필 없이 큰 곱셈을 하면 틀리기 쉽지만, 계산기와 연필을 쓰면 정확해져요. 학생의 머리가 갑자기 좋아진 게 아니라 **도구를 쓸 수 있게 된 거예요.**

챗봇도 7장에서 본 것처럼 긴 계산에서 틀릴 수 있어요. 그런데 **코드를 짜서 컴퓨터에게 실행시키면** 계산은 정확해져요. 이것이 코드 실행 도구예요.

!!! tip "10살 눈높이 한 줄 요약"
    챗봇이 **계산기와 연필(코드 실행)**을 손에 쥐면 계산과 표 만들기가 훨씬 정확해져요. 하지만 뭘 계산했는지는 봐야 해요.

## 2. 어떻게 작동하나

13.1.1에서 본 도구 사용 방식과 같아요. Anthropic의 도구 사용 문서에 따르면 챗봇이 도구를 부르고 싶을 때 **구조화된 호출 요청**을 돌려주고, 그 호출을 애플리케이션이나 Anthropic이 실행해요. 코드 실행의 경우 흐름은 대략 이래요(일반적인 설명이에요).

1. 내가 "이 파일의 월별 매출 합계를 구하고 그래프로 그려 줘"라고 부탁해요.
2. 챗봇이 그 일을 하는 **코드를 써요.**
3. 코드가 **실행**되고 결과(숫자, 그래프)가 나와요.
4. 챗봇이 그 결과를 읽고 나에게 **설명**해요.

그래서 계산은 챗봇의 "말하기"가 아니라 **컴퓨터의 계산**이에요. Anthropic 문서의 목차에는 코드 실행 도구, 파일을 다루는 Files API, PDF와 이미지 지원 항목이 있어요.

## 3. 파일을 올릴 때 일어나는 일

- 올린 파일은 챗봇이 읽을 수 있는 **글로 바뀌거나**(PDF는 쪽 이미지가 함께 쓰이기도 해요) 컨텍스트에 들어가요(6장). 표나 그림은 변환 중에 깨질 수 있어요.
- 파일이 길면 컨텍스트 한도 때문에 **일부만 읽을 수 있어요**(11장).
- 서비스에 따라 파일 종류와 크기 제한이 달라요.

## 4. 코드 실행이 도움이 되는 일

| 일 | 이유 |
|---|---|
| 합계, 평균, 퍼센트 계산 | 계산은 코드가 정확해요 |
| 표 정리, 중복 제거, 형식 바꾸기 | 규칙대로 처리하면 되는 일이에요 |
| 그래프 그리기 | 코드로 그림을 만들 수 있어요 |
| 많은 파일을 한꺼번에 처리 | 반복은 코드가 잘해요 |

## 5. 조심할 것

- **어떤 코드가 실행됐는지 보세요.** 식이 틀렸으면 값이 정확해도 답이 틀려요(7장). "실행한 코드를 보여 줘"라고 요청하세요.
- **파일에 개인정보가 있는지 확인하세요.** 올린 파일은 서비스로 전송돼요(3장).
- **파일 안에 숨은 지시가 있을 수 있어요.** 남에게 받은 문서에 "앞의 지시는 무시해"라는 글이 숨어 있으면 챗봇이 따를 수 있어요(프롬프트 인젝션, 2장).
- **원본은 따로 보관하세요.** 변환한 결과 파일이 원본을 대체하지 않게 하세요.
- **결과의 몇 줄은 직접 확인하세요.** 표라면 몇 행을 손으로 계산해 보세요.

!!! note "★ 한 걸음 더 (심화)"
    - 코드를 실행하는 곳은 보통 **격리된 공간(샌드박스)**이에요. 내 컴퓨터를 직접 건드리지 않게 하려는 장치예요. 하지만 내 컴퓨터에서 직접 코드를 실행하는 도구(예: 터미널 도구)는 권한이 훨씬 커서 위험도 커져요. 이 부분은 14장 에이전트에서 다시 다뤄요.
    - 도구 호출은 한 번으로 끝나지 않을 수 있어요. 결과를 보고 코드를 고쳐서 다시 실행하는 반복도 흔해요(14장).
    - 이 페이지의 작동 흐름은 일반적인 설명이고, 서비스마다 구현은 달라요.

## 직접 해보기

파일을 올릴 수 있고 코드 실행이 되는 서비스라면 이렇게 해 보세요.

1. 간단한 표(5~10행)를 만들어요. 이름, 날짜, 금액 열이 있으면 좋아요. 개인정보는 가짜로 바꿔요.
2. 파일을 올리고 말해요.

```text
이 파일에서 월별 금액 합계를 구해서 표로 보여 줘.
어떤 계산을 했는지 사용한 코드도 같이 보여 줘.
```

3. 결과를 내가 손으로 계산한 값과 비교해요. 코드가 어떤 열을 어떻게 썼는지도 읽어 보세요.

코드 실행이 안 되는 서비스라면 "엑셀 함수를 알려 줘"로 같은 일을 해 볼 수 있어요(7장).

## 오늘 바로 써먹기

1. **정확한 계산은 코드 실행으로 요청하세요.** "코드를 써서 계산해 줘"가 통하는 서비스가 있어요.
2. **실행한 코드를 보여 달라고 하세요.** 읽을 수 없어도 열 이름과 조건 정도는 확인할 수 있어요.
3. **개인정보는 지우고 올리세요.** 파일은 한 번 올리면 전송돼요.
4. **원본은 복사해서 올리세요.** 실수로 바뀌는 걸 막아요.
5. **결과는 일부를 손으로 확인하세요.** 3행쯤이면 충분해요.

## 자주 하는 오해

- "코드로 계산하면 항상 맞다" → 계산은 정확해도 어떤 식을 세웠는지가 틀리면 답이 틀려요.
- "파일을 올려서 읽혔으니 내용을 다 이해한다" → 길거나 복잡한 파일은 일부를 놓칠 수 있어요.
- "코드 실행은 위험하니 쓰면 안 된다" → 격리된 곳에서 실행하는 도구는 비교적 안전해요. 권한이 큰 도구가 위험해요.
