# 질문 모음

책에서 만든 질문 틀을 상황별로 모았어요. 칸을 채워서 쓰고, 잘 되면 8장처럼 이름을 붙여 저장하세요. **예시는 시작점이에요.** 내 일에 맞게 고치고, 결과는 3장의 방법으로 확인하세요.

!!! warning "먼저 기억하세요"
    - 개인정보, 비밀번호, 회사 기밀은 넣지 마세요([3장](../part1/ch03/privacy.md)).
    - 틀은 결과를 대신 확인해 주지 않아요. 숫자, 이름, 인용은 직접 대조하세요([3장](../part1/ch03/check-numbers.md)).

## 기본기

**맥락을 주는 질문** ([2장](../part1/ch02/context.md))
```text
[무엇을] 해 줘. 읽는 사람은 [누구]야. [어디에 쓸지]에 쓸 거야.
조건은 [길이, 말투, 빼야 할 것]이고, 이유는 [왜]야.
참고할 자료는 아래에 붙였어.
```

**모르면 모른다고 하게** ([1장](../part1/ch01/hallucination.md))
```text
모르거나 확실하지 않으면 "모르겠어요"라고 말해 줘.
추측이면 앞에 "추측:"이라고 표시해 줘.
```

**빈칸은 먼저 물어보게** ([2장](../part1/ch02/specific.md))
```text
작업을 시작하기 전에, 내가 알려 주지 않았지만 꼭 필요한 정보가 있으면
먼저 질문해 줘. 질문은 최대 3개까지만 해 줘.
```

**단계별로 시키기** ([2장](../part1/ch02/specific.md))
```text
아래 일을 단계별로 진행해 줘.
1. [첫 번째 단계]
2. [두 번째 단계]
3. [세 번째 단계]
```

**기본 질문 틀** ([2장](../part1/ch02/templates.md))
```text
[역할] 너는 ___야.
[목적] 이 결과는 ___에 쓸 거야.
[읽는 사람] 읽는 사람은 ___야.
[조건] ___로, ___ 이내로, ___는 빼 줘. 이유는 ___야.
[형식] 결과는 ___ 모양으로 써 줘.
[자료] 아래 자료만 바탕으로 해 줘. 모르면 "모르겠어요"라고 말해 줘.
<자료>
(여기에 붙여 넣기)
</자료>
```

## 고치기와 다듬기

**고쳐 달라고 말하기** ([2장](../part1/ch02/iterate.md))
```text
[어디]를 [어떻게] 바꿔 줘. [이유]야. [그대로 둘 것]은 유지해 줘.
```

**내용은 그대로 고쳐 쓰기** ([5장](../part2/ch05/rewrite.md))
```text
의미는 바꾸지 말고, 원문에 없는 사실이나 숫자는 추가하지 마.
바꾼 부분은 [원문 → 수정] 형태로 목록으로 알려 줘.
```

**새 대화로 옮기기 위한 정리** ([2장](../part1/ch02/fresh-start.md))
```text
지금까지 대화에서 정해진 것을 정리해 줘.
- 목적:
- 읽는 사람:
- 꼭 지켜야 할 조건:
- 지금까지 마음에 든 부분:
- 마음에 안 든 부분과 그 이유:
새 대화에서 그대로 붙여 넣어 쓸 수 있게 간결하게 써 줘.
```

## 쓰기와 정리

**개요 먼저 받기** ([5장](../part2/ch05/first-draft.md), [12장](../part3/ch12/long-answer.md))
```text
[목적]에 쓸 글이야. 요점은 1) ___ 2) ___ 3) ___ 이야. 독자는 ___야.
먼저 3문단 이내 개요를 제안해 줘. 글은 아직 쓰지 마.
```

**요약** ([5장](../part2/ch05/summarize.md))
```text
아래 글을 [읽는 사람]을 위해 요약해 줘.
조건: [개수]문장 이내, 숫자와 날짜는 그대로 남기기.
원문에 없는 내용은 추가하지 말고, 원문이 불확실하게 말한 부분은 불확실하다고 써 줘.
<글>(붙여 넣기)</글>
```

**회의록** ([7장](../part2/ch07/meeting-notes.md))
```text
아래 회의 메모를 정리해 줘.
형식: 1) 결정된 것 2) 아직 안 정해진 것 3) 할 일 표(할 일 / 담당자 / 기한)
규칙: 메모에 없는 담당자나 기한은 만들지 말고 "미정"이라고 써 줘.
숫자와 날짜는 바꾸지 마. 해석이 필요한 부분은 "확인 필요"로 표시해 줘.
<메모>(붙여 넣기)</메모>
```

**두 대상 비교** ([2장](../part1/ch02/templates.md))
```text
[A]와 [B]를 [기준 3가지]로 비교해 줘. 표로 만들고,
마지막에 [내 상황]이라면 어느 쪽이 나을지 이유와 함께 한 줄로 알려 줘.
모르거나 확실하지 않은 칸에는 "확인 필요"라고 써 줘.
```

**표 계산 프로그램 함수 질문** ([7장](../part2/ch07/tables.md))
```text
[엑셀/구글 시트]를 쓰고 있어.
A열: ___, B열: ___, C열: ___
예) (실제 데이터 모양 한두 줄, 개인정보는 가짜로)
[어느 칸]에 [원하는 결과]를 구하고 싶어.
함수 하나를 알려 주고, 각 부분이 무슨 뜻인지 한 줄씩 설명해 줘.
```

## 조사와 공부

**낯선 분야 파악** ([6장](../part2/ch06/quick-intro.md))
```text
나는 [분야]를 처음 접하는 [직업/학년]이야. 다음 순서로 알려 줘.
1) 초등학생도 이해할 한 단락 설명
2) 가장 자주 나오는 용어 10개와 한 줄 설명
3) 하위 분야들의 지도 (표 또는 목록)
4) 입문자가 자주 하는 오해 3가지와 전문가들 사이에서 의견이 갈리는 쟁점
5) 더 공부할 때 던질 질문 5개
확실하지 않은 내용은 "확실하지 않음"이라고 표시해 줘.
```

**긴 자료에서 근거 먼저 뽑기** ([6장](../part2/ch06/long-docs.md))
```text
<자료>(보고서 전문)</자료>

위 자료를 읽고 다음 질문에 답해 줘. 질문: [질문]
1) 먼저 질문과 관련된 문장을 자료에서 그대로 인용해 번호를 붙여 줘.
2) 그 인용문 번호만 근거로 답을 정리해 줘.
인용문으로 뒷받침할 수 없는 내용은 쓰지 말고 "자료에 없음"이라고 말해 줘.
```

**공부 도우미: 설명 후 바로 시험** ([6장](../part2/ch06/tutor.md))
```text
[주제]를 초등학교 6학년이 이해할 수 있게 설명해 줘.
설명이 끝나면 바로 내가 이해했는지 확인하는 질문 3개를 내 줘.
정답은 내가 대답한 다음에 알려 줘.
```

**내 설명 점검받기** ([6장](../part2/ch06/tutor.md))
```text
내가 [주제]를 이렇게 이해했어. 틀리거나 빠진 부분을 알려 줘.
<내 설명>(내가 이해한 대로 적은 글)</내 설명>
```

## 확인과 검증

**근거 인용 달기** ([3장](../part1/ch03/check-sources.md))
```text
아래 자료만 바탕으로 답해 줘. 각 주장 뒤에 자료에서 그대로 가져온 문장을
따옴표로 붙여 줘. 자료에서 근거를 찾지 못한 내용은 쓰지 말고
"자료에 없음"이라고 적어 줘.
<자료>(붙여 넣기)</자료>
```

**스스로 점검시키기** ([3장](../part1/ch03/second-opinion.md))
```text
아래 답에서 사실이 틀렸거나 근거가 약한 부분을 찾아서 목록으로 만들어 줘.
확신이 없는 부분은 "확인 필요"라고 표시해 줘.
<답>(이전 답 붙여 넣기)</답>
```

**맞장구를 줄이는 질문** ([3장](../part1/ch03/second-opinion.md))
```text
[주장]에 대해 맞다는 근거와 틀리다는 근거를 각각 3개씩 써 줘.
마지막에 어느 쪽이 더 설득력 있는지 이유와 함께 말해 줘.
```

**계산은 식만** ([7장](../part2/ch07/math-caution.md))
```text
이 문제를 푸는 데 필요한 계산 과정을 식으로 단계별로 써 줘.
각 식에 들어가는 값이 무엇인지 설명해 줘. 계산은 내가 계산기로 할 거야.
```

## 에이전트에게 맡길 때

**계획 먼저 보여 달라고** ([14장](../part4/ch14/loop.md))
```text
목표: [목표]
다음 순서로 진행하고 각 단계가 끝나면 나에게 보여 줘.
1) [첫 단계]
2) 내가 하나를 고르면 [다음 단계]
3) 내가 괜찮다고 하면 [마지막 단계]
5번 시도해도 안 되면 멈추고 알려 줘.
```

**에이전트 안내서(지시문) 틀** ([15장](../part4/ch15/instructions.md))
```text
너는 [역할]이야.
목표: [무엇을 이루는 일인지, 왜 중요한지]
도구: [어떤 도구를 언제 쓰는지]. 도구로 찾을 수 없는 내용은 말하지 마.
하지 말 것: [금지 사항]. 대신 [이렇게 해].
순서: 1) [ ] 2) [ ] 3) [ ]
모를 때: "[ ]"라고 말하고 [누구에게 안내].
멈추는 조건: [횟수, 시간, 금액 한도].
```
