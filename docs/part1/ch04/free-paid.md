# 무료와 유료는 뭐가 다를까

<p class="ep-meta"><span>4장 · 4.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 무료와 유료는 보통 ==사용량, 쓸 수 있는 모델, 기능, 데이터 설정==이 다르다.
    - 내가 하는 일에 그 차이가 필요한지 따져 보고 결정한다.
    - 가격과 기능은 자주 바뀌므로, 결정할 때마다 서비스의 안내 페이지를 직접 확인한다.

!!! warning "알려 드려요"
    이 페이지에는 가격이나 구체적인 요금제 이름을 적지 않았어요. 서비스의 요금제는 자주 바뀌어서 책에 적는 순간 틀릴 수 있기 때문이에요. 바뀌지 않는 **비교 기준**을 알려 드려요.

## 1. 놀이공원 자유이용권

놀이공원에서 입장권만 사면 몇 가지만 탈 수 있고, 자유이용권을 사면 줄을 덜 서고 더 많이 탈 수 있어요. 어떤 건 자유이용권이 있어도 따로 돈을 내야 하고요.

챗봇도 비슷해요. 무료로도 충분히 쓸 수 있지만, 많이 쓰거나 더 어려운 일을 하려면 유료가 도움이 될 수 있어요. 유료라고 항상 더 정확한 건 아니고, **환각과 한계는 유료에도 남아 있어요.**

!!! tip "10살 눈높이 한 줄 요약"
    무료와 유료의 차이는 **얼마나 많이, 얼마나 큰 일을 할 수 있는지**예요. 내 일에 필요한지부터 따져요.

## 2. 비교할 다섯 가지

| 기준 | 물어볼 것 |
|---|---|
| 사용량 | 하루나 일정 시간에 몇 번까지 쓸 수 있나? 한도에 걸리면 어떻게 되나? |
| 모델 | 더 크고 똑똑한 모델을 쓸 수 있나? 속도는 어떤가? |
| 기능 | 검색, 파일 올리기, 이미지, 음성, 긴 글 처리가 되나? |
| 데이터 설정 | 내 대화가 학습에 쓰이는지 끌 수 있나? 회사 계정이면 관리자가 볼 수 있나? |
| 안정성 | 사람이 몰릴 때 느려지거나 막히나? 고객 지원이 있나? |

## 3. 유료가 필요한 때, 필요 없는 때

**유료를 생각해 볼 만한 때**
- 매일 많이 써서 무료 한도에 자주 걸려요.
- 긴 문서를 자주 올려서 분석하는 등 무료 한도로는 부족한 작업이 필요해요.
- 일이 걸려 있어서 속도와 안정성이 중요해요.
- 회사 일에 쓰는데 데이터 보호 설정이 필요해요.

**무료로 충분한 때**
- 가끔 질문하거나 글을 다듬는 정도예요.
- 쓰는 방법을 아직 배우는 중이에요. (질문 요령이 더 큰 차이를 만드는 경우가 많아요.)
- 결과를 어차피 직접 확인해서 쓰는 일이에요.

## 4. 결정하는 방법

1. **먼저 무료로 일주일 써 보세요.** 어떤 일에 한도에 걸리는지 기록하세요.
2. **막힌 일이 있는지 보세요.** 한도 때문에 못 한 일이 일에 도움이 되는 일인가요?
3. **유료는 한 달씩 시험해 보세요.** 정기 결제는 해지 방법도 미리 확인하세요.
4. **효과를 확인하세요.** 같은 일을 무료와 유료로 시켜 결과를 비교하세요.

!!! note "★ 한 걸음 더 (심화)"
    - Anthropic 문서는 모델을 고를 때 **능력, 속도, 비용의 균형**을 보라고 안내하고, 골랐다면 실제로 시험해 보라고 말해요. 개발자용 문서지만 일반 사용자에게도 같은 생각이 적용돼요. 가장 큰 모델이 항상 최선은 아니에요. 간단한 일은 작고 빠른 모델이 더 알맞을 수 있어요.
    - 서비스 안에서 모델을 직접 고를 수 있는 경우가 있어요. 쉬운 질문은 작은 모델, 어려운 추론은 큰 모델처럼 나눠 쓰는 방법도 있어요.
    - 개발자가 API로 쓰는 경우에는 요금이 토큰 수 기준인 경우가 많아요. 1장에서 본 토큰이 여기서 돈과 연결돼요.

## 직접 해보기

한 주 동안 쓰기 기록을 해 보세요.

| 날짜 | 시킨 일 | 한도에 걸렸나? | 결과가 만족스러웠나? |
|---|---|---|---|
| | | | |

일주일 뒤에 "한도에 걸렸고 그 일이 중요했던 날"이 몇 번인지 세어 보세요. 그 횟수가 유료를 생각해 볼 이유예요.

## 오늘 바로 써먹기

1. **유료 결정은 기록을 보고 하세요.** 느낌으로 결정하면 안 쓰는 구독이 쌓여요.
2. **같은 질문으로 비교하세요.** 무료와 유료(또는 두 서비스)에 똑같은 질문을 하고 차이를 보세요.
3. **회사 일은 회사 방침을 먼저 확인하세요.** 개인 구독으로 회사 자료를 다루는 건 규정에 어긋날 수 있어요.
4. **약관의 데이터 부분을 읽으세요.** 요금제마다 데이터 처리 조건이 다를 수 있어요.
5. **공식 요금 페이지를 직접 확인하세요.** 블로그나 영상의 가격 정보는 낡았을 수 있어요.

## 자주 하는 오해

- "유료면 환각이 없다" → 유료도 틀려요. 확인하는 습관은 그대로 필요해요.
- "비싼 모델이 모든 일에 낫다" → 일에 따라 작고 빠른 모델이 더 낫기도 해요.
- "무료는 쓸모없다" → 많은 일에 충분해요. 질문 요령이 먼저예요.
