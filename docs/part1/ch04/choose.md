# 내 일에 맞는 AI 고르기

<p class="ep-meta"><span>4장 · 4.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 도구를 고를 때는 이름을 먼저 보지 말고 ==내가 하려는 일==부터 정한다.
    - 일의 종류, 정확도 요구, 민감한 정도, 반복 횟수 네 가지로 후보를 좁힌다.
    - 고른 뒤에는 같은 일로 시험해 보고, 가끔 다시 점검한다.

## 1. 신발 고르기

산책할 때, 달리기할 때, 등산할 때 신는 신발은 달라요. "가장 비싼 신발"이 아니라 **하려는 일에 맞는 신발**이 좋은 신발이에요.

AI도 마찬가지예요. 어떤 서비스가 유명한지보다 **내가 무슨 일을 할지**가 먼저예요.

!!! tip "10살 눈높이 한 줄 요약"
    "뭐가 제일 좋아?"보다 **"내가 뭘 할 건데?"**를 먼저 물어요.

## 2. 네 가지 질문

**① 어떤 일인가?** 글쓰기, 조사, 정리, 그림, 코딩 중 무엇인가요? (앞 페이지의 종류표를 보세요.)

**② 얼마나 정확해야 하나?** 아이디어라면 틀려도 괜찮지만, 숫자와 법, 의학은 확인이 꼭 필요해요. 정확도가 중요할수록 검색, 출처, 사람 확인이 필요해요.

**③ 얼마나 민감한가?** 개인정보나 회사 기밀이 있다면 데이터 설정과 규정이 선택 기준이에요. (3.2의 개인정보 페이지)

**④ 얼마나 자주 하나?** 한 번이면 아무거나 괜찮고, 매일 반복한다면 사용량과 안정성, 틀 저장 기능이 중요해요.

## 3. 일에 따른 시작점

| 일 | 먼저 볼 것 |
|---|---|
| 글 다듬기·초안 | 텍스트 챗봇. 내 자료를 붙여 주기 |
| 최근 소식·사실 확인 | 검색이 붙은 도구 + 출처 열어 보기 |
| 긴 문서 읽기 | 긴 글을 올릴 수 있는 기능과 한도 |
| 숫자·표 정리 | 계산은 도구로 따로 검증 |
| 그림 | 이미지 도구 + 저작권 약관 확인 |
| 회사 일 | 회사가 승인한 도구, 데이터 설정 |

## 4. 시험해 보는 법

1. **같은 일을 두 도구에 시켜 보세요.** 가장 자주 하는 일로 해야 의미가 있어요.
2. **체크리스트로 비교하세요.** 정확도, 말투, 출처, 속도, 불편한 점을 적어요.
3. **실수를 일부러 찾아보세요.** 틀린 부분이 있는지, 틀렸을 때 인정하는지 보세요.
4. **정했다면 한 달쯤 뒤에 다시 점검해 보세요(이 책의 권장 요령이에요).** 서비스는 빠르게 바뀌어요.

```text
[시험용 일]
내가 가장 자주 하는 일: ___
기대하는 결과: ___
확인할 것: 사실이 맞는가 / 말투가 맞는가 / 시간이 얼마나 걸렸나
```

!!! note "★ 한 걸음 더 (심화)"
    - Anthropic 문서는 모델을 고를 때 **먼저 필요한 조건을 정하고, 실제 시험으로 확인**하라고 안내해요. 개발자를 위한 글이지만 사용자에게도 통해요. 조건은 능력, 속도, 비용이고, 시험은 내 일을 닮은 예시로 해야 해요.
    - 공개된 성능 비교표(벤치마크)는 참고는 되지만 내 일과 맞는지는 별개예요. 벤치마크의 한계는 V부에서 다뤄요.

## 직접 해보기

가장 자주 하는 일 하나를 정해서, 아래를 채워 보세요.

1. 일의 종류:
2. 정확도 요구 (낮음/보통/높음):
3. 민감한 정보 포함 여부:
4. 한 주에 하는 횟수:

그 답을 보고 위의 "일에 따른 시작점" 표에서 첫 후보를 정하세요. 그리고 일주일 동안 그 후보로 같은 일을 해 보세요.

## 오늘 바로 써먹기

1. **일을 먼저 정하고 도구를 고르세요.** 순서가 거꾸로면 도구에 일을 맞추게 돼요.
2. **정확도가 높은 일엔 확인 단계를 같이 정하세요.** 3장의 확인법을 쓰세요.
3. **회사 일은 승인된 도구부터 보세요.** 개인정보와 기밀은 선택의 첫 기준이에요.
4. **시험은 내 실제 일로 하세요.** 남이 만든 예시는 내 일과 다를 수 있어요.
5. **한 달에 한 번 점검하세요.** 더 나은 도구가 나오거나, 쓰던 기능이 바뀔 수 있어요.

## 자주 하는 오해

- "다들 쓰는 게 최고다" → 내 일에 맞는지가 중요해요.
- "한 번 정하면 계속 쓴다" → 서비스는 바뀌고 내 일도 바뀌어요. 가끔 점검하세요.
- "성능표 1등이면 내 일에도 1등이다" → 성능표는 내 일과 다른 문제로 잰 거예요.
