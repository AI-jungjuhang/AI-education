# 챗봇, 검색형, 이미지, 음성: 종류 나누기

<p class="ep-meta"><span>4장 · 4.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - "AI"라고 부르는 도구들은 ==무엇을 입력받고 무엇을 만들어 내는지==로 나눌 수 있다.
    - 텍스트 챗봇, 검색이 붙은 챗봇, 이미지·음성 도구, 코딩 도우미는 잘하는 일이 다르다.
    - 종류를 알면 일에 맞는 도구를 고르기 쉽고, 틀릴 때 어디를 의심할지도 보인다.

## 1. 도구 상자

망치, 드라이버, 줄자는 다 "공구"지만 쓰임이 달라요. 못에 드라이버를 쓰진 않죠.

"AI"도 이름은 하나지만 **하는 일이 다른 도구들**이에요. 무엇을 넣고(입력) 무엇이 나오는지(출력)를 보면 구분하기 쉬워요.

!!! tip "10살 눈높이 한 줄 요약"
    AI는 **도구 상자**예요. 무엇을 넣고 무엇이 나오는지 보면 어떤 도구인지 알 수 있어요.

## 2. 종류 나누기

| 종류 | 넣는 것 → 나오는 것 | 이럴 때 | 조심할 점 |
|---|---|---|---|
| 텍스트 챗봇 | 글 → 글 | 글쓰기, 설명, 아이디어, 번역 | 환각, 최신 정보 부족 |
| 검색이 붙은 챗봇 | 질문 → 검색해서 쓴 답과 출처 | 최근 소식, 사실 확인이 필요한 질문 | 출처를 잘못 요약할 수 있음 |
| 이미지 생성 | 글(또는 사진) → 그림 | 삽화, 시안, 아이디어 스케치 | 손가락이나 글자가 어색할 수 있음, 저작권 |
| 음성·대화 | 말 → 말 | 말로 묻고 듣기, 통역, 받아쓰기 | 인식 오류, 개인정보 |
| 코딩 도우미 | 설명이나 코드 → 코드 | 프로그램 작성, 오류 찾기 | 실행해 보고 검증해야 함 |
| 에이전트 | 목표 → 스스로 여러 단계를 실행 | 여러 단계의 일을 맡길 때 | 실수가 쌓일 수 있음 (IV부) |

위 표는 이해를 돕기 위한 대략적인 분류예요. 요즘은 하나의 서비스가 여러 종류를 함께 제공하는 경우가 많아요.

## 3. 합쳐져서 나오는 경향

Karpathy의 LLM 소개 강연은 언어 모델이 글뿐 아니라 이미지와 소리 같은 다른 입력과 출력을 다루고, 검색이나 계산기 같은 도구를 쓰는 방향으로 발전하는 모습을 소개해요. 그래서 한 챗봇에서 사진을 올려 물어보고, 검색해서 답을 받고, 표까지 만드는 일이 가능해졌어요.

다만 **같은 이름의 서비스라도 기능은 요금제와 시점에 따라 달라요.** 내가 지금 쓰는 서비스가 어떤 기능을 제공하는지는 직접 확인해야 해요.

!!! note "★ 한 걸음 더 (심화)"
    - 글, 이미지, 소리를 한 모델이 함께 다루는 것을 **멀티모달**이라고 불러요. 이미지를 토큰 같은 조각으로 쪼개 글과 함께 읽는 방식 등이 쓰여요. 이 책의 III부에서 토큰과 임베딩을 배우면 그 방식도 이해하기 쉬워져요.
    - 이미지 생성은 글을 쓰는 방식("다음 말 고르기")과는 다른 방식(예: 점점 노이즈를 걷어 내며 그림을 만드는 방식)이 많이 쓰이지만, 글과 그림을 한 모델이 함께 만드는 방식도 연구돼요. 이 책에서는 글 챗봇을 중심으로 다뤄요.

## 직접 해보기

최근 한 주 동안 내가 AI에게 시킨 일 5가지를 적어 보세요. 그리고 각각을 위 표에서 어느 종류로 해결했는지 분류해 보세요.

- 검색이 필요한 일을 검색 기능 없이 시킨 적이 있나요?
- 정확해야 하는 일을 챗봇에게만 맡긴 적이 있나요?

## 오늘 바로 써먹기

1. **최신 정보는 검색이 되는 도구로 물으세요.** 학습한 시점 이후의 일은 일반 챗봇이 모를 수 있어요.
2. **그림은 시안으로, 글자와 숫자는 직접 확인하세요.** 이미지 안의 글자는 틀리기 쉬워요.
3. **코드는 반드시 실행해 보세요.** 코딩 도우미가 쓴 코드도 틀릴 수 있어요.
4. **내가 쓰는 서비스의 기능 목록을 한 번 읽어 보세요.** 몰라서 못 쓰는 기능이 있을 수 있어요.
5. **한 가지 도구로 모든 걸 하려 하지 마세요.** 일마다 알맞은 도구를 고르세요.

## 자주 하는 오해

- "AI는 다 같은 AI다" → 종류마다 잘하는 일과 틀리는 방식이 달라요.
- "검색이 붙어 있으면 항상 맞다" → 검색이 도움이 되지만 가져온 내용을 잘못 요약할 수 있어요.
- "이미지 AI도 글 챗봇처럼 다음 말을 맞힌다" → 만드는 방식은 도구마다 달라요.
