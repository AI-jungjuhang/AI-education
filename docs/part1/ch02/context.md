# 맥락을 주면 답이 달라진다

<p class="ep-meta"><span>2장 · 2.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 챗봇은 우리가 적은 글만 보고 다음 말을 고르기 때문에, ==적지 않은 사정은 알 수 없다.==
    - 맥락 네 가지(누가 읽나, 무엇을 위해, 어떤 조건, 가진 자료)를 적으면 답이 확 달라진다.
    - 맥락은 "많이"가 아니라 "관련 있게" 주는 것이다.

## 1. 길 가는 사람에게 "맛집 알려 줘"라고 하면

길에서 처음 본 사람에게 "맛집 알려 주세요"라고 하면 뭐라고 대답할까요? 아마 "어떤 음식이요? 누구랑 가세요? 예산은요?"라고 되물을 거예요.

챗봇도 똑같은 상황이에요. 사람처럼 되묻기도 하지만, 질문이 모호해도 **바로 그럴듯한 답을 이어 쓰는 일이 많아요.** 1장에서 봤듯이 챗봇은 앞에 적힌 글을 보고 다음 말을 고르니까요. 적힌 게 적으면, 고를 수 있는 말이 너무 많아서 누구에게나 맞는 평범한 답이 나와요.

!!! tip "10살 눈높이 한 줄 요약"
    챗봇은 **내 머릿속을 볼 수 없어요.** 내가 아는 사정은 글로 적어 줘야 챗봇도 알아요.

## 2. 맥락 네 가지

| 맥락 | 이런 걸 적어요 | 예시 |
|---|---|---|
| 누가 읽나 | 읽는 사람과 그 사람이 아는 정도 | 초등학교 5학년, 팀장님 |
| 무엇을 위해 | 이 결과를 어디에 쓸지 | 발표 자료의 첫 장, 사과 문자 |
| 어떤 조건 | 길이, 말투, 하지 말아야 할 것 | 3문장, 존댓말, 전문 용어 금지 |
| 가진 자료 | 참고할 글이나 숫자 | 아래에 붙인 회의 메모 |

## 3. 달라지는 모습

```text
약한 질문: 동아리 홍보 문구 써줘

나은 질문: 대학교 보드게임 동아리의 신입 회원 모집 문구를 써 줘.
          읽는 사람은 게임을 한 번도 안 해 본 1학년이야.
          인스타 게시물에 올릴 거라서 3문장 이내, 반말 말고 부드러운 존댓말로.
          "경쟁"이라는 말은 빼 줘. 부담스러워 보일 수 있어서.
```

마지막 줄처럼 **이유를 같이 적으면** 챗봇이 목적을 더 잘 헤아려요. Anthropic의 문서도 지시의 이유나 동기를 설명해 주면 챗봇이 목표를 더 잘 이해한다고 안내해요.

## 4. 동료 테스트

Anthropic 문서가 알려 주는 간단한 점검법이 있어요. 내가 쓴 질문을 **그 일을 전혀 모르는 동료에게 보여 주고 그대로 해 보라고** 한다면 어떨까요? 동료가 헷갈려 할 것 같다면 챗봇도 헷갈려요.

!!! note "★ 한 걸음 더 (심화)"
    - 챗봇이 한 번에 볼 수 있는 글 전체를 **컨텍스트 창**이라고 해요. 이 안에 들어 있는 것이 "맥락"의 전부예요. 학습할 때 읽은 방대한 글과는 다른, 일종의 작업 기억이에요.
    - 많이 넣는다고 무조건 좋지는 않아요. Anthropic 문서는 글이 길어질수록 정확도와 기억이 떨어지는 현상(컨텍스트 로트)을 언급하며, 무엇을 넣을지 가려내는 일이 얼마나 넣을 수 있는지만큼 중요하다고 해요. 컨텍스트 창은 III부에서 자세히 다뤄요.

## 직접 해보기

같은 부탁을 두 가지로 해 보고 비교하세요.

```text
① 주말에 할 만한 거 추천해 줘.
```

```text
② 서울에 사는 30대 직장인이야. 이번 주말에 비가 오고 예산은 3만 원 이하야.
   혼자 보낼 거고 집에서 한 시간 안에 갈 수 있는 곳이면 좋겠어. 3가지만 추천해 줘.
```

어느 쪽 답이 내 상황에 더 쓸모 있었나요?

## 오늘 바로 써먹기

1. **질문을 보내기 전에 네 칸을 채워 보세요.** 누가 읽나, 무엇을 위해, 어떤 조건, 가진 자료. 다 채울 필요는 없고, 비어 있는 칸이 있으면 "챗봇이 이걸 모르는구나" 하고 알아차리면 돼요.
2. **조건에는 이유를 붙이세요.** "전문 용어 금지"보다 "읽는 분이 초등학생이라서 전문 용어는 빼 줘"가 더 잘 통해요.
3. **내 자료는 질문 아래에 붙여 주세요.** 메모, 이메일, 숫자를 직접 붙여 주면 챗봇이 기억에 의존해서 지어내는 일이 줄어요. (환각은 1장에서 다뤘어요.)
4. **개인정보는 지우고 붙이세요.** 이름, 연락처, 계좌 같은 건 빼거나 가려서 붙이세요. 3장에서 더 다뤄요.

## 자주 하는 오해

- "길게 쓸수록 좋다" → 관련 없는 이야기까지 길게 쓰면 오히려 헷갈려요. 답에 영향을 주는 사정만 적으세요.
- "챗봇은 알아서 눈치껏 해 준다" → 눈치가 아니라 확률로 이어 써요. 적지 않은 것은 가장 흔한 쪽으로 채워져요.
- "한 번 알려 줬으니 계속 기억한다" → 대화 안에서는 기억하지만, 새 대화에서는 처음부터예요. 2.2에서 다뤄요.
