# 고쳐 달라고 말하는 법

<p class="ep-meta"><span>2장 · 2.2</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - "다시 해 줘"만으로는 챗봇이 **무엇을 어떻게** 바꿀지 알 수 없다.
    - 마음에 안 드는 점은 ==한 번에 한 가지, 구체적으로== 말한다.
    - 좋았던 부분은 "유지해 줘"라고 따로 말해야 지켜진다.

## 1. 미용실에서 "좀 다르게 해 주세요"

미용실에서 "좀 다르게 해 주세요"라고만 하면 어떻게 될까요? 어디를, 얼마나, 어떤 방향으로 바꿀지 몰라서 결과가 마음에 안 들 가능성이 커요. "앞머리만 짧게, 옆은 그대로"라고 해야 원하는 대로 나오죠.

챗봇도 같아요. 1장에서 본 것처럼 챗봇은 앞에 적힌 글을 모두 보고 다음 말을 골라요. 그래서 이전 답도 계속 입력의 일부로 남아 있어요. 그런데 "다시 해 줘"라고만 하면 **어느 부분이 문제인지** 알 단서가 없어요.

!!! tip "10살 눈높이 한 줄 요약"
    고쳐 달라고 할 때는 **"어디를, 어떻게"**를 말해 주세요. 그리고 마음에 든 부분은 "그건 그대로"라고 알려 주세요.

## 2. 약한 피드백과 센 피드백

| 약한 피드백 | 센 피드백 |
|---|---|
| 별로야. 다시 해 줘 | 2번째 문단이 너무 어려워. 초등학생이 알 만한 말로 바꿔 줘 |
| 더 짧게 | 전체를 5문장 이내로 줄이고, 숫자 정보는 남겨 줘 |
| 딱딱해 | 존댓말은 유지하되 문장 끝을 "~예요"로 부드럽게 바꿔 줘 |
| 다른 거 | 지금 답은 다 가격 중심이야. 이번엔 사용 편의성 중심으로 3가지 |

## 3. 고치는 요령

1. **한 번에 한 가지를 고치세요.** 길이, 말투, 내용을 한꺼번에 바꾸라고 하면 어느 것이 좋아졌는지 알기 어려워요.
2. **좋았던 부분을 지켜 달라고 말하세요.** "첫 문단은 그대로 두고 두 번째부터 바꿔 줘"처럼요. 말하지 않으면 전체를 새로 쓰면서 좋았던 부분도 바뀔 수 있어요.
3. **이유를 알려 주세요.** "읽는 분이 어르신이라서"처럼 이유를 말하면 챗봇이 비슷한 다른 부분도 함께 고쳐 줘요.
4. **견본을 한 줄 주세요.** "이런 느낌으로"라며 마음에 드는 문장 한 줄을 붙이면 방향이 바로 맞아요.
5. **여러 버전을 받아 보세요.** "서로 다르게 3가지 버전으로"라고 하면 고르기만 하면 돼요. 고친 뒤에는 맨 처음 요청과 비교해 보세요.

```text
방금 쓴 글에서 첫 문단은 그대로 두고, 두 번째 문단만 고쳐 줘.
너무 어려워서 초등학생이 읽어도 이해할 수 있게 쉬운 말로 바꿔 줘.
```

!!! note "★ 한 걸음 더 (심화)"
    - 대화가 길어지면 이전 답과 요청이 모두 컨텍스트 창에 쌓여요. Anthropic 문서는 글이 길어질수록 정확도와 기억이 떨어질 수 있다고 설명해요. 그래서 고치는 횟수가 많아질수록 처음 조건을 잊거나 섞는 일이 생길 수 있어요. 다음 페이지에서 새 대화로 넘어가는 시점을 다뤄요.
    - 같은 요청을 다시 보내면 점수표에서 새로 뽑기 때문에 답이 달라져요. 마음에 안 들면 같은 말을 한 번 더 보내 보는 것도 방법이에요(재생성). 다만 같은 말을 반복하는 것보다 달라진 조건을 적어 주는 쪽이 대체로 낫다고 보는 게 안전해요.

## 직접 해보기

챗봇에게 이렇게 시키고, 나온 답에 두 방식으로 피드백해 보세요.

```text
친구 생일을 축하하는 짧은 메시지를 써 줘.
```

- 방식 A: "별로야. 다시 해 줘."
- 방식 B: 새 대화에서 같은 요청을 한 뒤 "첫 문장은 좋은데 너무 형식적이야. 20대 친구에게 하는 말처럼 편하게, 이모티콘 없이 바꿔 줘."

두 번째 답이 내 마음에 더 가까웠나요?

## 오늘 바로 써먹기

1. **피드백 틀을 외워 두세요.** "[어디]를 [어떻게] 바꿔 줘. [이유]. [그대로 둘 것]은 유지해 줘."
2. **고친 뒤에는 변경점을 물어보세요.** "무엇을 바꿨는지 세 줄로 알려 줘"라고 하면 확인하기 쉬워요.
3. **여러 개 받아서 고르세요.** 마음에 드는 조각들을 골라 "1번의 첫 문장과 3번의 마지막 문장을 합쳐 줘"라고 하면 돼요.
4. **세 번 고쳐도 안 맞으면 요청을 처음부터 다시 쓰세요.** 다음 페이지에서 설명할게요.

## 자주 하는 오해

- "화를 내면 더 잘한다" → 감정 표현은 정보가 아니에요. 무엇이 문제인지가 정보예요.
- "고칠수록 계속 좋아진다" → 몇 번 고치다 보면 처음 조건이 흐려져서 오히려 나빠질 수 있어요.
- "마음에 들면 아무 말도 안 해도 된다" → 이어서 고칠 때는 좋았던 부분을 지켜 달라고 말해야 해요.
