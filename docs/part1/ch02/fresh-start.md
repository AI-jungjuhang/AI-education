# 새 대화가 나을 때

<p class="ep-meta"><span>2장 · 2.2</span><span>읽는 시간 약 4분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 대화가 길어질수록 챗봇은 앞부분을 놓치거나 섞을 수 있고, ==엇나간 답도 계속 영향을 준다.==
    - 이럴 때는 요약을 만들어 새 대화로 옮기는 편이 낫다.
    - 새 대화에서는 처음부터 다시 알려 줘야 한다.

## 1. 낙서가 가득한 칠판

칠판에 낙서가 빼곡하면 새로 중요한 내용을 써도 눈에 안 들어와요. 이럴 땐 칠판을 지우고 **꼭 필요한 것만 다시 써 주는** 게 빨라요.

대화창이 칠판이에요. 지금까지 주고받은 글이 모두 챗봇이 읽는 대상이에요. 길어지면 중요한 조건이 묻히고, 중간에 나온 엉뚱한 답이 계속 다음 말을 끌어당길 수 있어요.

!!! tip "10살 눈높이 한 줄 요약"
    칠판이 낙서투성이면 **지우고 요점만 다시 쓰는** 게 빨라요. 새 대화가 바로 그거예요.

## 2. 새 대화가 나은 때

| 이럴 때 | 왜 |
|---|---|
| 몇 번을 고쳐도 계속 엇나갈 때 | 잘못된 방향의 답이 앞에 남아서 계속 영향을 줘요 |
| 대화가 아주 길어졌을 때 | 한 번에 볼 수 있는 양에는 한도가 있고, 길수록 정확도가 떨어질 수 있어요 |
| 주제가 완전히 바뀔 때 | 앞의 이야기가 새 주제에 섞일 수 있어요 |
| 처음 조건을 챗봇이 자꾸 잊을 때 | 조건이 대화 속에 묻혀 있어요 |

반대로 같은 주제를 이어서 다듬는 중이라면 새 대화로 갈 필요는 없어요.

## 3. 요약해서 옮기기

새 대화를 열기 전에, 지금 대화에서 요점을 뽑아 둬요.

```text
지금까지 대화에서 정해진 것을 정리해 줘.
- 목적:
- 읽는 사람:
- 꼭 지켜야 할 조건:
- 지금까지 마음에 든 부분:
- 마음에 안 든 부분과 그 이유:
새 대화에서 그대로 붙여 넣어 쓸 수 있게 간결하게 써 줘.
```

나온 요약을 읽어 보고 틀린 부분을 고친 다음, **새 대화의 첫 메시지로 붙여 넣으세요.** 이전에 잘못된 방향의 답은 요약에 넣지 않으니 깨끗하게 시작할 수 있어요.

!!! note "★ 한 걸음 더 (심화)"
    - Anthropic 문서는 컨텍스트 창을 모델의 "작업 기억"에 비유해요. 그리고 토큰이 늘수록 정확도와 기억이 떨어지는 현상(컨텍스트 로트)이 있다고 설명하며, 무엇을 컨텍스트에 둘지 가려내는 일이 중요하다고 해요.
    - 긴 대화나 에이전트 작업에서는 서비스가 오래된 부분을 **자동으로 요약해서 압축**해 주기도 해요. 문서는 서버 쪽 압축을 긴 대화를 관리하는 주요 방법으로 소개해요. 어떤 서비스가 어떻게 하는지는 제각각이니, 내가 쓰는 서비스의 설명을 확인하세요.
    - 일부 서비스에는 "기억" 기능이 있어서 새 대화에서도 이전 정보를 불러올 수 있어요. 기능과 설정은 서비스마다 달라요.

## 직접 해보기

챗봇과 이야기를 열 번쯤 주고받으며 조건을 하나씩 추가해 보세요. (예: 여행 계획에 예산, 날짜, 동행, 식사 취향을 차례로 추가) 그다음 이렇게 해 보세요.

1. 위의 "정리" 요청을 보내 요약을 받아요.
2. 새 대화를 열고 요약을 붙여 넣은 뒤 "이 조건으로 일정표를 만들어 줘"라고 해요.
3. 긴 대화에서 받은 답과 비교해 보세요. 빠진 조건이 있나요?

## 오늘 바로 써먹기

1. **세 번 고쳐도 안 되면 새 대화로 가세요.** 계속 고치는 것보다 요약해서 옮기는 쪽이 빨라요.
2. **요약에는 "안 된 이유"도 적으세요.** 같은 방향의 실수를 피하는 데 도움이 돼요.
3. **주제가 바뀌면 새 대화를 여세요.** 대화 하나에 일 하나가 좋아요.
4. **중요한 조건은 매 대화 첫머리에 적으세요.** 다음 페이지에서 만들 "나만의 질문 틀"이 바로 그 용도예요.

## 자주 하는 오해

- "새 대화를 열면 아까 일이 전부 사라진다" → 요약해서 옮기면 필요한 건 가져올 수 있어요.
- "대화가 길수록 챗봇이 나를 더 잘 안다" → 길수록 오히려 앞부분을 놓칠 수 있어요.
- "기억 기능이 있으면 요약이 필요 없다" → 기억 기능이 무엇을 어떻게 저장하는지 내가 다 알 수는 없어서, 중요한 조건은 직접 적는 게 확실해요.
