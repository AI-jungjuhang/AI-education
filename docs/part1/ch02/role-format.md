# 역할, 형식, 예시를 정해 준다

<p class="ep-meta"><span>2장 · 2.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - **역할**은 말투와 관점을, **형식**은 결과의 모양을, **예시**는 원하는 견본을 알려 준다.
    - 이 셋을 정해 주면 챗봇이 고를 수 있는 "다음 말"의 범위가 ==내가 원하는 쪽으로 좁아진다.==
    - 역할을 준다고 모르는 사실을 알게 되는 건 아니다.

## 1. 옷, 그릇, 견본

요리사에게 부탁한다고 생각해 보세요.

- **역할은 옷이에요.** "초등학교 선생님처럼 설명해 줘"라고 하면 말투와 설명 방식이 달라져요.
- **형식은 그릇이에요.** "표로", "세 줄로", "번호를 붙여서"처럼 담을 모양을 정해 줘요.
- **예시는 견본이에요.** "이런 느낌으로"라고 한 가지를 보여 주면 백 마디 설명보다 빨라요.

!!! tip "10살 눈높이 한 줄 요약"
    **옷(역할), 그릇(형식), 견본(예시)**을 정해 주면 챗봇이 엉뚱한 쪽으로 이어 쓸 일이 줄어요.

## 2. 역할: 관점과 말투를 정한다

```text
너는 중학교 과학 선생님이야. 학생이 "왜 하늘은 파랗죠?"라고 물었어.
중학교 1학년이 이해할 수 있게 설명해 줘.
```

Anthropic 문서는 역할을 한 문장만 줘도 챗봇의 행동과 말투가 집중된다고 안내해요. 챗봇은 그 역할이 쓸 법한 말을 다음 말로 더 많이 고르게 되는 거예요.

다만 역할은 **옷일 뿐 지식이 아니에요.** "너는 세계 최고의 의사야"라고 해도 모르는 사실을 알게 되지는 않아요. 그러면 환각의 위험은 그대로예요.

## 3. 형식: 결과의 모양을 정한다

```text
아래 회의 메모를 정리해 줘. 형식은 이렇게 해 줘.
- 결정된 것: 최대 3개, 한 줄씩
- 아직 안 정해진 것: 최대 3개
- 다음 할 일: 담당자와 날짜가 있는 표
```

받아서 바로 쓸 수 있는 모양을 미리 정해 두면, 고쳐 달라는 말을 여러 번 하지 않아도 돼요. 문서도 원하는 출력 형식과 조건을 구체적으로 적으라고 말해요.

## 4. 예시: 견본을 보여 준다

```text
상품 이름을 짓는 중이야. 이런 느낌으로 지어 줘.
예시 1) 감자 → 포슬포슬 감자샘
예시 2) 우유 → 하얀 구름 한 컵
같은 느낌으로 "딸기"로 5개 지어 줘.
```

예시는 형식, 말투, 구조를 맞추는 가장 믿을 만한 방법 중 하나라고 Anthropic 문서가 설명해요. 문서는 예시를 3~5개 정도 주고, 서로 조금씩 다르게 고르라고 권해요. 예시가 다 비슷하면 챗봇이 그 특징을 그대로 따라 해 버려요.

!!! note "★ 한 걸음 더 (심화)"
    - 예시를 주는 방법을 **퓨샷(few-shot) 프롬프팅**이라고 불러요. 예시가 하나면 원샷, 없으면 제로샷이에요.
    - 지시, 예시, 자료가 섞여 길어질 때는 `<예시>`처럼 이름 붙은 태그로 구분하면 챗봇이 헷갈리지 않아요. Anthropic 문서는 XML 태그로 내용을 나누는 방법을 안내해요.
    - 이런 효과가 왜 생기는지는 "다음 말 고르기"로 설명돼요. 앞에 놓인 글이 다음 말의 확률을 바꾸기 때문이에요.

## 직접 해보기

같은 주제를 세 가지 방식으로 시켜 보세요.

```text
① 감자의 장점을 알려 줘.
② 너는 초등학교 선생님이야. 감자의 장점을 초등학교 3학년에게 알려 줘.
③ ②처럼 하되 표로 만들어 줘. 열은 "장점"과 "쉬운 예"로 해 줘.
```

답이 어떻게 달라지는지 비교해 보세요. 어떤 변화가 역할 때문이고, 어떤 변화가 형식 때문인지 구분해 보면 재미있어요.

## 오늘 바로 써먹기

1. **세 가지를 한 줄씩 적는 틀을 만들어 두세요.** "역할: / 형식: / 예시:"를 메모 앱에 저장해 두고 필요할 때 채워 넣으면 돼요.
2. **마음에 드는 글은 견본으로 쓰세요.** 예전에 잘 나온 답이나 내가 쓴 글을 "이 글처럼"이라고 붙여 주면 말투를 맞추기 쉬워요.
3. **예시는 다양하게 고르세요.** 비슷한 예시만 주면 비슷한 결과만 나와요.
4. **역할은 말투와 관점에 쓰고, 사실 확인에는 쓰지 마세요.** 사실은 자료를 붙여 주거나 직접 확인하세요.

## 자주 하는 오해

- "역할을 주면 전문가의 지식이 생긴다" → 말투와 관점이 바뀌는 거지 지식이 늘지는 않아요.
- "형식을 정하면 내용이 나빠진다" → 보통은 읽기 쉬워져요. 다만 형식이 너무 빡빡하면 담을 말이 모자랄 수 있어요.
- "예시는 많을수록 좋다" → 문서는 3~5개 정도를 권해요. 너무 많으면 길어지고 한쪽으로 쏠려요.
