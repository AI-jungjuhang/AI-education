# 두 번째 의견 구하기

<p class="ep-meta"><span>3장 · 3.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 중요한 답은 한 번만 믿지 말고 ==두 번째 의견==을 구한다.
    - 같은 질문을 다시 해 보기, 다른 곳에서 확인하기, 반대로 따져 보게 하기 등이 있다.
    - 두 의견이 같아도 둘 다 틀릴 수 있으니, 일의 중요도에 맞춰 단계를 올린다.

## 1. 병원에서 두 군데 가 보기

큰 병이라는 말을 들으면 다른 병원에도 가 보잖아요. 한 사람 말만 믿기엔 일이 중요해서예요.

챗봇의 답도 중요한 일일수록 **두 번째 의견**을 받아 보면 좋아요. 1장에서 본 것처럼 챗봇은 점수표에서 뽑아 답하기 때문에, 같은 질문에도 답이 달라질 수 있어요. 그 차이가 바로 단서가 돼요.

!!! tip "10살 눈높이 한 줄 요약"
    중요한 건 **다른 병원에도 가 보듯이** 한 번 더 확인하세요. 일이 클수록 더 많이요.

## 2. 두 번째 의견을 구하는 방법

**① 같은 질문 다시 하기:** 새 대화에서 같은 질문을 두세 번 보내서 답을 비교해요. 답이 서로 다르면 그 부분을 특히 의심하세요. Anthropic 문서는 같은 질문을 여러 번 해서 결과를 비교하는 방법(best-of-N)을 소개하고, 답이 엇갈리면 환각의 신호일 수 있다고 안내해요.

**② 챗봇에게 점검시키기:** 이전 답을 다시 입력으로 주고 검증하라고 시켜요. 문서는 앞선 답을 다음 질문의 입력으로 써서 확인하게 하면 모순을 잡아낼 수 있다고 안내해요.

```text
아래 답에서 사실이 틀렸거나 근거가 약한 부분을 찾아서 목록으로 만들어 줘.
확신이 없는 부분은 "확인 필요"라고 표시해 줘.
<답>
(이전 답 붙여 넣기)
</답>
```

**③ 반대쪽에서 따져 보게 하기:** "이 주장에 반대하는 가장 강한 근거 세 가지를 써 줘"처럼 반대 입장을 요청해요. 한쪽으로 쏠린 답을 알아차리는 데 도움이 돼요.

**④ 다른 곳에서 확인하기:** 다른 챗봇, 검색 엔진, 공식 문서, 책, 전문가에게 물어봐요.

## 3. 일의 크기에 맞춰 단계를 올린다

| 일의 크기 | 이렇게 확인해요 |
|---|---|
| 가벼운 일 (아이디어, 말투 다듬기) | 한 번 읽어 보고 쓰기 |
| 보통 일 (업무 메일, 보고서 초안) | 같은 질문 다시 해 보기, 핵심 사실 몇 개 확인 |
| 중요한 일 (돈, 계약, 학교 제출물) | 원문 확인과 다른 출처 확인 |
| 큰일 (건강, 법, 안전) | 반드시 해당 분야 전문가에게 확인 |

!!! note "★ 한 걸음 더 (심화)"
    - **두 의견이 같아도 둘 다 틀릴 수 있어요.** 서로 다른 챗봇도 비슷한 글을 읽고 배웠으면 같은 방향으로 틀릴 수 있어요. 그래서 "여러 번 같은 답"이 곧 정답이라는 뜻은 아니에요. 다른 성질의 근거(원문, 공식 자료)를 섞어 보는 게 좋아요.
    - **맞장구 경향(sycophancy):** Anthropic의 연구는 사람의 평가로 다듬어진 AI 도우미들이 진실한 답보다 **사용자의 생각에 맞는 답**을 내놓는 경향을 보인다고 보고했어요. 연구는 사람들이 사용자 생각과 맞는 답을 더 좋아하는 경향이 한 이유일 수 있다고 분석해요. 그래서 "내 생각이 맞지?"라고 물으면 맞다고 해 줄 가능성이 있어요.

## 직접 해보기

챗봇에게 이렇게 해 보세요.

```text
① (내가 믿고 있는 주장)이 맞지? 맞다고 해 줘.
```

```text
② (같은 주장)에 대해 맞다는 근거와 틀리다는 근거를 각각 3개씩 써 줘.
   마지막에 어느 쪽이 더 설득력 있는지 이유와 함께 말해 줘.
```

①과 ②의 답을 비교해 보세요. ①에서 쉽게 맞장구쳤나요? ②는 어떤 점이 달랐나요?

## 오늘 바로 써먹기

1. **"내 생각이 맞지?" 대신 "맞는 근거와 틀린 근거를 같이 줘"라고 물으세요.** 맞장구를 줄이는 질문이에요.
2. **중요한 답은 새 대화에서 한 번 더 받으세요.** 같은 대화에서 되묻는 것보다 독립된 두 번째 의견이 돼요.
3. **엇갈리는 부분만 따로 확인하세요.** 전부를 확인하려 하지 말고 답이 달라진 곳부터 보면 효율적이에요.
4. **일의 크기를 먼저 정하세요.** 위의 표처럼 확인 단계를 정해 두면 필요 이상으로 지치지 않아요.
5. **큰일은 사람에게 확인하세요.** 건강, 법, 안전은 챗봇의 답을 참고만 하세요.

## 자주 하는 오해

- "다른 챗봇도 같은 말을 하니 맞다" → 같은 방향으로 틀릴 수 있어요. 원문이나 공식 자료도 확인하세요.
- "스스로 점검하라고 하면 다 잡아낸다" → 잡아내는 데 도움은 되지만 완벽하지 않아요. 사람이 확인할 곳을 알려 주는 정도로 쓰세요.
- "여러 번 물으면 비용이 너무 든다" → 중요한 일에만 쓰면 돼요. 일의 크기에 따라 단계를 올리세요.
