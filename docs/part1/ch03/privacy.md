# 개인정보와 민감한 자료

<p class="ep-meta"><span>3장 · 3.2</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 인터넷으로 쓰는 챗봇에 글을 입력하는 것은 ==그 서비스 회사에 내용을 보내는 일==이다(내 컴퓨터 안에서만 돌리는 모델은 예외예요).
    - 이름, 연락처, 계좌 같은 개인정보와 회사 기밀은 가리고 쓴다.
    - 입력한 내용이 어떻게 쓰이는지는 서비스와 설정마다 달라서 직접 확인해야 한다.

!!! warning "알려 드려요"
    이 페이지는 일반 정보예요. 법률 자문이 아니에요. 회사나 학교에는 따로 규칙이 있을 수 있으니 그 규칙이 먼저예요.

## 1. 엽서에 쓴 말

엽서에 쓴 글은 우체부 아저씨도 볼 수 있어요. 편지 봉투에 넣어야 비밀이 지켜지죠.

챗봇에 글을 입력하는 것도 비슷해요. 내 컴퓨터 안에서 끝나는 게 아니라 **인터넷으로 쓰는 서비스라면 운영하는 회사의 서버로 글이 전달돼요(내 컴퓨터 안에서만 돌리는 모델은 달라요).** 그 글이 어떻게 보관되고 쓰이는지는 서비스와 설정에 따라 달라요.

!!! tip "10살 눈높이 한 줄 요약"
    챗봇에 쓰는 건 **엽서에 쓰는 것과 비슷해요.** 남이 보면 곤란한 건 쓰기 전에 가려요.

## 2. 가려야 하는 정보

| 종류 | 예 |
|---|---|
| 나를 알아볼 수 있는 정보 | 이름, 연락처, 주소, 주민등록번호, 계좌번호, 얼굴 사진 |
| 민감한 정보 | 건강 상태, 병력, 종교, 정치적 성향, 성생활 |
| 남의 정보 | 친구, 고객, 동료의 이름과 사정 |
| 일터의 정보 | 아직 공개되지 않은 계획, 고객 목록, 코드, 계약서 |
| 로그인 정보 | 비밀번호, 인증 번호, API 키 |

## 3. 가려서 쓰는 요령

1. **이름을 바꾸세요.** "김민수 → A씨", "서울 강남구 ○○동 → 서울의 한 지역"처럼 쓰세요.
2. **숫자를 가리세요.** 계좌번호나 주민번호는 아예 지우고, 금액은 필요한 만큼만 적으세요.
3. **필요한 부분만 붙이세요.** 문서 전체가 아니라 질문과 관련된 문단만 골라 붙이세요.
4. **일반적인 상황으로 바꿔 물으세요.** "우리 회사 ○○ 고객의 사정"이 아니라 "한 고객이 이런 불만을 말했을 때"처럼요.

```text
아래 글에서 이름, 연락처, 주소, 계좌번호 같은 개인정보를 찾아서 [이름1], [연락처1]처럼
바꾼 글로 다시 써 줘. 바꾼 목록은 따로 적지 마.
```

(가리는 작업 자체를 챗봇에 맡기면 원본이 이미 전송된다는 점에 주의하세요. 가능하면 직접 가리세요.)

## 4. 어떻게 쓰이는지 확인하는 법

입력한 내용을 서비스가 어떻게 다루는지는 회사와 요금제, 설정에 따라 달라요. 내가 쓰는 서비스의 **설정 화면과 개인정보 처리방침**에서 이런 것을 확인해 보세요.

- 내 대화가 모델 개선에 쓰이는지, 끌 수 있는지
- 대화가 얼마나 오래 보관되는지
- 삭제하면 어떻게 되는지
- 회사 계정에 속해 있다면 회사가 대화 기록을 볼 수 있는지

!!! note "★ 한 걸음 더 (심화)"
    - 한국의 개인정보보호위원회는 2025년 8월 6일 「생성형 인공지능(AI) 개발·활용을 위한 개인정보 처리 안내서」를 공개했다고 보도됐어요. 보도에 따르면, 외부 AI 서비스(API)를 쓰는 경우 이용자가 입력한 내용이 해외 서버로 전송될 수 있어서 계약이나 약관으로 안전성을 확보하라고 권고한다고 해요. 이 안내서는 회사나 기관이 AI를 만들고 쓰는 경우를 중심으로 한 내용이에요.
    - 학습 데이터 쪽에서는 모델이 훈련 과정에서 본 글을 일부 그대로 내뱉을 가능성이 연구돼 왔어요. 그래서 "서비스가 내 대화를 학습에 쓰는가"는 중요한 질문이에요. 서비스마다 정책이 달라 일반화하기 어려워요.

## 직접 해보기

최근 챗봇에 보냈거나 보내려는 글 하나를 골라서 점검해 보세요.

1. 위의 표에서 해당하는 정보가 있는지 체크하세요.
2. 있다면 가려서(이름 바꾸기, 숫자 지우기) 다시 써 보세요.
3. 가린 글로도 원하는 답이 나오는지 확인하세요. 대부분은 나와요.
4. 내가 쓰는 서비스의 설정에서 "대화 내용 사용" 항목을 한 번 찾아보세요.

## 오늘 바로 써먹기

1. **보내기 전에 한 번 멈추세요.** "이게 엽서에 써도 괜찮은 내용인가?"
2. **가린 글로 물어보고, 답을 받은 뒤에 내 자료로 채우세요.** 예: 이름은 A씨로 쓰고, 받은 문구에서 A씨를 실제 이름으로 바꾸기
3. **회사 일은 회사 규정을 먼저 확인하세요.** 승인된 도구가 있으면 그것을 쓰세요.
4. **남의 정보는 더 조심하세요.** 내 정보는 내가 정하지만 남의 정보는 그 사람의 동의가 필요할 수 있어요.
5. **비밀번호와 키는 절대 붙이지 마세요.** 코드를 붙일 때도 키가 들어 있지 않은지 보세요.

## 자주 하는 오해

- "대화 내용은 나만 볼 수 있다" → 서비스를 운영하는 회사가 어떻게 보관하고 쓰는지는 서비스마다 달라요. 설정과 처리방침을 확인하세요.
- "지우면 완전히 사라진다" → 삭제 정책은 서비스마다 달라요. 보관 기간이나 예외가 있을 수 있어요.
- "가리면 질문이 안 된다" → 가려도 대부분의 도움은 받을 수 있어요.
