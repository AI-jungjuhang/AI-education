# 숫자와 인용 대조하기

<p class="ep-meta"><span>3장 · 3.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 숫자, 날짜, 따옴표 안의 문장은 챗봇이 ==가장 그럴듯하게 틀리기 쉬운 곳==이다.
    - 숫자는 원문, 어림 계산, 계산 도구로 대조한다.
    - 인용문은 원문에서 그대로 찾아서 맞춰 본다.

## 1. 닮은 그림 찾기

비슷해 보이는 두 그림에서 틀린 곳 찾기 놀이를 해 본 적 있나요? 큰 모양은 똑같아서 한참 들여다봐야 작은 차이가 보여요.

챗봇이 틀린 숫자는 꼭 이렇게 생겼어요. **그럴듯해 보여서** 쉽게 지나치게 돼요. 1장에서 봤듯 챗봇은 그럴듯한 다음 말을 고르기 때문에, 숫자도 "있을 법한 숫자"가 나올 수 있어요.

!!! tip "10살 눈높이 한 줄 요약"
    숫자와 따옴표는 **틀린 그림 찾기**처럼 한 번 더 비교해 보세요.

## 2. 어디가 위험한가

| 종류 | 잘 틀리는 모습 |
|---|---|
| 숫자 | 비슷하지만 다른 값, 단위가 바뀜(원/달러, 만/억) |
| 날짜 | 연도나 요일이 하루 이틀 어긋남 |
| 이름 | 비슷한 사람이나 회사와 섞임 |
| 인용문 | 의미는 비슷하지만 문장은 원문과 달라짐 |
| 계산 | 긴 계산에서 중간 값이 틀림 |

## 3. 대조하는 세 가지 방법

**① 원문과 맞춰 보기:** 챗봇이 말한 숫자를 원문에서 찾아 같은지 봐요. 내 자료를 붙여 주고 답하게 했다면, 숫자 옆에 원문 문장을 같이 달라고 하세요.

**② 어림 계산하기:** 대충 맞는지 먼저 봐요. 예를 들어 "인구 5천만 명 중 20%"라면 천만 명쯤이겠죠? 답이 2천만이나 1억이면 이상하다는 걸 바로 알 수 있어요.

**③ 계산은 계산기나 표 계산 프로그램으로:** 정확한 계산은 챗봇보다 계산 도구가 확실해요. 챗봇에게는 계산식을 쓰게 하고, 값은 도구로 구하세요. 도구를 연결해서 쓰는 챗봇은 계산도 도구로 하기도 해요(IV부에서 다뤄요).

## 4. 인용문 확인하기

따옴표 안에 있는 문장은 "원문 그대로"라는 약속처럼 보이지만, 챗봇은 의미를 비슷하게 기억해서 **원문과 다른 문장을 따옴표 안에 넣을 수 있어요.** 확인하는 방법은 간단해요.

1. 인용문의 핵심 단어를 골라요.
2. 원문에서 Ctrl+F로 찾아요.
3. 찾아지지 않으면 "그대로 인용"이 아닐 수 있다고 보세요(스캔본이나 띄어쓰기 차이일 수도 있으니 원문 페이지도 살펴요).

Anthropic 문서는 긴 문서를 다룰 때 먼저 **관련 문장을 한 자 한 자 그대로 뽑게** 한 뒤, 그 문장을 바탕으로 답하게 하라고 안내해요. 그러면 인용이 답의 근거로 남아서 확인하기 쉬워요.

!!! note "★ 한 걸음 더 (심화)"
    - 챗봇이 숫자를 잘 못 다루는 이유 중 하나는 숫자도 토큰 조각으로 읽는다는 점이에요(1장). 긴 숫자는 여러 조각으로 쪼개져서, 사람이 자리를 맞춰 계산하는 것과 다르게 처리돼요. 요즘 모델은 많이 나아졌지만, 긴 계산에서 실수할 수 있다고 알려져 있어요.
    - Anthropic 문서는 같은 질문을 여러 번 보내 답이 서로 다른지 비교하는 방법(best-of-N 검증)을 소개해요. 숫자가 매번 다르게 나온다면 의심하라는 신호예요. 다음 페이지에서 다뤄요.

## 직접 해보기

```text
1234 × 5678은 얼마야? 계산 과정도 보여 줘.
```

계산기에 직접 넣어서 비교해 보세요. (정답은 7,006,652예요.) 맞았나요? 틀렸다면 어디서 틀렸는지 과정에서 찾아보세요. 그다음에 이렇게도 시켜 보세요.

```text
이 계산을 하는 식만 적어 줘. 값은 내가 계산기로 구할게.
```

이 두 방법 중 어느 쪽이 더 안심되나요?

## 오늘 바로 써먹기

1. **숫자에는 "근거 문장도 같이"를 붙이세요.** 숫자 옆에 원문 문장을 달면 대조하기 쉬워요.
2. **어림 계산을 습관으로 하세요.** 크기가 안 맞으면 바로 잡아낼 수 있어요.
3. **계산은 도구에 맡기세요.** 챗봇에게는 식을 쓰게 하고, 값은 계산기나 표 계산 프로그램으로 구하세요.
4. **따옴표 문장은 원문에서 찾아보세요.** 찾을 수 없으면 인용으로 쓰지 마세요.
5. **단위와 기준 연도를 확인하세요.** 같은 숫자도 단위와 기준에 따라 뜻이 달라요.

## 자주 하는 오해

- "숫자가 자세할수록 정확하다" → 소수점까지 자세해도 틀릴 수 있어요. 자세함은 정확함의 증거가 아니에요.
- "과정을 보여 주면 정답이다" → 과정이 그럴듯해도 중간에 틀릴 수 있어요. 값은 따로 확인하세요.
- "인용 부호가 있으면 원문 그대로다" → 확인하기 전에는 모르는 거예요.
