# 긴 답이 이어지는 과정

<p class="ep-meta"><span>12장 · 12.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 챗봇의 긴 답은 ==한 토큰을 뽑고, 그것을 입력에 붙이고, 처음부터 다시 계산하는 일의 반복==이다.
    - 한 번 뽑은 말은 되돌릴 수 없고 뒤의 선택에 영향을 준다.
    - 긴 글은 개요를 먼저 받고 나눠서 쓰게 하면 흐름이 덜 어긋난다.

## 1. 이어달리기

이어달리기에서는 한 사람이 달리고 다음 사람에게 바통을 넘겨요. 앞 사람이 넘어졌다면 다음 사람이 그 자리에서 이어서 달려야 해요. 결승선에서 되돌려 다시 달릴 수는 없죠.

긴 답이 만들어지는 과정이 이래요. **토큰 하나를 뽑을 때마다 바통(이미 쓴 글)이 다음으로 넘어가고**, 이미 쓴 글은 바꿀 수 없어요.

!!! tip "10살 눈높이 한 줄 요약"
    긴 답은 **이어달리기**예요. 한 번 뛴 구간은 되돌릴 수 없고, 그 위에서 다음 구간을 달려요.

## 2. 한 토큰의 일생

3Blue1Brown 강의는 긴 글이 만들어지는 과정을 이렇게 설명해요. 예측 모델이 있으면 긴 글을 만드는 간단한 방법은 이래요.

1. **시작 글을 줘요.**
2. **다음 단어를 예측해요.** (점수표 만들기)
3. **분포에서 무작위로 하나를 뽑아요.** (12장 앞의 두 페이지)
4. **뽑은 것을 글 뒤에 붙여요.**
5. **붙인 글 전체를 입력으로 해서 처음부터 다시 예측해요.**

이 **예측과 뽑기의 반복**이 ChatGPT와 대화할 때 일어나는 일이고, 그래서 **한 단어씩 나오는 것처럼** 보여요. 서비스 화면에서 글자가 조금씩 나타나는 이유예요.

## 3. 이어달리기의 특징

| 특징 | 결과 |
|---|---|
| 한 번 뽑은 말은 되돌릴 수 없다 | 앞에서 엇나가면 뒤까지 이어져요 |
| 앞의 글이 뒤의 입력이 된다 | 앞에서 한 표현이 뒤에서도 반복되기 쉬워요 |
| 매번 전체를 다시 계산한다 | 긴 답은 시간이 걸리고 비용이 들어요 |
| 마지막 토큰을 뽑을 때까지 전체 계획이 없다 | 글의 구조가 길수록 흐름이 어긋날 수 있어요 |

앞 페이지에서 본 것처럼 모델이 계획을 전혀 세우지 않는 것은 아니에요. 내부 계산에 앞을 내다보는 부분이 있다는 연구도 있어요(★ 참고). 하지만 겉으로 보기에 뽑힌 토큰은 되돌릴 수 없어요.

!!! note "★ 한 걸음 더 (심화)"
    - Anthropic의 해석 연구는 시를 쓰는 사례에서 의외의 결과를 보고했어요. 모델이 앞을 내다보지 않을 거라고 예상하고 시작했는데, 오히려 **미리 계획하는 모습**을 발견했다는 거예요(이 글의 소개 문장에서 확인했어요). 한 번에 한 토큰씩 뽑는 구조라도 내부에서는 뒤를 고려한 계산이 있을 수 있다는 뜻이에요. 자세한 내용은 16장에서 다뤄요.
    - 답을 쓰기 전에 **중간 생각을 글로 적게 하면** 그 글이 뒤의 선택에 근거가 돼서 정확도가 오르는 경우가 많아요(7장 "단계별로 생각해 줘"). 요즘 추론 모델은 이 방식을 훈련해서 길게 생각한 뒤 답해요(17장).
    - 긴 글에서는 앞에 쓴 내용이 컨텍스트 창을 차지해 뒤의 선택에 영향을 줘요(11장). 이미 쓴 글이 길수록 입력이 길어져서 계산이 더 필요해요.

## 직접 해보기

두 방식으로 긴 글을 요청해 보세요.

```text
① 우리 동네 도서관을 소개하는 1,000자짜리 글을 써 줘.
```

```text
② 우리 동네 도서관을 소개하는 1,000자짜리 글을 쓰려고 해.
   먼저 5개 문단의 개요(문단별 한 줄)만 제안해 줘. 글은 쓰지 마.
   (개요를 보고 내가 고칠 거야. 그다음 문단별로 쓰자.)
```

①의 글은 끝으로 갈수록 처음의 주제에서 벗어나거나 같은 말이 반복되지 않나요? ②로 개요를 받고 한 문단씩 쓰면 흐름이 어떻게 달라지나요?

## 오늘 바로 써먹기

1. **긴 글은 개요를 먼저 받으세요.** 방향이 틀렸을 때 일찍 고칠 수 있어요(5장).
2. **문단별로 나눠서 쓰게 하세요.** 한 번에 쓰는 구간이 짧을수록 어긋남이 적어요.
3. **끝으로 갈수록 점검하세요.** 앞 내용과 모순되거나 반복되는 부분이 생기기 쉬워요.
4. **길이를 숫자로 정하세요.** "1,000자 이내"는 정확히 맞지 않을 수 있어요(1장 토큰). 대략의 길이로만 보세요.
5. **답이 중간에 끊기면 "이어서 써 줘"라고 하세요.** 한도에 걸린 경우가 많아요(11장).

## 자주 하는 오해

- "AI는 글 전체를 구상한 다음에 쓴다" → 겉으로는 한 토큰씩 뽑아 이어요. 내부에서 앞을 내다보는 계산이 있을 수는 있어요.
- "답이 길면 정성스럽게 쓴 것이다" → 길이와 정확성은 별개예요.
- "중간에 틀린 부분만 고쳐 달라고 하면 앞뒤가 자동으로 맞춰진다" → 앞뒤 일관성은 따로 확인하세요.
