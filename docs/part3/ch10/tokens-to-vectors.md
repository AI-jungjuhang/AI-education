# 토큰이 숫자 묶음이 된다

<p class="ep-meta"><span>10장 · 10.1</span><span>읽는 시간 약 6분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 챗봇은 토큰을 번호로 바꾼 다음, 번호마다 정해진 ==긴 숫자 묶음(벡터)==으로 바꿔서 계산한다.
    - 이 숫자 묶음은 사람이 정한 게 아니라 학습하면서 정해진다.
    - 숫자 묶음 한 줄은 "뜻의 좌표"처럼 쓰인다.

## 1. 주소에서 좌표로

"서울시 중구 세종대로 110"이라는 주소는 사람에게는 의미가 있지만 지도 프로그램은 이걸 **위도와 경도라는 숫자 두 개**로 바꿔서 거리를 계산해요. 숫자가 되어야 계산할 수 있으니까요.

챗봇도 같아요. 1장에서 글을 **토큰**으로 쪼갰죠. 컴퓨터는 글자를 그대로 계산하지 못하니(신경망은 숫자로 계산해요), 토큰마다 **번호**를 붙이고 그 번호를 다시 **여러 개의 숫자 묶음(벡터)**으로 바꿔요. 이 과정을 **임베딩(embedding)**이라고 불러요.

!!! tip "10살 눈높이 한 줄 요약"
    토큰은 **주소**, 임베딩은 **좌표**예요. 좌표가 되어야 거리를 잴 수 있어요.

## 2. 숫자 묶음은 어떻게 생겼나

예를 들어 "감자"라는 토큰은 이런 숫자 묶음이 돼요. (이해를 돕기 위해 3개 숫자로 줄인 지어낸 예시예요.)

| 토큰 | 숫자 묶음 (예시) |
|---|---|
| 감자 | 0.8, −0.2, 0.5 |
| 고구마 | 0.7, −0.1, 0.6 |
| 자동차 | −0.6, 0.9, 0.1 |

실제로는 3개가 아니라 훨씬 많아요. 3Blue1Brown의 설명에 따르면 GPT-3에서는 한 토큰이 **12,288개**의 숫자로 이루어진 묶음이에요. 어휘는 **50,257개** 토큰이고요.

## 3. 변환표가 모델의 첫 번째 부품이에요

토큰 번호를 숫자 묶음으로 바꿔 주는 **변환표**는 모델의 첫 번째 부품이에요. 3Blue1Brown 강의는 이를 **임베딩 행렬**이라고 부르며, 처음에는 값이 무작위지만 **학습하면서 정해진다**고 설명해요. 50,257개 토큰마다 12,288개 숫자가 있으니, 이 첫 단계에만 약 6억 1,756만 개의 숫자(617,558,016개)가 쓰여요. 이 숫자들도 9장에서 본 파라미터의 일부예요.

즉, 어떤 토큰이 어떤 숫자 묶음이 될지는 사람이 정하지 않고, **다음 말 맞히기 연습을 하면서 모델이 스스로 알아내요.**

## 4. 왜 숫자 묶음이 필요할까

- **계산하려고:** 모델 안의 모든 일은 숫자 계산이에요.
- **비슷함을 표현하려고:** 번호 하나로는 "감자와 고구마가 비슷하다"를 표현하기 어려워요. 숫자 묶음이라면 가까운 숫자끼리 비슷한 뜻을 가질 수 있어요(다음 페이지).
- **처음 보는 말도 다루려고:** 처음 보는 단어도 아는 조각으로 쪼개서 각 조각의 숫자 묶음을 합쳐 다룰 수 있어요(1장 토큰).

!!! note "★ 한 걸음 더 (심화)"
    - 단어를 연속된 숫자 묶음으로 나타내는 아이디어는 transformer 이전에도 흔했어요. 2013년 Mikolov 외 연구진은 아주 큰 자료에서 단어의 벡터 표현을 효율적으로 계산하는 두 구조를 제안했고, 16억 단어 자료로 하루가 안 걸려 좋은 단어 벡터를 학습했다고 보고했어요(*word2vec*의 바탕이 된 논문).
    - 차원 수(12,288)는 모델이 정하는 설계 선택이에요. 3Blue1Brown 강의는 차원이 아주 많아야 서로 다른 방향이 많이 생겨서 유용하다고 설명해요.
    - 이미지나 소리도 비슷하게 숫자 묶음으로 바꿔 글과 같은 공간에서 다루는 방법이 있어요(4장 멀티모달).

## 직접 해보기

**계산 연습.** 위 숫자들이 얼마나 큰지 계산해 보세요.

1. 50,257 × 12,288은 얼마일까요? 계산기로 구해 보세요. (617,558,016이에요.)
2. 이 숫자가 모델 전체 파라미터 1,750억 개(GPT-3)의 몇 퍼센트쯤일까요? (약 0.35%예요. 첫 단계 하나가 이렇게 크지만 전체의 아주 작은 부분이에요.)

**연습 문제.** 아래 세 토큰 중 숫자 묶음이 서로 가장 가까울 것 같은 두 개를 골라 보세요: "고양이", "강아지", "냉장고". (정답은 확실하지 않지만, 고양이와 강아지일 가능성이 높아요. 다음 페이지에서 이유를 알아봐요.)

## 오늘 바로 써먹기

1. **핵심 단어는 정확하게 쓰세요.** 철자가 다르면 다른 토큰이 되어서 다른 숫자 묶음이 돼요. 고유명사는 특히 그래요.
2. **같은 뜻을 여러 표현으로 써 봐도 돼요.** 비슷한 뜻은 비슷한 숫자 묶음을 가지니 대체로 비슷한 답이 나와요.
3. **특이한 줄임말이나 은어는 풀어서 쓰세요.** 드문 표현은 조각이 많거나 뜻이 흐릿할 수 있어요.
4. **다른 언어로 물어봐도 같은 개념이 통하는 이유가 여기 있어요.** 하지만 언어마다 조각 수가 다를 수 있어요(1장).
5. **숫자 묶음 자체를 사람이 읽으려 하지 마세요.** 의미는 개별 숫자가 아니라 묶음 전체의 위치와 방향에 있어요.

## 자주 하는 오해

- "AI는 단어의 사전적 뜻을 저장한다" → 사전이 아니라 학습으로 정해진 숫자 묶음이에요.
- "숫자 묶음 한 줄이 뜻 하나를 뜻한다" → 개별 숫자가 아니라 묶음 전체의 위치가 뜻을 나타내요.
- "토큰 번호가 비슷하면 뜻도 비슷하다" → 번호는 순서대로 붙인 이름표일 뿐이에요. 가까워야 하는 건 숫자 묶음이에요.
