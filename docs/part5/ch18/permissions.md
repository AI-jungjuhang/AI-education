# 권한 모드와 안전장치

!!! abstract "이 페이지에서 배우는 것"
    - Claude가 **묻지 않고 해도 되는 일의 범위**가 권한 모드예요. 편함과 안전의 거래예요.
    - 처음에는 기본(Manual)과 계획 모드면 충분해요. 나머지는 이유가 있을 때 단계적으로 열어요.
    - `bypassPermissions`는 ==컨테이너나 가상 머신 안에서만== 쓰는 모드예요.

## 1. 자동차의 보조 장치

운전을 처음 배울 때는 속도를 낮추고 운전대를 꽉 잡죠. 익숙해지면 크루즈 컨트롤도 쓰지만, 고속도로의 안전한 구간에서만 켜요. 권한 모드가 이 보조 장치예요. 공식 문서도 각 모드를 "편리함과 감독 사이의 서로 다른 거래"라고 설명해요.

| 모드 | 묻지 않고 하는 것 | 어울리는 때 |
|---|---|---|
| 기본(Manual, 설정값은 `default`) | 읽기만 | 모든 일을 내가 확인하고 싶을 때, 민감한 작업 |
| `acceptEdits` | 읽기 + 파일 고치기 + 간단한 파일 명령(폴더 만들기, 옮기기, 복사) | 내가 결과를 검토하며 반복할 때 |
| `plan` | 읽기만 (계획 단계) | 바꾸기 전에 탐색할 때 |
| `auto` | 거의 모두, 단 백그라운드 안전 점검이 있어요 | 긴 작업에서 묻는 피로를 줄이고 싶을 때 |
| `dontAsk` | 미리 허락한 도구만, 나머지는 거절 | 잠가 둔 자동화(CI) |
| `bypassPermissions` | 모두 | 격리된 컨테이너·가상 머신 전용 |

모드는 대화 중 `Shift+Tab`으로 돌려가며 바꿀 수 있고(일부 모드는 순환에 나오지 않고 따로 시작해야 해요), 시작할 때는 `--permission-mode`로 정해요.

**내 대화가 어느 모드로 시작하는지 꼭 확인하세요.** 공식 문서에 따르면 터미널에서 새로 여는 대화는 Claude Code 2.1.283 이상에서 기본으로 `auto`로 시작해요(조직 설정이나 환경에 따라 다를 수 있고, 자동 모드를 못 쓰는 환경에서는 Manual로 시작해요). 반면 한 줄 모드(`claude -p`)는 기본(`default`)으로 시작해요. 상태 표시줄의 모드 이름을 보거나, 모든 일을 확인하고 싶다면 이렇게 시작해요.

```bash
claude --permission-mode default
```

## 2. 그 위에 얹는 규칙

모드는 기본 틀이고, 그 위에 **허락 규칙**을 얹어 특정 도구를 미리 허락하거나 막을 수 있어요. 공식 문서에 따르면 막기(deny) 규칙은 어떤 모드에서도 적용돼요. `/permissions`를 쓰면 허락·확인·거절 규칙을 한눈에 보고 고칠 수 있어요.

## 3. 어떤 모드로도 자동 승인되지 않는 것

공식 문서는 `bypassPermissions`에서도 승인되지 않는 일이 있다고 알려 줘요. 내가 "물어봐"로 정해 둔 도구, 사람의 확인이 꼭 필요한 도구, 중요한 경로의 삭제(`rm` 등)가 대표적이에요. 그리고 보호된 경로에 쓰는 일은 `bypassPermissions`가 아니면 자동으로 승인되지 않아요.

## 4. 우리의 선택

| 하는 일 | 모드 |
|---|---|
| 책 페이지 쓰기, 영상 만들기 | 기본 또는 `acceptEdits` (결과를 내가 검토하니까) |
| 큰 변경의 설계 | `plan` |
| 같은 일을 자동으로 반복하는 스크립트 | `dontAsk` + 필요한 도구만 허락 |
| `bypassPermissions` | 쓰지 않아요 |

!!! tip "10살 눈높이 한 줄 요약"
    권한 모드는 운전 보조 장치예요. 익숙한 길에서만, 하나씩 켜요.

!!! note "★ 한 걸음 더 (심화)"
    CI에서 쓰는 예로 공식 문서는 `claude -p "테스트를 실행해" --permission-mode dontAsk --allowedTools "Bash(npm test)" "Read"` 같은 정확한 허락 목록 방식을 보여 줘요. 격리 환경에서 완전 무인으로 돌릴 때만 `--dangerously-skip-permissions`를 쓰고, 컨테이너나 가상 머신 안에서, 가능하면 관리자가 아닌 사용자로 실행하라고 해요. 이 책에서는 이 마지막 방식을 다루지 않아요.

## 직접 해보기

1. `/permissions`를 열어 지금 내 허락·확인·거절 규칙을 읽어요. 모르는 규칙이 있으면 어디서 온 것인지 찾아봐요.
2. `Shift+Tab`을 눌러 상태 표시줄의 모드 이름이 바뀌는 것을 눈으로 확인해요. 가운데에서 멈추지 말고 처음 모드로 돌아와요.

## 오늘 바로 써먹기

- 처음 보는 폴더나 남의 저장소는 `--permission-mode default`로 시작하고 계획 모드로만 살펴보기
- `acceptEdits`는 내가 결과를 열어 볼 일에만 켜기
- `bypassPermissions` 설정이 내 설정 파일에 들어 있지 않은지 확인하기

## 자주 하는 오해

- "자동 모드면 안전하다?" 자동 모드에는 안전 점검이 있지만, 문서도 완벽한 시스템은 없다고 말해요. 중요한 일에서는 내가 확인해요.
- "권한 모드는 한 번 정하면 계속 간다?" 대화 중에도 바뀌고, 계획 승인으로도 바뀌어요. 지금 모드를 가끔 보는 습관이 필요해요.
