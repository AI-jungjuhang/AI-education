# 백그라운드와 예약 작업

!!! abstract "이 페이지에서 배우는 것"
    - 오래 걸리는 일은 ==내가 지켜보지 않아도 되게 뒤에서 돌릴 수 있어요.==
    - 같은 일을 시간마다 반복시키는 방법이 세 가지 있어요(`/loop`, 데스크톱 예약, 클라우드 예약).
    - 알아서 도는 만큼 **무엇을 허락했는지**가 더 중요해져요.

## 1. 로봇청소기와 타이머

로봇청소기를 돌려 놓고 학교에 가면 돌아왔을 때 집이 깨끗하죠. 매일 아침 7시에 켜지게 해 두면 시켜 놓지 않아도 돼요. 백그라운드 작업과 예약 작업이 이런 것들이에요.

## 2. 뒤에서 돌리기

`claude agents`를 입력하면 **에이전트 보기(agent view)** 가 열려요. 공식 문서 설명으로는 백그라운드로 돌고 있는 세션들을 한 화면에서 보여 주고, 지금 일하는 중인지, 내 입력을 기다리는지, 끝났는지를 알려 줘요. 새 세션을 보내 놓고 다른 일을 하다가 필요할 때 들어가서 이어 할 수 있어요. 아직 연구 미리보기라서 화면과 단축키가 바뀔 수 있다고 문서에 적혀 있어요.

## 3. 시간 맞춰 돌리기: 세 가지

| | `/loop` | 데스크톱 예약 | 클라우드 예약 |
|---|---|---|---|
| 어디서 도나 | 내 컴퓨터 | 내 컴퓨터 | 클라우드 |
| 컴퓨터가 켜져 있어야 하나 | 예 | 예 | 아니요 |
| 대화창이 열려 있어야 하나 | 예 | 아니요 | 아니요 |
| 내 컴퓨터의 파일 | 쓸 수 있어요 | 쓸 수 있어요 | 못 써요(새로 내려받은 사본) |

예를 들어 배포 상태를 5분마다 확인하게 하거나, 오래 걸리는 빌드가 끝났는지 가끔 보게 할 때 `/loop`를 써요. 대화창을 닫아도 계속 돌아야 하면 예약 작업을 써야 해요. `/loop`는 대화에 묶여 있어서, 대화를 다시 열 때 만료되지 않은 작업만 복원돼요.

## 4. 우리 채널에서는

- 책 페이지를 한 장 쓸 때마다 사이트 빌드를 돌리는 검사는 백그라운드로 보내고 나는 다음 페이지를 이어 쓰기
- 매주 월요일 아침에 "지난주 올린 영상에서 확인이 필요한 링크가 죽었는지" 점검하는 예약 작업 만들기(클라우드 예약은 새로 내려받은 사본에서 도니까 저장소만 있으면 돼요)

!!! tip "10살 눈높이 한 줄 요약"
    청소기는 돌려 놓고 학교에 가요. 타이머를 맞추면 매일 아침 알아서 돌아요.

!!! note "★ 한 걸음 더 (심화)"
    백그라운드에서 도는 세션에는 `bypassPermissions` 설정이 적용되지 않는 경우가 있다고 문서에 나와요(백그라운드 세션에서 무시됨). 즉 허락해 둔 범위 안에서만 돌려야 해요. 또 예약 작업이 쓰는 스킬이 내 컴퓨터의 `~/.claude/skills/`에만 있으면 클라우드 예약에서는 찾을 수 없어요. 클라우드 세션은 저장소에 든 설정만 쓰기 때문이에요(5.5의 스킬 위치 표 참고).

## 직접 해보기

1. `claude agents`를 입력해서 화면이 열리는지만 봐요. 처음에는 비어 있어요.
2. 연습용 폴더에서 "파일 10개의 이름을 훑어서 목록을 만들어 줘" 같은 작은 일 하나를 백그라운드로 보내 보고, 상태가 바뀌는 것을 지켜봐요.

## 오늘 바로 써먹기

- 5분 넘게 걸리는 일은 뒤로 보내고 다른 일 하기
- 예약 작업은 읽기 전용 일부터(링크 검사, 상태 확인)
- 예약 작업에는 "무엇을 하면 안 되는지"를 지시문에 먼저 쓰기

## 자주 하는 오해

- "예약하면 컴퓨터가 꺼져도 된다?" 방식에 따라 달라요. 위 표에서 내 방식이 컴퓨터를 켜 두어야 하는지 꼭 확인해요.
- "백그라운드니까 비용이 안 든다?" 백그라운드 세션도 같은 사용량 한도를 써요.
