# CLI로 자동화 파이프라인 만들기

!!! abstract "이 페이지에서 배우는 것"
    - `claude -p`를 **반복문**에 넣으면 여러 파일을 한꺼번에 점검하는 파이프라인이 돼요.
    - 자동화의 안전 세 가지: ==도구는 좁게 허락, 횟수·비용에 상한, 낯선 폴더는 읽지 않기==
    - 결과는 사람이 읽을 파일과 프로그램이 읽을 JSON, 두 가지로 받을 수 있어요.

## 1. 컨베이어 벨트에 반복문 얹기

5.4에서 `cat 파일 | claude -p "…"`로 파일 하나를 처리했어요. 파일이 100개라면? 반복문으로 한 줄을 100번 돌리면 돼요. 이게 가장 단순한 파이프라인이에요.

```bash
#!/bin/bash
# docs 폴더의 페이지마다 "10살이 어려워할 단어"를 찾아 out/ 폴더에 저장한다.
set -euo pipefail
mkdir -p out

for f in $(find docs -name '*.md' | sort); do
  name=$(echo "$f" | tr '/' '_')
  cat "$f" | claude --bare -p \
      "10살이 읽기에 어려운 단어를 목록으로만 알려 줘. 없으면 '없음'." \
      --allowedTools "Read" --max-turns 3 > "out/${name}.txt"
  echo "끝: $f"
done
```

이 스크립트의 반복 구조와 파일 저장은 가짜 `claude`로 돌려서 확인했어요. 실제 모델 호출은 내 계정으로 확인해 보세요.

한 줄씩 읽어요.

- `set -euo pipefail`: 중간에 문제가 생기면 멈추게 하는 안전 스위치예요.
- `--bare`: 내 설정이나 남의 훅·MCP를 읽지 않고 같은 조건으로 돌려요. 대신 구독 로그인이 아니라 `ANTHROPIC_API_KEY` 환경 변수가 필요해요.
- `--allowedTools "Read"`: 읽기만 허락해요. 쓰기나 명령 실행은 허락하지 않았어요.
- `--max-turns 3`: 한 번에 최대 3번까지만 움직여요(한 줄 모드 전용 상한이에요).

## 2. 기계가 읽을 결과로 받기

다른 프로그램이 읽어야 하면 JSON으로 받아요.

```bash
claude --bare -p "이 글에서 확인이 필요한 주장 목록" \
  --output-format json \
  --json-schema '{"type":"object","properties":{"claims":{"type":"array","items":{"type":"string"}}},"required":["claims"]}' \
  | jq '.structured_output'
```

`--json-schema`로 틀을 정하면 결과의 `structured_output` 칸에 그 틀대로 담겨요. 다만 모델이 요청을 거절한 경우처럼 틀이 안 채워질 수도 있으니, 쓰기 전에 그 칸이 있는지 확인하라고 공식 문서가 알려 줘요. 비용 상한이 필요하면 `--max-budget-usd`도 있어요(한 줄 모드 전용이고, 클라이언트 쪽 비용 추정으로 확인해요).

## 3. 자동화 안전 세 가지

1. **좁게 허락**: 읽기만 필요하면 `Read`만 줘요. 쓰기가 필요하면 쓸 폴더를 정해요.
2. **상한 두기**: `--max-turns`와 `--max-budget-usd`로 폭주를 막아요.
3. **낯선 폴더는 읽지 않기**: 남의 저장소에서는 `--bare`로 시작하거나 훅을 꺼요(5.6, 5.5의 안전 페이지).

그리고 이 파이프라인에 비밀번호나 개인정보가 든 파일이 섞이지 않게 입력 폴더를 정해요. 보낸 내용은 AI 서비스로 전송돼요.

!!! tip "10살 눈높이 한 줄 요약"
    한 줄 명령을 반복문에 넣으면 컨베이어 벨트가 돼요. 안전은 "좁게, 상한 두고, 낯선 곳은 안 읽기"예요.

!!! note "★ 한 걸음 더 (심화)"
    CI(자동 검사 서버)에서는 `--permission-mode dontAsk`와 `--allowedTools`로 정확한 허락 목록만 두는 방식이 공식 문서의 대표 예시예요. 또 한 줄 모드에서도 프롬프트에 `/스킬이름`을 넣으면 내가 부르는 스킬이 펼쳐져서 실행돼요(공식 문서 기준, 터미널에서 여러 스킬을 겹쳐 쓰는 것과 달리 한 줄 모드에서는 첫 스킬만 불러와요). 다만 `--bare`는 스킬을 자동으로 찾지 않으니, 플러그인은 `--plugin-dir`로 따로 불러야 하고 그 플러그인의 훅은 `--bare`에서 실행되지 않아요.

## 직접 해보기

1. 연습용 폴더에 마크다운 파일 두 개를 만들어요.
2. 위 반복문 스크립트를 파일로 저장하고 `bash -n 스크립트.sh`로 문법만 먼저 확인해요.
3. `ANTHROPIC_API_KEY`가 설정된 환경이라면 실제로 돌려 보고, `out/` 폴더의 결과를 읽어요. 키가 없다면 `--bare`를 빼고 돌려 볼 수 있지만, 이때는 내 설정과 훅이 읽힌다는 점을 기억해요.

## 오늘 바로 써먹기

- 같은 점검을 파일 열 개 이상에 한다면 반복문으로 만들기
- 결과 파일 이름에 원본 경로를 넣어 나중에 찾기 쉽게 하기
- 돌리기 전에 입력 폴더에 비밀 파일이 없는지 확인하기

## 자주 하는 오해

- "자동화 = 사람이 필요 없다?" 결과를 읽고 판단하는 일은 여전히 내 몫이에요. 자동화는 읽을 거리를 만드는 일이에요.
- "한 줄 모드는 대화 모드와 똑같이 동작한다?" 허락, 믿음 확인, 기억 불러오기가 달라요. 5.4와 5.5의 안전 페이지를 다시 읽어 봐요.
