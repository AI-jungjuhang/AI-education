# 대화 모드와 한 줄 모드

!!! abstract "이 페이지에서 배우는 것"
    - `claude`는 주고받는 **대화 모드**, `claude -p "질문"`은 답만 받고 끝나는 **한 줄 모드**예요.
    - 한 줄 모드는 ==사람 없이도 돌아가서 자동화의 문==이 돼요.
    - 이어 하기(`-c`)와 다시 열기(`-r`)로 어제 하던 대화를 이어 갈 수 있어요.

## 1. 식당 vs 자판기

대화 모드는 식당이에요. 주문하고, 메뉴를 바꾸고, 주방장과 이야기를 주고받아요. 한 줄 모드는 자판기예요. 버튼 한 번 누르면 음료가 나오고 끝나요. 사람이 옆에서 지켜볼 필요가 없죠.

| 하고 싶은 일 | 명령 |
|---|---|
| 대화 시작 | `claude` |
| 첫 질문을 넣고 대화 시작 | `claude "이 프로젝트를 설명해 줘"` |
| 답만 받고 끝내기 | `claude -p "이 함수를 설명해 줘"` |
| 가장 최근 대화 이어 가기 | `claude -c` |
| 이름이나 번호로 대화 다시 열기 | `claude -r "이름" "마저 해 줘"` |
| 버전 확인 | `claude -v` |

대화 모드에서 `/resume`을 쳐도 지난 대화를 고를 수 있어요.

## 2. 모델과 폴더 고르기

실행할 때 몇 가지를 정할 수 있어요.

```bash
claude --model sonnet               # 이번 대화에서 쓸 모델
claude --add-dir ../다른폴더         # 읽고 고칠 폴더를 하나 더
claude --permission-mode plan        # 먼저 계획만 세우는 모드로 시작
```

`--add-dir`로 폴더를 더하면 그 폴더의 파일을 읽고 고칠 수 있는 권한이 생겨요. 믿을 수 있는 폴더만 더해요. 권한 모드는 5C에서 자세히 다뤄요.

!!! tip "10살 눈높이 한 줄 요약"
    `claude`는 식당, `claude -p`는 자판기. 자판기는 혼자서도 돌아가요.

!!! note "★ 한 걸음 더 (심화)"
    한 줄 모드를 자동화에 쓸 때는 `--bare`를 붙이면 시작이 빨라져요. 훅, 스킬, 플러그인, MCP 서버, CLAUDE.md 같은 자동 불러오기를 건너뛰기 때문이에요. 공식 문서는 스크립트에서는 `--bare`를 권하고, 앞으로 `-p`의 기본값이 될 예정이라고 해요. 반대로 `--bare` 없이 `-p`를 쓰면 프로젝트의 훅과 MCP 설정이 그대로 실행되니, 처음 보는 폴더에서는 주의해야 해요(5.6, 5.7에서 다시 다뤄요).

## 직접 해보기

1. `claude -p "1부터 5까지 더하면 얼마야? 숫자만 답해"`를 실행해요. 답이 한 줄 나오고 프로그램이 끝나는 것을 확인해요.
2. `claude`를 열고 아무 질문을 한 뒤 `/exit`로 나와요.
3. `claude -c`로 방금 대화를 이어 열어요.

## 오늘 바로 써먹기

- 한 번 묻고 끝나는 질문은 `claude -p`로 하기. 창을 열고 닫을 필요가 없어요.
- 어제 하던 일은 `claude -c`로 이어서 하기. 처음부터 설명하지 않아도 돼요.
- 이름을 붙여 둔 대화는 `claude -r "이름"`으로 열기

## 자주 하는 오해

- "한 줄 모드는 더 약한 AI다?" 아니에요. 같은 AI가 대화 없이 일하는 방식일 뿐이에요.
- "`-c`는 어제 일을 다 기억한다?" 이어 열린 대화의 기록은 남아 있지만, 새 대화에서는 5.2의 메모(CLAUDE.md)가 읽히는 것은 같아요.
