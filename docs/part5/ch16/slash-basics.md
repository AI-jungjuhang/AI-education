# 자주 쓰는 슬래시 명령

!!! abstract "이 페이지에서 배우는 것"
    - Claude Code에서 `/`로 시작하는 말은 ==채팅이 아니라 단축 버튼==이에요.
    - 처음에는 일곱 개만 알아도 충분해요: `/help` `/clear` `/compact` `/context` `/model` `/init` `/rewind`
    - 명령 목록은 자주 바뀌니, 외우지 말고 `/help`로 찾는 습관을 들여요.

## 1. 슬래시는 리모컨 버튼

TV 리모컨을 떠올려 봐요. "볼륨을 올려 주세요"라고 말하는 대신 버튼 하나를 누르면 되죠. Claude Code에서 `/`로 시작하는 말이 바로 그 버튼이에요. 대화창에 `/`만 쳐도 쓸 수 있는 목록이 뜨고, 글자를 더 치면 목록이 줄어들어요.

버튼은 두 종류예요.

- **내장 명령**: Claude Code가 처음부터 가지고 있는 버튼. `/help`, `/clear` 같은 것들이에요.
- **내가 만든 명령**: 내가 자주 시키는 말을 버튼으로 만든 것. 다음 페이지에서 만들어 봐요.

## 2. 처음에 쓸 일곱 개

| 명령 | 하는 일 | 언제 쓰나요 |
|---|---|---|
| `/help` | 도움말과 명령 목록을 보여 줘요 | 뭘 눌러야 할지 모를 때 |
| `/clear` | 빈 대화를 새로 시작해요 | 이야기가 완전히 바뀔 때 |
| `/compact` | 지금까지의 대화를 요약해서 자리를 비워요 | 대화가 길어졌지만 이어 가고 싶을 때 |
| `/context` | 기억 공간을 얼마나 썼는지 색칠된 칸으로 보여 줘요 | 답이 엉뚱해지기 시작할 때 |
| `/model` | 쓸 AI 모델을 바꿔요 | 더 빠른 것, 더 똑똑한 것을 고르고 싶을 때 |
| `/init` | 이 폴더용 `CLAUDE.md` 메모를 만들어 줘요 | 새 프로젝트를 처음 열었을 때 |
| `/rewind` | 대화나 파일을 이전 시점으로 되돌려요 | 실수했을 때(5.3에서 자세히) |

`/clear`와 `/compact`는 비슷해 보이지만 달라요. `/clear`는 ==칠판을 지우고 새로 시작==하는 것이고, `/compact`는 ==칠판 내용을 공책 한 장으로 요약하고 이어서 쓰는 것==이에요. 3장에서 배웠듯 AI의 기억 공간(컨텍스트 창)은 한계가 있어서 이 둘이 필요해요.

!!! tip "10살 눈높이 한 줄 요약"
    슬래시 명령은 말로 길게 시킬 필요 없이 누르는 리모컨 버튼이에요.

!!! note "★ 한 걸음 더 (심화)"
    일부 명령은 사실 "번들 스킬"이에요. 예를 들어 `/doctor`(설정 점검)나 `/batch`(큰 변경을 여러 조각으로 나눠 동시에 처리)는 명령 모양을 한 스킬이어서, 내장 코드가 아니라 프롬프트와 절차로 움직여요. 스킬은 5.5에서 다뤄요. 또 일부 명령은 특정 버전 이상에서만 있어요. 같은 이름을 쳤는데 "Unknown command"가 나오면 버전부터 확인해요(`claude --version`).

## 직접 해보기

2분이면 끝나요.

1. 터미널에서 `claude`를 실행해요.
2. `/help`를 쳐서 목록을 훑어봐요.
3. `/context`를 쳐서 지금 기억 공간을 얼마나 썼는지 봐요. 방금 연 대화인데도 이미 조금 차 있을 거예요. 기본 안내문과 도구 설명이 먼저 들어가 있기 때문이에요.
4. `/model`을 쳐서 지금 쓰는 모델 이름만 확인하고 닫아요.

## 오늘 바로 써먹기

- 대화가 길어져서 답이 흐려지면 `/context`로 먼저 보고, 이어 갈 일이면 `/compact`, 새 일이면 `/clear` 하기
- `/compact`에는 요약 방향을 같이 적을 수 있어요.

```text
/compact 지금 만들고 있는 스킬의 결정 사항과 남은 할 일만 남겨 줘
```

- 이름이 기억나지 않으면 `/`만 치고 글자를 하나씩 더해 찾기

## 자주 하는 오해

- "`/clear`하면 만든 파일도 지워진다?" 아니에요. 지워지는 건 대화이고, 이미 저장된 파일은 그대로예요.
- "명령은 모두 AI가 처리한다?" 아니에요. `/help`나 `/context`처럼 AI에게 묻지 않고 프로그램이 바로 보여 주는 명령도 많아요.
