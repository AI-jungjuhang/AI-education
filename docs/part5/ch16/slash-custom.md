# 내 단축 명령 만들기

!!! abstract "이 페이지에서 배우는 것"
    - 자주 시키는 말은 ==파일 하나로 저장해서 `/이름`으로 부를 수 있어요.==
    - 지금은 "명령"이 **스킬**과 합쳐졌어요. 만드는 법은 하나이고, 폴더 이름이 곧 명령 이름이에요.
    - 같은 말을 세 번 이상 쳤다면 버튼으로 만들 때예요.

## 1. 같은 부탁을 매번 치고 있다면

영상 대본을 쓰고 나면 늘 이렇게 부탁하고 있을 수 있어요. "초등학생도 알아듣게 고쳐 줘. 어려운 단어는 비유 하나로 풀어 줘. 문장은 짧게." 매번 치기 귀찮고, 어느 날은 빼먹기도 하죠. 이 부탁을 파일에 적어 두고 `/easy`처럼 이름을 붙이면 한 번에 불러낼 수 있어요.

## 2. 옛 방식과 새 방식

옛날에는 `.claude/commands/` 폴더에 파일을 두면 명령이 됐어요. 지금 공식 문서는 이 방식이 스킬로 합쳐졌다고 설명해요. 두 가지 모두 같은 `/이름` 명령을 만들고, 이전 방식의 파일도 계속 동작해요. 새로 만들 때는 스킬 방식을 권해요. 폴더 안에 참고 파일을 더 넣을 수 있고, 누가 부를 수 있는지 정하는 설정도 있기 때문이에요.

## 3. 직접 만들어 보기: /easy

내 컴퓨터 어디서나 쓸 수 있는 "개인 스킬"로 만들어 봐요. 폴더는 `~/.claude/skills/` 아래에 만들어요.

```bash
mkdir -p ~/.claude/skills/easy
```

그 폴더 안에 `SKILL.md` 파일을 이렇게 써요.

```markdown
---
description: 어려운 글을 10살도 알아듣게 고칠 때 쓴다.
disable-model-invocation: true
---

아래 글을 10살이 알아듣게 고쳐 줘. $ARGUMENTS

- 어려운 말은 처음 나올 때 비유 하나로 풀기
- 문장은 짧게, "~예요" 말투
- 사실은 바꾸지 말고, 모르는 것은 모른다고 쓰기
```

위쪽 `---` 사이는 "이 스킬이 뭔지"를 적는 칸이에요. 아래는 Claude가 따를 지시문이에요.

- `$ARGUMENTS`는 명령 뒤에 내가 적은 말로 바뀌어요. `/easy 토큰이 뭔지 설명한 글`처럼 부르면 그 말이 들어가요.
- `disable-model-invocation: true`는 "내가 부를 때만 실행해"라는 뜻이에요. 이걸 안 쓰면 Claude가 설명을 읽고 알아서 부를 수도 있어요. 실행 시점을 내가 정하고 싶은 작업에는 켜 두는 게 안전해요.

저장하고 Claude Code를 열어 `/easy`를 입력하면 목록에 보여요. 파일을 고치면 실행 중에도 바로 반영돼요(이미 불러온 내용은 대화에 남아 있어요).

!!! tip "10살 눈높이 한 줄 요약"
    자주 하는 부탁을 폴더 하나에 적어 두면, 이름 하나로 불러낼 수 있어요.

!!! note "★ 한 걸음 더 (심화)"
    스킬은 놓인 곳에 따라 쓸 수 있는 범위가 달라요. 개인 폴더(`~/.claude/skills/`)는 내 모든 프로젝트에서, 프로젝트 폴더(`.claude/skills/`)는 그 저장소에서 쓰이고 저장소에 넣으면 팀과 나눌 수 있어요. 같은 이름이 둘 다 있으면 개인 것이 우선이에요. 그리고 `$0`, `$1`처럼 위치로 여러 값을 따로 받을 수도 있어요. 자세한 구조는 5.5에서 다뤄요.

## 직접 해보기

위의 `/easy`를 만들고 어려운 문단 하나를 넣어 봐요. 결과가 마음에 들지 않으면 `SKILL.md`의 지시문을 한 줄 고치고 다시 불러서 달라지는지 봐요. 지시문을 고치며 결과를 바꿔 보는 경험이 이 페이지의 진짜 공부예요.

## 오늘 바로 써먹기

- 같은 부탁을 세 번 이상 쳤다면 파일로 만들기
- 이름은 짧게 짓기(영어 소문자와 하이픈이 가장 안전해요): `/easy`, `/summary`, `/check`
- 지시문에는 "무엇을, 어떤 모양으로, 하지 말 것"을 한 줄씩 쓰기

## 자주 하는 오해

- "명령을 만들려면 프로그래밍을 해야 한다?" 아니에요. 말로 쓴 지시문이 전부예요.
- "만들어 두면 항상 지켜진다?" 스킬은 지시문일 뿐이라 가끔 어긋나요. 꼭 지켜야 하는 일은 5.6의 훅으로 막아요.
