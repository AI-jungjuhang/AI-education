# 실습: 영상 한 편 만들기 스킬

!!! abstract "이 페이지에서 배우는 것"
    - 책 한 페이지를 쇼츠 영상으로 만드는 **우리 채널의 반복 작업**을 스킬로 묶어 봐요.
    - 스킬은 코드가 아니라 ==순서와 기준을 적은 글==이에요. 그래서 내가 직접 쓸 수 있어요.
    - 이 스킬이 5.8의 에이전트와 5.10의 슈퍼 스킬로 자라나요.

## 1. 반복 작업을 찾기

우리 채널은 한 편을 만들 때마다 같은 흐름을 따라가요. 책 페이지를 읽고, 장면표를 쓰고, 화면을 만들고, 렌더링하고, 점검해요. 이 흐름은 이미 이 저장소의 `.claude/skills/video-script/SKILL.md`에 적혀 있어요. 이 페이지에서는 같은 일을 하는 작은 스킬을 처음부터 직접 만들어 봐요.

## 2. 만드는 순서

폴더를 만들어요(프로젝트 안에 두면 저장소와 함께 나눌 수 있어요).

```bash
mkdir -p .claude/skills/make-short
```

`.claude/skills/make-short/SKILL.md`에 이렇게 써요.

```markdown
---
name: make-short
description: 책 페이지 하나를 60초 이내 세로 쇼츠 대본으로 바꿀 때 쓴다. "영상으로 만들어 줘", "쇼츠 대본" 같은 말에 쓴다.
disable-model-invocation: true
argument-hint: [페이지 경로]
---

대상 페이지: $ARGUMENTS

1. 대상 페이지와 CLAUDE.md를 읽고, 페이지에서 **한 가지 생각**과
   **끝에 남길 행동** 하나를 고른다.
2. 장면표를 쓴다. 장면마다 "원본 페이지의 어느 부분인지"를 적는다.
3. 원본에 없는 말은 넣지 않는다. 지어낸 숫자는 화면에 "예시"라고 쓴다.
4. 한 화면의 글은 35자 이하. 처음 5초 안에 무엇을 알게 되는지 보여 준다.
5. 끝에는 행동 하나, 다음 편 예고, "프로필 링크에서 보기"를 넣는다. 주소는 쓰지 않는다.
6. 결과는 video/shorts/ 아래 새 폴더의 script.md로 저장하고, 쓰지 않은 것(확인 못 한 것)이 있으면 맨 아래에 적는다.
```

핵심은 세 가지예요.

- `disable-model-invocation: true`: 영상 만들기는 시간이 걸리고 파일이 생기는 일이에요. 내가 부를 때만 실행되게 해요.
- `$ARGUMENTS`: `/make-short docs/part1/ch01/next-word.md`처럼 페이지를 인자로 넘겨요.
- 번호 매긴 절차: 순서가 있는 일은 번호로 쓰면 빠뜨리지 않아요.

## 3. 쓰고 나서 고치기

`/make-short docs/part1/ch01/next-word.md`를 실행해서 나온 대본을 읽어 봐요. 마음에 안 드는 부분이 보이면 스킬 파일의 해당 줄을 고쳐요. 예를 들어 첫 장면이 밋밋하면 "첫 화면은 질문 한 줄로 시작한다"를 추가해요. 이렇게 **결과를 보고 지시문을 고치는 것**이 스킬을 키우는 방법이에요.

!!! tip "10살 눈높이 한 줄 요약"
    반복되는 일의 순서와 기준을 글로 적어 두면, 이름 하나로 불러서 그대로 시킬 수 있어요.

!!! note "★ 한 걸음 더 (심화)"
    이 저장소의 실제 `video-script` 스킬은 대본뿐 아니라 렌더링과 점검까지 안내하고, 템플릿 파일과 빌드 스크립트를 폴더 안에 함께 둬요. 스킬 폴더 안의 스크립트는 스킬이 필요할 때 읽거나 실행하는 보조 파일이에요. 처음에는 위처럼 글만으로 시작하고, 반복해서 쓰게 되면 스크립트와 템플릿을 하나씩 더해요.

## 직접 해보기

1. 위 스킬을 만들어요.
2. 이 책의 아무 페이지로 실행해요.
3. 나온 장면표에서 "원본에 없는 말"이 있는지 찾아봐요. 있으면 그 줄을 지시문에 금지 사항으로 보태요.

## 오늘 바로 써먹기

- "이 일을 또 하게 될까?"가 "예"라면 스킬로 만들기
- 처음부터 완벽하게 쓰지 않고, 첫 버전은 5줄이면 충분해요. 쓰면서 고쳐요.
- 결과물이 파일로 남는 스킬은 어디에 저장할지도 지시문에 적기

## 자주 하는 오해

- "스킬을 쓰면 결과가 항상 같다?" 지시문이 같아도 AI의 답은 달라질 수 있어요(1.1.1에서 배운 것처럼). 그래서 점검 단계가 필요해요.
- "스킬이 영상을 직접 만든다?" 위 스킬은 대본까지만 만들어요. 렌더링 같은 일은 스크립트와 도구가 붙어야 해요.
