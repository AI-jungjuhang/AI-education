# 일을 나눠 맡기는 서브에이전트

!!! abstract "이 페이지에서 배우는 것"
    - 서브에이전트는 ==자기만의 작업 공간(컨텍스트)을 가진 조수 AI==예요. 일을 하고 **요약만** 돌려줘요.
    - 책상이 어질러지지 않으니 내 대화가 길어지지 않아요.
    - 기본으로 들어 있는 조수(Explore, Plan)와, 내가 만드는 조수의 차이를 알아요.

## 1. 심부름꾼 친구

시험 공부를 하는데 도서관에서 자료 열 권을 뒤져야 한다고 해 봐요. 내가 직접 가면 내 책상이 책으로 가득 차요. 친구에게 "관련된 부분만 세 줄로 정리해 와"라고 부탁하면 책상은 그대로고 정리본만 받아요. 서브에이전트가 이 친구예요. 공식 문서도 "검색 결과, 로그, 파일 내용처럼 다시 안 볼 내용이 대화를 어지럽힐 때 서브에이전트를 쓰라"고 설명해요.

서브에이전트는 이런 특징이 있어요.

- 자기만의 기억 공간, 자기만의 지시문, 자기만의 도구 목록과 권한을 가져요.
- 일을 마치면 결과의 요약만 내 대화로 돌아와요.
- 도구를 제한할 수 있어요. 읽기만 하는 조수를 만들 수 있어요.
- 더 가볍고 싼 모델(예: Haiku)에게 맡겨 비용을 아낄 수도 있어요.

## 2. 이미 들어 있는 조수

Claude Code에는 기본 조수가 있고, Claude가 필요할 때 알아서 써요.

| 이름 | 하는 일 | 특징 |
|---|---|---|
| Explore | 파일을 찾고 코드를 훑어 읽기 | 읽기 전용(쓰기·고치기 금지) |
| Plan | 계획 모드에서 자료를 모으기 | 읽기 전용 |

두 조수는 속도를 위해 CLAUDE.md를 읽지 않고 시작해요. 내가 만든 조수는 기본으로 CLAUDE.md를 읽어요.

## 3. 내가 만드는 법

조수는 **마크다운 파일 하나**예요. 위쪽 이름표에 이름과 설명을 쓰고, 아래에 그 조수의 지시문을 써요. `name`과 `description`만 꼭 필요해요. 예를 들어 이렇게 생겼어요.

```markdown
---
name: code-improver
description: 파일을 읽고 읽기 쉽게 고칠 점을 제안한다. 코드를 쓰거나 고친 뒤에 쓴다.
tools: Read, Grep, Glob
model: sonnet
---

당신은 코드 개선 전문가입니다. 문제마다 이유를 설명하고, 지금 코드와 개선한 코드를 보여 주세요.
```

파일을 `~/.claude/agents/`에 두면 내 모든 프로젝트에서, 프로젝트의 `.claude/agents/`에 두면 그 프로젝트에서 써요. 새 조수는 Claude에게 만들어 달라고 말해도 돼요. 만든 뒤에는 이렇게 불러요.

```text
code-improver 에이전트로 이 프로젝트에서 고칠 점을 찾아 줘
```

!!! tip "10살 눈높이 한 줄 요약"
    서브에이전트는 심부름꾼 친구예요. 내 책상을 어지르지 않고 정리본만 가져와요.

!!! note "★ 한 걸음 더 (심화)"
    조수에게는 `maxTurns`(최대 몇 번 일하고 멈출지), `skills`(미리 읽힐 스킬), `isolation: worktree`(따로 복사한 작업 폴더에서 일하게 하기) 같은 칸도 있어요. 칸 이름은 camelCase(대소문자 섞어 쓰기)로 글자 하나까지 맞아야 하고, 틀리면 조용히 무시돼요. 또 조수는 기본적으로 다른 조수를 부를 수도 있지만 깊이에 제한이 있어요.

## 직접 해보기

1. Claude Code에서 "Explore 조수를 써서 이 폴더에 어떤 파일들이 있는지 훑어 줘"라고 시켜 봐요.
2. 대화 기록에 조수 이름이 한 줄로 보이는지 확인해요.
3. `~/.claude/agents/` 폴더가 이미 있다면 안의 파일 이름을 훑어 봐요.

## 오늘 바로 써먹기

- 내 대화에 긴 검색 결과나 로그가 쌓이기 시작하면 "서브에이전트를 써서 요약만 알려 줘"라고 말하기
- 조수의 `description`은 짧게. 조수들의 설명이 합쳐서 너무 길면 시작할 때 경고가 떠요.
- 조수가 파일을 바꾸게 하기 전에 먼저 커밋하기. 서브에이전트가 고친 파일은 5.3의 되돌리기가 대부분 되돌리지 못해요.

## 자주 하는 오해

- "조수는 공짜다?" 아니에요. 조수도 자기 요청을 보내서 같은 사용량 한도를 써요. 여러 조수를 동시에 돌리면 사용량이 늘어요.
- "조수가 많을수록 좋다?" 아니에요. 서로 이어져야 하거나 오가며 다듬는 일은 메인 대화에서 하는 편이 나아요.
