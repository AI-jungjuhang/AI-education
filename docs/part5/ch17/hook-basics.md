# 특정 순간에 자동으로 실행하기: 훅

!!! abstract "이 페이지에서 배우는 것"
    - 훅은 "Claude가 ○○할 때 ==내가 정해 둔 프로그램을 AI의 판단 없이 실행==하라"는 약속이에요.
    - 스킬과 메모는 AI가 따를지 말지 고르지만, 훅은 약속한 순간이 오면 **AI의 판단 없이** 실행돼요(설정이 맞고 꺼 두지 않았다면요).
    - 자주 쓰는 순간(이벤트) 네 개와 설정 파일의 위치를 알아요.

## 1. 현관 센서등

현관에 센서등이 있으면 누가 오든 불이 켜지죠. 사람이 "불 켜는 거 잊지 마"라고 말해 둔 것과는 달라요. 훅이 바로 센서등이에요. 공식 문서도 훅을 "정해진 순간에 무조건 일어나는 일을, AI의 판단에 맡기지 않고 보장하는 방법"이라고 설명해요. CLAUDE.md의 규칙은 참고 자료로 읽혀서 어길 수 있지만, 훅은 어길 수 없어요.

## 2. 자주 쓰는 네 가지 순간

| 순간(이벤트) | 언제 | 쓰임새 |
|---|---|---|
| `PreToolUse` | 도구를 쓰기 **직전** | 위험한 일 막기 |
| `PostToolUse` | 도구를 쓴 **직후** | 검사, 자동 정리 |
| `Notification` | Claude가 내 입력을 기다릴 때 | 알림 보내기 |
| `SessionStart` | 대화를 시작하거나 이어 열 때 | 필요한 정보 미리 넣기 |

그 밖에 `Stop`(Claude가 답을 마쳤을 때), `PreCompact`(요약 직전) 등 이벤트가 많아요. 전체 목록은 공식 문서의 훅 레퍼런스에 있어요.

## 3. 설정은 어디에 쓰나

설정 파일의 `hooks` 칸에 써요. 위치에 따라 범위가 달라요.

| 위치 | 범위 |
|---|---|
| `~/.claude/settings.json` | 내 모든 프로젝트 |
| `.claude/settings.json` | 이 프로젝트(저장소에 올려 나눌 수 있어요) |
| `.claude/settings.local.json` | 이 프로젝트, 나만 |

예를 들어 Claude가 입력을 기다릴 때 알림을 받는 훅(맥 기준)은 이래요.

```json
{
  "hooks": {
    "Notification": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "osascript -e 'display notification \"Claude Code needs your attention\" with title \"Claude Code\"'"
          }
        ]
      }
    ]
  }
}
```

`matcher`는 "어떤 경우에만"을 고르는 필터예요. 무엇을 거르는지는 이벤트마다 달라요. `PreToolUse`와 `PostToolUse`는 도구 이름(예: `Edit|Write`), `Notification`은 알림 종류, `SessionStart`는 대화가 시작된 방식(시작·이어 열기·비우기 등)을 걸러요. 비워 두면 모든 경우에 실행돼요. 설정한 뒤 `/hooks`를 입력하면 등록된 훅 목록을 볼 수 있어요. 목록에 없으면 설정 파일의 괄호와 쉼표부터 확인해요.

!!! tip "10살 눈높이 한 줄 요약"
    훅은 센서등이에요. 사람이 부탁하지 않아도 약속한 순간에 켜져요.

!!! note "★ 한 걸음 더 (심화)"
    훅은 셸 명령 말고도 종류가 있어요. AI가 판단하는 프롬프트 훅, 에이전트 훅, 주소로 신호를 보내는 HTTP 훅이에요. 판단이 필요한 검사에는 AI 훅을, 규칙이 분명한 검사에는 명령 훅을 쓰면 돼요. 이 책에서는 명령 훅 하나만 써 봐요.

## 직접 해보기

위의 `Notification` 훅을 `~/.claude/settings.json`에 넣어요(맥이 아니면 공식 문서의 리눅스·윈도 명령으로 바꿔요). 그다음 `/hooks`로 목록에 보이는지 확인하고, Claude에게 권한이 필요한 일을 시킨 뒤 다른 창으로 가서 알림이 오는지 기다려요. 알림이 오지 않으면 설정 파일의 괄호와 쉼표가 맞는지, 운영체제용 명령이 맞는지부터 확인해요.

## 오늘 바로 써먹기

- "꼭 해야 하는 일"은 메모가 아니라 훅으로 만들기
- 훅은 처음에는 알림처럼 해가 없는 것부터 달기
- 훅을 단 뒤에는 항상 `/hooks`로 확인하기

## 자주 하는 오해

- "훅은 AI가 하는 일이다?" 아니에요. 내 컴퓨터가 실행하는 프로그램이에요. 그래서 5.6의 마지막 페이지에서 안전 수칙을 따로 다뤄요.
- "훅을 달면 Claude가 더 똑똑해진다?" 똑똑해지는 게 아니라 약속이 지켜져요.
