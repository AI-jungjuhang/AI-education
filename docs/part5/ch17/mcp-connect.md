# 실습: 외부 서비스 연결하기

!!! abstract "이 페이지에서 배우는 것"
    - 한 줄 명령으로 원격 서버를 연결하고, `/mcp`에서 **로그인(OAuth)** 으로 허락해요.
    - 연결한 뒤 Claude에게 "읽기만" 시켜서 확인하는 순서를 익혀요.
    - 예시는 노션이에요. 다른 서비스도 같은 틀이에요.

## 1. 준비물

- Claude Code (2.1.319 기준으로 확인)
- 연결해 볼 서비스 계정. 여기서는 노션을 예로 들지만, **중요한 문서가 든 계정이 아닌 연습용 페이지나 작업공간**을 쓰는 것이 안전해요.

## 2. 연결하기

공식 문서의 원격 HTTP 서버 연결 틀과 노션 예시는 이래요.

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

- `--transport http`: 원격 서버로 연결해요.
- `notion`: 내가 붙이는 이름이에요.
- 마지막은 서버 주소예요.

`Added …` 같은 줄이 나오면 설정이 저장된 거예요. 이 상태에서는 아직 **로그인 전**이에요.

## 3. 로그인(허락)하기

Claude Code를 열고 `/mcp`를 입력해요. 목록에서 `notion`을 고르면 인증이 필요하다고 나오고, 브라우저가 열려서 로그인과 접근 허락 창이 나와요. 허락 창에서 서비스가 보여 주는 접근 범위를 꼼꼼히 읽고, 고를 수 있는 범위는 최소로 고르세요. 다만 노션 같은 서비스의 MCP 연결은 "페이지 하나만"처럼 좁게 제한되지 않고 내 계정이 볼 수 있는 내용에 닿을 수 있어요(서비스마다 다르고, 이 책은 노션의 범위를 직접 확인하지 못했어요). 그래서 **중요한 문서가 없는 별도의 연습용 계정이나 작업공간**을 쓰는 것이 가장 안전해요.

공식 문서에 따르면 서버가 `401`이나 `403`으로 답하면 Claude Code가 "인증 필요"로 표시해요. 로그인이 끝나면 `/mcp`에서 상태가 연결됨으로 바뀌어요. 서버를 지우면(`claude mcp remove notion`) 저장된 로그인 정보도 같이 지워지지만, 발급한 쪽의 토큰이 자동으로 폐기되는 것은 아니라는 점은 다음 페이지에서 다뤄요.

## 4. 읽기만 시켜서 확인하기

```text
노션에서 '연습' 페이지의 제목과 첫 단락만 읽어서 알려 줘. 아무것도 고치지는 마.
```

대답이 나오면 연결 성공이에요. "읽기만"이라고 부탁해도 이것이 쓰기를 막아 주지는 않아요. 쓰기를 막으려면 서비스에서 읽기 전용 권한으로 연결하거나, Claude Code의 권한 규칙(5.9)으로 쓰기 도구를 막아야 해요. 권한 창이 뜨면 읽고, 원하지 않은 쓰기는 거절해요. 모드나 이미 해 둔 승인에 따라 창이 뜨지 않을 수도 있어요.

!!! tip "10살 눈높이 한 줄 요약"
    연결 한 줄, 로그인 한 번, 읽기 시험 한 번. 이 순서로 하면 안전해요.

!!! note "★ 한 걸음 더 (심화)"
    같은 서버를 팀이 함께 쓰려면 프로젝트 범위(`--scope project`)로 `.mcp.json`에 저장해요. 이때 다른 사람이 받은 저장소의 `.mcp.json`은 처음 연결할 때 Claude Code가 허락을 물어봐요. 하지만 `claude -p`로 실행하면 묻지 않고 연결돼요(5.5 안전 페이지 참고). 그래서 `.mcp.json`도 읽고 믿어야 해요.

## 직접 해보기

1. 연습용 서비스 계정이나 작업공간을 준비해요.
2. 위의 연결 명령을 실행하고 `/mcp`에서 로그인해요.
3. "읽기만" 시험을 해 보고, 성공하면 `/mcp`에서 연결 상태를 확인해요.
4. 다 쓴 뒤에는 `claude mcp remove notion`으로 끊고, 서비스 쪽 설정에서 연결된 앱의 허락도 취소해요. 이 마무리가 다음 페이지의 주제예요.

## 오늘 바로 써먹기

- 연결 전에 "읽기만"인지 "쓰기도"인지 먼저 정하고, 가능하면 읽기만 허락하기
- 연습은 연습용 계정·페이지에서 하기
- 서버 이름은 서비스 이름과 비슷하게 붙이기(`notion`, `github`). 목록이 길어져도 알아보기 쉬워요.

## 자주 하는 오해

- "연결하면 내 모든 문서를 AI가 학습한다?" 연결은 Claude가 필요할 때 읽어 오는 통로예요. 내 문서가 어떻게 다뤄지는지는 서비스와 AI 회사의 정책을 따로 확인해야 해요. 이 책은 사실로 단정하지 않아요.
- "`/mcp`에서 연결됨이면 끝이다?" 끝이 아니에요. 끊는 법까지 알아야 해요.
