# 공부 도우미로 쓰기

<p class="ep-meta"><span>6장 · 6.1</span><span>읽는 시간 약 6분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 공부에서 AI는 ==답을 대신 알려 주는 사람이 아니라, 나를 시험해 주고 설명을 들어 주는 연습 상대==로 쓸 때 더 오래 남는다.
    - 읽고 나서 스스로 떠올려 보는 연습이 다시 읽기보다 오래 기억에 남는다는 연구가 있다.
    - 설명 요청, 문제 내기, 내 설명 점검 세 가지 방법을 쓴다.

## 1. 정답지만 베끼면

수학 문제집의 정답지만 베끼면 문제를 푼 것 같지만 시험에서는 못 풀어요. 풀어 보는 과정에서 머리가 일하기 때문이에요.

AI에게 "이거 설명해 줘"를 계속 시키면 쉽게 이해한 느낌이 들어요. 하지만 **이해한 느낌과 오래 기억하는 것은 달라요.**

!!! tip "10살 눈높이 한 줄 요약"
    AI에게 정답을 받아쓰지 말고, **AI가 낸 문제를 내가 풀어 보세요.**

## 2. 떠올리기 연습이 이긴다

2006년 *Psychological Science*에 실린 한 연구에서, 학생들이 글을 읽은 뒤 **기억해 내는 시험을 보는 방법**과 **같은 글을 다시 읽는 방법**을 비교했어요. 5분 뒤 시험에서는 다시 읽은 쪽이 더 잘했지만, **2일 뒤와 1주일 뒤 시험에서는 시험을 본 쪽이 훨씬 더 많이 기억**했어요. 흥미롭게도 다시 읽은 학생들이 자신의 기억력에 더 자신 있어 했어요. 연구진은 시험은 지식을 재는 데만 쓰이는 게 아니라 **학습을 돕는 강력한 방법**이라고 말해요.

그래서 AI에게 "다시 설명해 줘"만 반복하는 것보다 **"나를 시험해 줘"**가 오래 남는 공부에 더 가까워요.

## 3. 세 가지 공부법

**① 설명 요청 → 바로 시험**

```text
[주제]를 초등학교 6학년이 이해할 수 있게 설명해 줘.
설명이 끝나면 바로 내가 이해했는지 확인하는 질문 3개를 내 줘.
정답은 내가 대답한 다음에 알려 줘.
```

**② 문제 내기**

```text
방금 공부한 [범위]에서 문제를 5개 내 줘. 쉬운 것부터 어려운 순서로.
한 번에 한 문제씩 내고, 내가 답하면 맞는지 알려 주고 틀렸으면 힌트부터 줘.
```

**③ 내 설명 점검받기**

```text
내가 [주제]를 이렇게 이해했어. 틀리거나 빠진 부분을 알려 줘.
<내 설명>
(내가 이해한 대로 적은 글)
</내 설명>
```

세 번째 방법은 특히 좋아요. **내 말로 설명해 보는 것** 자체가 공부가 돼요.

## 4. 공부 도우미의 한계

- **AI의 설명이 틀릴 수 있어요.** 시험 범위나 교과서와 다르면 교과서가 기준이에요.
- **채점도 틀릴 수 있어요.** 정답이 정해진 문제는 해설지로 확인하세요.
- **정답을 바로 알려 주는 습관에 주의하세요.** 틀렸을 때 힌트부터 달라고 해야 머리가 일해요.

!!! note "★ 한 걸음 더 (심화)"
    - Anthropic은 2025년 4월 대학교를 위한 Claude for Education을 소개하면서 **학습 모드**를 함께 내놨어요. 답을 바로 주는 대신 학생의 사고 과정을 이끄는 방식이에요. 이것은 "정답을 주는 도우미"보다 "생각하게 만드는 도우미"가 공부에 낫다는 생각에서 나온 기능이에요. 서비스마다 비슷한 기능이 있는지는 확인해 보세요.
    - 연구는 글을 읽고 기억해 내는 상황의 실험이에요. 수학 풀이나 코딩처럼 다른 종류의 공부에도 같은 방식이 통할지는 따로 봐야 해요.
    - 5분 뒤 시험처럼 **당장 외워서 보는 시험**에는 다시 읽기가 더 나을 수 있다는 점도 연구가 보여 줘요. 목적이 단기 암기인지 오래 기억하기인지에 따라 방법이 달라요.

## 직접 해보기

이번 주에 공부한 것 하나를 정해서 해 보세요.

1. 위의 ①로 설명을 듣고 질문 3개에 답해요.
2. 하루 뒤에 같은 주제로 ②처럼 문제 5개를 풀어요.
3. 일주일 뒤에 AI 없이 종이에 내가 아는 것을 모두 적어 보고, ③으로 점검받아요.

일주일 뒤에 얼마나 기억하나요? 다시 읽기만 했던 주제와 비교해 보세요.

## 오늘 바로 써먹기

1. **"설명해 줘" 다음에 "나를 시험해 줘"를 붙이세요.** 한 줄이면 돼요.
2. **정답은 내가 답한 다음에 알려 달라고 하세요.** 그래야 떠올리는 연습이 돼요.
3. **간격을 두세요.** 오늘 한 번, 이틀 뒤 한 번, 일주일 뒤 한 번이 한꺼번에 하는 것보다 낫다고 알려져 있어요. (이 간격 효과는 이 연구가 아니라 일반적으로 알려진 학습 원리예요.)
4. **내 말로 설명해서 점검받으세요.** 가장 쉬운 방법이에요.
5. **AI 설명은 교과서와 대조하세요.** 시험의 기준은 교과서와 선생님이에요.

## 자주 하는 오해

- "AI가 쉽게 설명해 주면 공부가 된 거다" → 이해한 느낌과 기억은 달라요.
- "다시 읽으면 자신감이 생기니 효과가 있다" → 연구에서 다시 읽은 학생이 더 자신 있어 했지만, 1주일 뒤 기억은 시험을 본 쪽이 더 좋았어요.
- "AI에게 숙제를 시키면 공부를 대신해 준다" → 그러면 내 머리에는 남지 않아요.
