# 긴 자료 읽고 정리하기

<p class="ep-meta"><span>6장 · 6.1</span><span>읽는 시간 약 6분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 긴 보고서, 논문, 계약서는 ==질문을 먼저 정하고, 근거 문장을 뽑게 한 뒤== 정리한다.
    - 자료는 위에, 질문은 아래에 둔다.
    - 긴 글일수록 AI가 중간을 놓칠 수 있어서 나누거나 근거를 확인한다.

## 1. 큰 도서관에서 책 찾기

도서관에 가서 "이 책들 좀 알아봐"라고 하면 뭘 해야 할지 막막하죠. "이 중에서 감자의 역사를 다룬 부분을 찾아 줘"라고 하면 바로 찾을 수 있어요.

긴 자료도 그래요. "이거 정리해 줘"는 막연해서 평범한 요약이 나와요. **무엇을 알고 싶은지** 질문을 정하면 쓸모 있는 정리가 나와요.

!!! tip "10살 눈높이 한 줄 요약"
    긴 책을 읽힐 땐 **"뭘 찾아야 하는지"부터 알려 주세요.**

## 2. 네 단계 정리법

**1단계: 질문 정하기.** 이 자료로 무엇을 알고 싶은지 한두 문장으로 적어요.

**2단계: 자료를 위에, 질문을 아래에.** Anthropic 문서는 긴 자료(2만 토큰 이상)를 프롬프트의 위쪽에 두고 질문과 지시를 끝에 두라고 안내해요. 문서의 시험에서 끝에 둔 질문이 최대 30%까지 품질을 높였다고 소개해요.

**3단계: 근거 문장 먼저 뽑기.** 문서는 긴 문서 작업에서 **먼저 관련 있는 부분을 그대로 인용**하게 하라고 안내해요. 그러면 관련 있는 내용에 집중하게 돼요.

**4단계: 정리하기.** 뽑은 인용문만 바탕으로 답을 정리하게 해요.

```text
<자료>
(보고서 전문)
</자료>

위 자료를 읽고 다음 질문에 답해 줘.
질문: 이 계획의 가장 큰 위험 요소 세 가지는 무엇인가?
순서: 1) 먼저 질문과 관련된 문장을 자료에서 그대로 인용해 번호를 붙여 줘.
2) 그 인용문 번호만 근거로 답을 정리해 줘.
인용문으로 뒷받침할 수 없는 내용은 쓰지 말고 "자료에 없음"이라고 말해 줘.
```

## 3. 여러 문서를 비교할 때

문서가 여러 개일 때는 각각 **이름표**를 붙이면 헷갈리지 않아요. Anthropic 문서는 문서마다 태그로 감싸고 출처 정보를 함께 넣는 구조를 소개해요.

```text
<문서 번호="1" 출처="2025년 사업계획서">...</문서>
<문서 번호="2" 출처="2026년 사업계획서">...</문서>
두 문서에서 달라진 점을 표로 정리해 줘. 각 항목 옆에 어느 문서의 어느 문장인지 적어 줘.
```

## 4. 긴 글일수록 조심할 것

한 연구는 언어 모델이 긴 글 안에서 **관련 정보가 가운데 있을 때 성능이 크게 떨어질 수 있다**고 보고했어요(2023년, 당시 모델). 요즘 모델은 나아졌겠지만 같은 문제가 완전히 사라졌다고 보기는 어려워요. 그래서 중요한 내용은 이런 식으로 확인하세요.

- **나눠서 물어보세요.** 장마다 따로 질문하면 놓치는 부분이 줄어요.
- **근거 문장으로 확인하세요.** 근거가 원문에 있는지 직접 찾아보세요.
- **같은 질문을 순서를 바꿔 다시 해 보세요.** 답이 달라지면 확인이 필요해요.

!!! note "★ 한 걸음 더 (심화)"
    - 긴 문서를 다루는 방법에는 문서를 조각내서 필요한 조각만 찾아 넣는 검색 방식(RAG)도 있어요. IV부에서 다뤄요.
    - 서비스에 파일을 올리면 파일이 글로 바뀌어 들어가기도 하고, PDF는 쪽의 이미지와 글이 함께 처리되기도 해요(서비스와 파일 형식마다 달라요). 표나 그림은 처리 과정에서 깨질 수 있어서, 표가 중요한 문서는 결과를 원문과 대조하세요.
    - 컨텍스트 창이 넉넉해도 길수록 정확도가 떨어질 수 있다고 Anthropic 문서는 설명해요(컨텍스트 로트). 많이 넣는 것보다 필요한 것을 가려 넣는 일이 중요해요.

## 직접 해보기

긴 글(10쪽 이상의 보고서나 기사 모음)을 하나 골라 보세요.

1. 먼저 "이 글을 요약해 줘"로 한 번 요약을 받아요.
2. 그다음 질문을 하나 정하고, 위의 "근거 문장 먼저" 틀로 답을 받아요.
3. 두 답을 비교하세요. 어느 쪽이 내 질문에 더 도움이 됐나요? 근거 문장이 실제 원문에 있었나요?

## 오늘 바로 써먹기

1. **질문을 한 문장으로 적고 시작하세요.** "정리해 줘"보다 훨씬 좋아요.
2. **자료는 위, 질문은 아래.** 순서만 바꿔도 달라져요.
3. **근거 문장을 번호와 함께 받으세요.** 확인하기 쉬워요.
4. **계약서와 법 문서는 AI가 위험을 알려 주는 정도로만 쓰세요.** 최종 판단은 전문가나 직접 읽기로 하세요.
5. **개인정보와 기밀은 가려서 올리세요.** 3장에서 다룬 내용이에요.

## 자주 하는 오해

- "긴 글은 올리기만 하면 다 이해한다" → 길수록 놓치는 부분이 생길 수 있어요.
- "요약본만 읽어도 충분하다" → 중요한 결정에는 원문의 해당 부분을 읽으세요.
- "문서를 올렸으니 환각이 없다" → 자료가 있으면 줄지만 없어지지는 않아요. 근거 문장으로 확인하세요.
