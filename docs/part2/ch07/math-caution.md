# 계산을 맡길 때 조심할 것

<p class="ep-meta"><span>7장 · 7.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 챗봇은 글을 잘 쓰지만 ==여러 단계의 정확한 계산에서는 실수가 쌓일 수 있다.==
    - 계산은 "식 세우기"는 AI에게, "값 구하기"는 계산 도구에게 맡긴다.
    - 돈, 세금, 약 용량처럼 틀리면 큰 일은 반드시 따로 확인한다.

## 1. 암산 대회에서 긴 곱셈

짧은 덧셈은 암산으로 쉽게 하지만, 네 자리 곱셈을 암산으로 하면 중간에 하나만 틀려도 답이 틀려요. 앞의 틀린 값이 뒤로 계속 전해지니까요.

챗봇이 계산할 때도 비슷한 일이 생길 수 있어요. 1장에서 본 것처럼 챗봇은 다음 조각을 하나씩 이어 쓰고, 한번 쓴 조각은 되돌리지 않아요.

!!! tip "10살 눈높이 한 줄 요약"
    **식은 AI가 세우고, 값은 계산기가 구해요.** 암산 대회 선수에게 긴 곱셈을 시키지 마세요.

## 2. 연구는 뭐라고 할까

2023년 한 논문(*Faith and Fate*)은 트랜스포머 언어 모델이 **여러 자리 곱셈, 논리 퍼즐, 동적 계획법 문제**처럼 문제를 작은 단계로 쪼개서 푸는 과제에서 어떤지 살펴봤어요. 연구진은 이런 모델이 이런 문제를 체계적으로 푸는 능력 없이, 비슷한 계산 조각을 맞춰 보는 방식으로 푸는 것으로 보인다고 분석했어요. 그리고 문제가 복잡해질수록 순서대로 이어 쓰는 방식의 성능이 빠르게 떨어질 수 있다는 이론적 주장도 했어요.
- Andrej Karpathy, [Deep Dive into LLMs like ChatGPT](https://www.youtube.com/watch?v=7xTGNNLPyMI), YouTube. 챕터 '01:46:56 models need tokens to think'에서 계산을 여러 토큰에 나눠 쓰고, 중간 결과를 만들게 하거나 가능하면 도구를 쓰라고 권하며, 모델이 한 번에 다 하게 하면 완전히 믿지 못한다고 말하는 것을 제3자 사이트 Rosetta가 자막에서 자동 생성한 비공식 [자막](https://rosetta.to/u/andrejkarpathy/deep-dive-into-llms-like-chatgpt)으로 확인했어요.

이 논문은 2023년 모델을 대상으로 했어요. 요즘 모델은 도구를 쓰거나 충분히 생각한 뒤 답해서 훨씬 나아졌지만, **복잡한 계산에서 틀릴 수 있다는 가능성은 여전히 확인해야 해요.**

## 3. 계산 유형별 안내

| 계산 | 어떻게 맡길까 |
|---|---|
| 짧은 덧셈, 간단한 비율 | 맡겨도 되지만 어림 계산으로 확인 |
| 평균, 합계, 퍼센트 | 식을 쓰게 하고 값은 계산기나 표 계산 프로그램으로 |
| 날짜 계산(며칠 뒤, 요일) | 달력이나 도구로 확인. 틀리기 쉬워요 |
| 환율, 단위 변환 | 최신 환율은 모르니 직접 입력하고, 식만 AI에게 |
| 대출 이자, 세금, 연금 | 식을 이해하는 용도로만 쓰고, 값은 공식 계산기나 전문가에게 |
| 약 용량, 의료 계산 | AI에게 맡기지 마세요. 의사와 약사에게 |

## 4. 식 세우기를 시키는 방법

```text
다음 문제를 풀어 줘. 숫자를 직접 계산하지 말고,
1) 필요한 계산 과정을 식으로 단계별로 써 줘.
2) 각 식에 들어가는 값이 무엇인지 설명해 줘.
계산은 내가 계산기로 할 거야.
문제: 한 달 동안 매일 아침 커피 4,500원, 점심 9,000원을 쓰고 주말에는 쓰지 않는다. 
한 달(4주)에 얼마를 쓰는가?
```

식과 설명을 받으면, 내가 이해했는지 확인하면서 계산기로 값을 구할 수 있어요. 이 방법은 계산 실수뿐 아니라 **문제를 잘못 이해한 곳**도 찾아줘요.

!!! note "★ 한 걸음 더 (심화)"
    - 계산에서 도구(계산기나 코드 실행)를 연결하면 값은 코드가 정확하게 계산하니 크게 좋아져요(IV부). 그래도 **어떤 식을 세웠는지**가 틀리면 값이 정확해도 답이 틀려요. 식은 사람이 읽고 확인해야 해요.
    - "단계별로 생각해 줘"가 도움이 될 때가 많은 이유는, 중간 계산을 글로 적어서 다음 조각을 고를 때 그 글을 근거로 쓸 수 있기 때문이에요. 요즘의 추론 모델은 이런 생각 과정을 스스로 길게 하도록 훈련돼요(20장). 하지만 과정이 그럴듯해도 틀릴 수 있어요.
    - 앞서 본 연구는 계산 자체가 아니라 "여러 단계를 이어 푸는 과제" 전반의 한계를 다뤄요. 글쓰기에서 긴 글의 앞뒤가 어긋나는 일도 같은 뿌리를 공유할 수 있다는 해석도 있지만, 이 연구가 직접 보여 준 건 아니에요.

## 직접 해보기

두 가지로 시켜 보세요.

```text
① 3,847 × 2,916 은 얼마야?
```

```text
② 3,847 × 2,916 을 구하는 과정을 자릿수별 식으로 나눠서 적어 줘. 값은 내가 계산기로 구할게.
```

①의 값을 계산기와 비교해 보세요. (정답은 11,217,852예요.) ②의 식을 따라 계산기로 구하면 답이 맞나요? 틀린 곳이 있다면 어디였나요?

## 오늘 바로 써먹기

1. **값 대신 식을 요청하세요.** 식은 내가 읽고 이해할 수 있어요.
2. **어림 계산을 하세요.** 3,800 × 2,900쯤이면 1,100만쯤이라는 감이 있으면 크게 틀린 답을 잡아내요.
3. **날짜와 단위를 따로 확인하세요.** 요일, 윤년, 단위 변환은 틀리기 쉬워요.
4. **돈과 건강은 전문 계산기나 전문가에게.** AI는 이해를 돕는 용도로만 쓰세요.
5. **도구가 연결된 서비스라도 식을 확인하세요.** 값이 정확해도 식이 틀리면 소용없어요.

## 자주 하는 오해

- "계산 과정을 보여 주면 맞다" → 과정이 그럴듯해도 중간에 틀릴 수 있어요.
- "컴퓨터니까 계산은 완벽하다" → 챗봇은 계산기가 아니라 말을 이어 쓰는 기계예요.
- "한 번 맞았으니 다음에도 맞다" → 같은 문제도 다시 물으면 다를 수 있어요(1장).
