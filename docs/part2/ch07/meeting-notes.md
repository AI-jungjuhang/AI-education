# 회의록과 메일 정리

<p class="ep-meta"><span>7장 · 7.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 흩어진 메모와 긴 메일은 AI가 ==결정, 미정, 할 일(담당자와 기한)==로 정리하는 데 좋다.
    - 정리 형식을 미리 정해 주고, 모르는 칸은 지어내지 말고 "미정"으로 두게 한다.
    - 담당자와 기한은 반드시 사람이 확인한다.

## 1. 서랍 정리

서랍이 엉망일 때, 칸막이부터 만들고 물건을 넣으면 빨라요. 회의 메모도 **칸막이(형식)**를 먼저 정해 두면 정리가 쉬워져요.

메모가 뒤죽박죽이어도 AI는 "결정된 것, 안 정해진 것, 해야 할 일"로 나누는 일을 잘해요. 다만 **빈칸을 그럴듯하게 채우는 버릇**이 있어서 조심해야 해요.

!!! tip "10살 눈높이 한 줄 요약"
    **칸막이를 먼저 만들고**, 모르는 칸은 비워 두게 하세요.

## 2. 회의록 틀

```text
아래 회의 메모를 정리해 줘.
형식:
1) 결정된 것 (한 줄씩)
2) 아직 안 정해진 것 (한 줄씩)
3) 할 일 표: 할 일 / 담당자 / 기한
규칙:
- 메모에 없는 담당자나 기한은 만들지 말고 "미정"이라고 써 줘.
- 메모의 숫자와 날짜는 바꾸지 마.
- 해석이 필요한 부분은 "확인 필요"로 표시해 줘.
<메모>
(회의 메모 붙여 넣기)
</메모>
```

Anthropic 문서도 원하는 출력 형식을 JSON, XML, 또는 직접 만든 템플릿으로 정확히 정해 주면 형식을 더 일관되게 따른다고 안내해요. 매번 같은 틀을 쓰면 회의록 모양이 일정해져요.

## 3. 긴 메일 정리

메일이 20통씩 오간 대화는 AI에게 읽히면 편해요.

```text
아래 메일 대화를 읽고 정리해 줘.
1) 지금까지 합의된 것
2) 아직 답이 필요한 질문과 질문한 사람
3) 내가 해야 할 일
4) 내가 보낼 답장 초안 (정중하게, 5문장 이내)
메일에 없는 내용은 추가하지 마.
<메일>(붙여 넣기)</메일>
```

## 4. 꼭 사람이 확인할 것

| 확인할 것 | 이유 |
|---|---|
| 담당자 이름 | 비슷한 이름이 섞이거나 잘못 배정될 수 있어요 |
| 기한 | 날짜가 바뀌거나 "다음 주"가 잘못 해석될 수 있어요 |
| 숫자 | 3장의 확인법을 쓰세요 |
| 결정 vs 제안 | "하자고 했다"와 "하기로 했다"는 달라요 |
| 빠진 내용 | 요약하면서 빠진 중요한 말이 없는지 |

!!! note "★ 한 걸음 더 (심화)"
    - 회의 녹음을 글로 바꾸는 서비스(음성 인식)를 쓸 수도 있어요. 인식이 틀리면 이름이나 전문 용어가 잘못 적히고, 그 틀린 글을 AI가 그대로 정리해요. 입력 단계의 오류가 뒤까지 이어질 수 있어요. 이름과 용어는 따로 확인하세요.
    - 회의 내용은 개인정보나 기밀이 많아서 3장의 점검이 특히 중요해요. 회사가 승인한 도구를 쓰고, 참석자의 동의가 필요한지도 규정을 확인하세요.

## 직접 해보기

최근 회의나 통화 내용을 아무렇게나 적은 메모(5~10줄)를 하나 골라요.

1. 위의 틀로 정리를 받아요.
2. 정리된 "할 일 표"를 원래 메모와 대조해서 담당자와 기한이 맞는지 보세요.
3. "미정"으로 표시된 칸이 몇 개인가요? 지어낸 칸은 없나요?

## 오늘 바로 써먹기

1. **회의록 틀을 저장해 두세요.** 2장에서 배운 "질문 틀"로 쓰세요.
2. **"없는 정보는 미정으로" 규칙을 넣으세요.** 지어내는 담당자와 날짜를 줄여 줘요.
3. **정리 직후에 바로 확인하세요.** 기억이 남아 있을 때 틀린 곳을 잡기 쉬워요.
4. **공유 전에 담당자에게 확인받으세요.** 정리한 사람이 AI여도 보내는 사람은 나예요.
5. **개인정보와 기밀은 가려서 넣으세요.** 이름은 A, B로 바꿔도 정리는 돼요.

## 자주 하는 오해

- "AI가 정리하면 틀림이 없다" → 담당자와 기한은 꼭 대조하세요.
- "메모가 엉망이면 AI도 못 한다" → 엉망인 메모를 구조화하는 건 AI가 잘하는 일이에요.
- "회의 전체를 녹음해서 맡기면 된다" → 녹음의 인식 오류가 그대로 따라갈 수 있어요.
