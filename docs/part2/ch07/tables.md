# 표와 엑셀 함수 도움받기

<p class="ep-meta"><span>7장 · 7.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 글을 표로 바꾸거나 표를 설명하는 일, 그리고 엑셀·구글 시트 함수를 알아내는 일에 AI가 큰 도움이 된다.
    - 함수를 물을 때는 ==프로그램 이름, 열 이름, 예시 두세 줄, 원하는 결과==를 알려 준다.
    - 받은 함수는 작은 데이터로 먼저 시험하고, 존재하는 함수인지 도움말로 확인한다.

## 1. 요리 레시피와 재료

요리사에게 "맛있는 거 해 줘"라고 하면 곤란하지만, 재료와 원하는 맛을 알려 주면 레시피를 줄 수 있어요. 함수 질문도 마찬가지예요. **내가 가진 표(재료)와 원하는 결과(맛)**를 알려 주면 AI가 함수(레시피)를 줘요.

!!! tip "10살 눈높이 한 줄 요약"
    "함수 알려 줘"가 아니라 **"이런 표에서 이런 결과를 얻고 싶어"**라고 말해요.

## 2. 글을 표로, 표를 글로

**글 → 표:** 흩어진 정보를 표로 정리해요.

```text
아래 글에서 상품 이름, 가격, 재고 수량을 찾아서 표로 만들어 줘.
글에 없는 칸은 비워 두고 "없음"이라고 적어 줘.
<글>(붙여 넣기)</글>
```

**표 → 글:** 표의 내용을 말로 설명해요. 숫자는 바꾸지 않도록 하세요.

## 3. 엑셀·구글 시트 함수 질문법

좋은 질문에는 네 가지가 있어요.

1. **프로그램:** 엑셀인지, 구글 시트인지 (함수가 조금씩 달라요)
2. **열 이름:** A열에 무엇이, B열에 무엇이 있는지
3. **예시 두세 줄:** 실제 데이터 모양 (개인정보는 가려서)
4. **원하는 결과:** 어느 칸에 어떤 값이 나와야 하는지, 예시로

```text
구글 시트를 쓰고 있어.
A열: 이름, B열: 부서, C열: 매출(숫자)
예) 홍길동 / 영업 / 120
영업 부서의 매출 합계를 E2 칸에 구하고 싶어.
함수 하나를 알려 주고, 각 부분이 무슨 뜻인지 한 줄씩 설명해 줘.
```

받은 함수는 **작은 데이터로 먼저 시험**해 보세요. Anthropic 문서도 결과 모양을 구체적으로 지정하고 예시로 제약하라고 안내해요. 원하는 결과 예시를 주면 맞는 답을 받기 쉬워요.

## 4. 함수가 안 될 때

- 오류 메시지를 그대로 복사해서 알려 주세요. "#NAME?", "#VALUE!" 같은 것이에요.
- 함수를 쓴 칸의 값과 범위를 알려 주세요.
- 함수가 **실제로 있는지** 프로그램의 도움말이나 공식 안내에서 확인하세요. AI가 없는 함수를 만들어 낼 수 있어요(환각).
- 버전에 따라 없는 함수가 있을 수 있어요. 쓰는 버전을 알려 주세요.

!!! note "★ 한 걸음 더 (심화)"
    - 큰 표를 통째로 붙여 넣는 것보다 **열 이름과 몇 줄의 예시**만 주는 것이 보통 더 좋아요. 긴 표는 컨텍스트에 많은 자리를 차지하고, 정확도도 떨어질 수 있어요(2장, 6장).
    - 파일을 올려 AI가 코드를 실행해 직접 계산하는 서비스도 있어요(IV부). 그런 경우 계산은 코드가 하지만, 어떤 코드를 어떤 열에 적용했는지는 확인해야 해요.
    - 개인정보가 있는 표는 3장의 방법으로 가리세요. 이름 열을 지우거나 가짜 데이터로 바꿔도 함수 질문에는 충분해요.

## 직접 해보기

내가 쓰는 표(또는 연습용으로 5줄짜리 표)를 하나 정하세요.

1. 풀고 싶은 문제를 정해요. (합계, 조건에 맞는 개수, 평균 등)
2. 위의 네 가지(프로그램, 열 이름, 예시, 원하는 결과)로 질문해요.
3. 받은 함수를 작은 데이터에 넣고, 내가 손으로 계산한 값과 같은지 확인해요.

## 오늘 바로 써먹기

1. **질문 틀을 저장하세요.** 프로그램, 열 이름, 예시, 결과 네 칸이에요.
2. **개인정보는 가짜 데이터로 바꾸세요.** 함수 질문에는 진짜 이름이 필요 없어요.
3. **결과는 몇 행만 손으로 확인하세요.** 3행쯤이면 틀을 알아채요.
4. **함수 설명도 요청하세요.** "각 부분이 무슨 뜻인지"를 알면 다음에는 스스로 고칠 수 있어요.
5. **안 되면 오류 메시지를 그대로 붙이세요.** 가장 빠른 길이에요.

## 자주 하는 오해

- "AI가 알려 준 함수는 다 있는 함수다" → 없는 함수나 다른 프로그램의 함수를 줄 수 있어요.
- "표 전체를 붙여야 정확하다" → 열 이름과 예시 몇 줄이면 충분한 경우가 많아요.
- "숫자 계산도 AI가 해 주니 함수가 필요 없다" → 계산은 함수나 도구로 하는 게 확실해요. 다음 페이지에서 이어져요.
