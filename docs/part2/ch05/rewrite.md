# 고쳐 쓰기와 말투 바꾸기

<p class="ep-meta"><span>5장 · 5.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - AI가 가장 믿음직하게 도와주는 일 중 하나가 **내가 쓴 글을 다듬는 일**이다.
    - "의미는 그대로, 사실은 추가하지 않기"를 꼭 말해야 한다.
    - 무엇이 바뀌었는지 보여 달라고 하면 확인이 쉽다.

## 1. 옷 갈아입히기

같은 사람이 면접 때와 소풍 때 다른 옷을 입는 것처럼, 같은 내용도 **상대에 따라 다른 옷**을 입혀야 해요. 사과 문자는 정중하게, 친구에게 보내는 건 편하게요.

고쳐 쓰기는 내용이 이미 내 안에 있다는 점에서 초안 만들기보다 안전해요. 1장에서 본 환각이 끼어들 틈이 적기 때문이에요. 다만 다듬다가 **슬쩍 내용을 바꾸거나 더하는** 일은 있어요.

!!! tip "10살 눈높이 한 줄 요약"
    내용은 그대로 두고 **옷만 갈아입히기.** 옷 갈아입히다가 몸이 바뀌면 안 돼요.

## 2. 고쳐 쓰기의 종류

| 하고 싶은 것 | 이렇게 말해요 |
|---|---|
| 맞춤법·띄어쓰기만 | "맞춤법과 띄어쓰기만 고치고 문장은 바꾸지 마" |
| 읽기 쉽게 | "문장을 짧게 나누고 어려운 말은 쉬운 말로. 내용은 그대로" |
| 말투 바꾸기 | "정중한 존댓말로 바꿔 줘. 같은 의미로" |
| 길이 줄이기 | "의미를 유지하면서 절반으로" |
| 분위기 바꾸기 | "차갑지 않게, 따뜻한 느낌으로. 사실은 그대로" |

## 3. 꼭 붙일 안전장치

고쳐 쓰기를 시킬 때는 이 두 줄을 습관으로 넣으세요.

```text
의미는 바꾸지 말고, 원문에 없는 사실이나 숫자는 추가하지 마.
바꾼 부분은 [원문 → 수정] 형태로 목록으로 알려 줘.
```

**변경 목록**을 받으면 어디가 바뀌었는지 한눈에 보여서, 몰래 바뀐 내용을 찾기 쉬워요.

## 4. 내 말투 지키기

말투를 바꾸고 싶다면 설명보다 **견본**이 빨라요(2장).

```text
아래 "견본"의 말투로 "원문"을 다시 써 줘. 견본의 문장 길이, 어미, 분위기를 참고해.
내용은 바꾸지 마.
<견본>(내가 쓴 글)</견본>
<원문>(고칠 글)</원문>
```

!!! note "★ 한 걸음 더 (심화)"
    - 고쳐 쓰기에서 AI가 의미를 슬쩍 바꾸는 이유는, 문장을 다시 쓰는 과정이 "다음 말 고르기"이기 때문이에요. 원문의 문장들을 보고 비슷한 의미의 새 문장을 고르다 보면 미묘하게 달라질 수 있어요. 특히 숫자, 부정문("~하지 않았다"), 정도 표현("거의", "반드시")이 바뀌기 쉬워요.
    - 그래서 고친 글을 원문과 나란히 놓고 **숫자, 부정, 정도 표현** 세 가지를 우선 확인하세요.

## 직접 해보기

최근에 쓴 글(메일이나 보고서의 한 문단)을 골라 보세요.

1. 위의 안전장치 두 줄을 붙여서 "읽기 쉽게" 고치게 해요.
2. 변경 목록을 보면서 원문과 비교해요.
3. 바뀌면 안 되는 내용(숫자, 약속, 부정문)이 바뀌었는지 확인해요.

바뀐 곳이 있었나요? 있었다면 어떤 종류였나요?

## 오늘 바로 써먹기

1. **"의미 유지, 사실 추가 금지"를 기본으로 붙이세요.** 이 한 줄이 사고를 줄여 줘요.
2. **변경 목록을 받으세요.** 어디가 바뀌었는지 알면 확인이 쉬워요.
3. **숫자, 부정문, 정도 표현을 따로 확인하세요.** 의미가 크게 달라질 수 있는 부분이에요.
4. **상대별로 여러 버전을 받으세요.** "팀장님용", "친구용"을 한 번에 받아 비교해요.
5. **중요한 글은 마지막에 내가 읽으세요.** AI가 고친 글은 내 책임이에요.

## 자주 하는 오해

- "고쳐 쓰기는 안전하니 확인할 필요가 없다" → 안전한 편이지만 숫자나 부정이 바뀔 수 있어요.
- "말투는 설명하면 바로 바뀐다" → 견본을 주는 게 더 정확해요.
- "맞춤법은 AI가 완벽하다" → 대부분 잘 고치지만 고유명사나 전문 용어는 틀릴 수 있어요.
