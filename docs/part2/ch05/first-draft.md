# 초안 만들기

<p class="ep-meta"><span>5장 · 5.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 빈 화면 앞에서 막막할 때 AI는 =="첫 번째 나쁜 초안"을 빨리 만들어 주는 도구==로 좋다.
    - 순서는 요점 정하기 → 뼈대 → 문단별 초안 → 내 손으로 고치기다.
    - 초안은 초안일 뿐이라서, 사실 확인과 마지막 문장은 내 몫이다.

## 1. 반죽부터 만들기

빵을 만들 때 처음부터 예쁜 모양을 빚을 수는 없어요. 일단 **반죽**을 만들어야 모양을 잡을 수 있죠. 글도 마찬가지예요. 빈 화면에서 첫 문장을 쓰기가 가장 어려워요.

AI는 이 반죽을 빨리 만들어 줘요. 완성된 글을 받으려 하기보다 **고칠 거리를 빨리 받는다**고 생각하면 마음이 편해요.

한 실험이 이를 뒷받침해요. 2023년 *Science*에 실린 연구에서 전문직 453명에게 직업별 글쓰기 과제를 주고 절반에게 ChatGPT를 쓰게 했더니, 평균 작업 시간이 40% 줄고 글의 평가 점수가 18% 올랐어요. 다만 이것은 온라인 실험이고 중간 수준의 업무용 글쓰기 과제였어요. 내 일에도 같은 효과가 난다는 뜻은 아니에요.

!!! tip "10살 눈높이 한 줄 요약"
    AI는 **반죽을 빨리 만들어 주는 도우미**예요. 모양은 내가 잡아요.

## 2. 네 단계 순서

**1단계: 요점을 내가 정한다.** 무엇을 말하고 싶은지는 내가 알아야 해요. 요점 세 가지를 직접 적어요.

**2단계: 뼈대를 먼저 받는다.** 바로 글을 쓰게 하지 말고 목차(개요)부터 받아요.

```text
[목적] 팀원들에게 보낼 주간 공지야.
[요점] 1) 금요일 회의가 월요일로 바뀜 2) 다음 주 마감은 그대로 3) 자료는 목요일까지 공유
[독자] 같은 팀 동료 8명, 바쁜 사람들
먼저 3문단 이내 개요를 제안해 줘. 글은 아직 쓰지 마.
```

**3단계: 문단별로 초안을 받는다.** 뼈대가 마음에 들면 한 문단씩 쓰게 하거나, 전체 초안을 받아요.

**4단계: 내 손으로 고친다.** 내 말투로 바꾸고, 사실을 확인하고, 마지막 문장은 내가 써요.

## 3. 내 목소리 지키기

AI 초안은 어딘가 "누구나 쓸 법한 글"이 되기 쉬워요. 내 말투를 지키려면 **내가 쓴 글을 견본으로** 주세요(2장의 "예시").

```text
아래는 내가 예전에 쓴 글이야. 이 말투와 문장 길이를 참고해서 초안을 써 줘.
<내가 쓴 글>
(붙여 넣기)
</내가 쓴 글>
```

!!! note "★ 한 걸음 더 (심화)"
    - 위 연구에서는 AI를 쓴 사람들 사이의 점수 차이도 줄었어요(글쓰기에 서툰 사람이 더 큰 도움을 받음). 연구는 불평등이 줄었다고 보고했지만 장기 효과나 다른 직업까지 일반화하기는 어려워요.
    - 초안을 AI로 만들면 **내가 직접 쓸 때보다 내용을 덜 곱씹게** 될 수 있어요. 이건 이 책의 주장이 아니라 주의하자는 제안이에요. 중요한 글은 요점 정리 단계를 AI에 맡기지 않는 게 좋아요.

## 직접 해보기

이번 주에 써야 하는 글 하나(메일, 공지, 자기소개 등)를 정해서 해 보세요.

1. 요점 세 가지를 직접 적어요.
2. 위 틀로 개요를 받아요.
3. 마음에 드는 개요로 초안을 받아요.
4. 내 말투로 세 군데 이상 고치고, 사실을 확인해요.

처음부터 내가 썼다면 시간이 얼마나 걸렸을지 비교해 보세요.

## 오늘 바로 써먹기

1. **요점은 내가 정하세요.** AI에게 요점까지 맡기면 흔한 내용으로 채워지기 쉬워요.
2. **개요를 먼저 받으세요.** 방향이 틀렸을 때 일찍 고칠 수 있어요.
3. **내가 쓴 글을 견본으로 붙이세요.** 말투가 훨씬 가까워져요.
4. **초안에는 "모르면 비워 둬"를 붙이세요.** `[여기에 숫자]`처럼 표시하게 하면 지어낸 숫자가 줄어요.
5. **마지막은 내가 읽고 소리 내어 보세요.** 어색한 문장이 바로 들려요.

## 자주 하는 오해

- "AI 초안을 그대로 보내면 된다" → 사실 확인과 내 말투 고치기가 빠지면 위험해요.
- "AI로 쓰면 누구 글인지 티가 난다" → 견본과 구체적인 맥락을 주면 훨씬 덜해요.
- "AI는 글을 못 쓰는 사람만 쓴다" → 연구에서도 다양한 사람이 시간을 줄였어요. 도구일 뿐이에요.
