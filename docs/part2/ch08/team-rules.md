# 팀에서 정하는 규칙

<p class="ep-meta"><span>8장 · 8.1</span><span>읽는 시간 약 5분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - 팀이 AI를 함께 쓰려면 ==무엇을 입력해도 되는지, 누가 확인하는지, 어떻게 밝히는지==를 미리 정해 둔다.
    - 규칙은 짧고 지킬 수 있어야 한다. 한 장이면 충분하다.
    - 일이 생기면 책임을 묻기보다 고치는 흐름을 만든다.

## 1. 학급 규칙

학급에 규칙이 없으면 다툼이 생기고, 규칙이 너무 많으면 아무도 안 지켜요. "복도에서는 걷기"처럼 **짧고 분명한 규칙**이 잘 지켜지죠.

팀이 AI를 쓸 때도 마찬가지예요. 사람마다 쓰는 방식이 다르면 어떤 사람은 고객 정보를 그대로 넣고, 어떤 사람은 AI를 숨기고 써서 나중에 문제가 돼요.

!!! tip "10살 눈높이 한 줄 요약"
    규칙은 **짧고 분명하게**, 한 장으로 만들어요.

## 2. 한 장짜리 규칙에 들어갈 것

| 칸 | 정할 것 | 예 |
|---|---|---|
| 써도 되는 일 | 허용하는 용도 | 초안, 요약, 아이디어, 표 정리 |
| 쓰면 안 되는 일 | 금지하는 용도 | 고객 개인정보 입력, 최종 법률 판단 |
| 자료 등급 | 무엇을 넣어도 되는지 | 공개 자료는 OK, 내부 자료는 승인된 도구만, 민감 자료는 금지 |
| 확인 담당 | 결과를 누가 확인하나 | 쓴 사람이 1차 확인, 외부 발송은 팀장이 확인 |
| 표기 | AI 사용을 어떻게 밝히나 | 외부 문서는 "초안 작성에 AI 활용" 표기 |
| 승인된 도구 | 어떤 도구를 쓰나 | 회사 계정의 ○○ |
| 문제가 생기면 | 어디에 알리나 | 담당자 이름과 연락 방법 |

## 3. 자료 등급 나누기

규칙에서 가장 중요한 부분이에요. 3장의 개인정보 내용을 팀의 언어로 옮겨요.

- **공개 자료:** 이미 공개된 자료. 입력해도 되는 경우가 많지만, 개인정보나 저작권·재배포 제한이 있는지는 확인해요.
- **내부 자료:** 사내 문서, 아직 공개되지 않은 계획. 회사가 승인한 도구에만.
- **민감 자료:** 고객 개인정보, 계약, 인사, 건강 정보. 입력하지 않거나 가려서만.

## 4. 규칙을 지키게 만드는 법

1. **한 장으로 만드세요.** 길면 읽지 않아요.
2. **예시를 넣으세요.** "이런 건 괜찮고 이런 건 안 돼요" 예가 규칙보다 이해가 빨라요.
3. **함께 정하세요.** 일하는 사람이 참여해야 현실적인 규칙이 나와요.
4. **물어볼 곳을 알려 주세요.** 애매할 때 물어볼 사람이 있어야 해요.
5. **석 달마다 고치세요.** 서비스와 법이 바뀌어요.
6. **실수를 신고하기 쉽게 하세요.** 숨기면 더 큰 문제가 돼요.

!!! note "★ 한 걸음 더 (심화)"
    - 미국 국립표준기술연구소(NIST)는 AI를 만들고 쓰는 조직이 신뢰성을 높이도록 돕는 **AI 위험 관리 프레임워크(AI RMF)**를 2023년 1월 26일 공개했어요. 자발적으로 쓰는 틀이에요. 2024년 7월 26일에는 생성형 AI의 고유한 위험을 다룬 생성형 AI 프로필(NIST-AI-600-1)도 나왔어요. 팀 규칙을 조직적으로 만들고 싶다면 참고할 수 있어요. 개인이나 작은 팀에는 이 책의 한 장짜리 규칙이 더 현실적이에요.
    - 한국에서는 개인정보보호위원회가 2025년 8월 생성형 AI 개발·활용을 위한 개인정보 처리 안내서를 공개했다고 보도됐어요(3장 참고). 외부 AI 서비스를 쓰는 경우 입력값이 해외 서버로 전송될 수 있어 계약이나 약관을 확인하라는 권고가 있다고 해요.
    - 이 페이지는 일반 정보이고 법률 자문이 아니에요. 회사의 정식 규정은 법무와 보안 담당자와 함께 정하세요.

## 직접 해보기

내가 속한 팀(또는 모임)에서 한 장짜리 규칙 초안을 만들어 보세요.

1. 위 표의 일곱 칸을 채워요.
2. 팀원 두 명에게 읽어 보게 하고 "어디가 애매해요?"를 물어보세요.
3. 애매한 곳을 고쳐서 팀에 공유하세요.

## 오늘 바로 써먹기

1. **자료 등급 세 가지부터 정하세요.** 그것만으로도 큰 사고를 막아요.
2. **"애매하면 물어보기" 담당을 정하세요.** 이름 하나면 돼요.
3. **외부로 나가는 글은 사람이 확인하세요.** AI가 쓴 글도 보내는 사람의 책임이에요.
4. **AI 사용을 밝히는 방법을 정하세요.** 숨기는 게 가장 위험해요.
5. **규칙 발표 때 예시를 같이 보여 주세요.** 이해가 빨라요.

## 자주 하는 오해

- "규칙이 있으면 AI 활용이 줄어든다" → 안전한 범위를 알면 오히려 안심하고 써요.
- "금지하면 안전하다" → 금지만 하면 몰래 쓰는 사람이 생길 수 있어요. 안전한 방법을 알려 주세요.
- "한 번 정하면 계속 쓴다" → 서비스와 법이 바뀌니 석 달마다 점검하세요.
