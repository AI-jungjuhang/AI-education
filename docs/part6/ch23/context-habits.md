# 기억 공간을 아끼는 습관

!!! abstract "이 페이지에서 배우는 것"
    - 책상 정리 도구는 네 가지예요: ==`/clear`(새로), `/compact`(요약), 부분 요약, 서브에이전트(밖에서 읽기)==
    - 요약해도 **살아남는 것과 사라지는 것**이 있어요. 중요한 규칙은 살아남는 자리에 둬요.
    - 정리의 목적은 "아끼기"가 아니라 "집중하기"예요.

## 1. 네 가지 정리 도구

| 도구 | 언제 | 효과 |
|---|---|---|
| `/clear` | 전혀 다른 일로 넘어갈 때 | 책상을 싹 비워요. 옛 대화가 다음 일을 방해하지 않아요 |
| `/compact 집중할 것` | 같은 일을 이어 가는데 길어졌을 때 | 대화를 요약해요. 무엇을 남길지 지시할 수 있어요 |
| `/rewind` → 여기서부터 요약 | 앞쪽은 소중하고 뒤쪽만 지저분할 때 | 고른 지점 앞뒤 중 한쪽만 요약해요 |
| 서브에이전트 | 많이 읽어야 하는 조사 | 읽는 일은 따로 하고 요약만 받아요 |

`/compact`에는 방향을 줄 수 있어요. 공식 문서의 예처럼 "인증 버그 수정에 집중해서"라고 쓰면 요약이 그걸 남겨요. 자동 요약이 알아서 중요하다고 추측하는 것보다 낫기 때문이에요.

```text
/compact 지금 쓰는 V부 페이지의 결정 사항과 아직 확인하지 못한 링크만 남겨 줘
```

## 2. 요약해도 살아남는 것

공식 문서가 정리한 표를 쉬운 말로 줄이면 이래요.

| 요약 뒤에도 | 어떻게 |
|---|---|
| 프로젝트 맨 위의 CLAUDE.md | 파일에서 다시 읽어 와요 |
| 자동 메모 | 파일에서 다시 읽어 와요 |
| 스킬 설명 | 현재 스킬 목록으로 다시 만들어 와요 |
| 작업 중에 읽거나 고친 파일 | 가장 최근에 바뀐 5개까지 다시 읽어요(5,000토큰이 넘는 파일은 경로만) |
| 이미 쓴 스킬 본문 | 스킬당 5,000토큰, 전체 25,000토큰까지 다시 넣고 오래된 것부터 빠져요 |
| **대화로만 한 지시** | **요약에 묻혀서 사라질 수 있어요** |

그래서 규칙이 있어요. **계속 지켜야 하는 규칙은 대화로 말하지 말고 프로젝트 맨 위 CLAUDE.md에 적어요.** 공식 문서도 하위 폴더의 CLAUDE.md나 특정 파일에만 적용되는 규칙은 요약에 묻힐 수 있으니, 꼭 남겨야 하면 프로젝트 맨 위 CLAUDE.md로 옮기라고 해요. 그리고 스킬은 길면 앞부분만 남으니 **중요한 지시를 SKILL.md 맨 위**에 둬요.

## 3. 낡은 조언 버리기

예전에는 "기억 공간을 공격적으로 관리하라"는 조언이 많았어요. 공식 모범 사례는 이제 대부분의 모델이 큰 창을 갖고 요약도 알아서 하니 가득 차는 일이 드물다고 해요. 그래도 `/clear`는 작업 사이에 계속 의미가 있다고 해요. 그러니 이 페이지의 습관은 "초조하게 아끼기"가 아니라 **"일이 바뀔 때 비우고, 규칙은 제자리에 두기"** 정도로 가볍게 가져가요.

!!! tip "10살 눈높이 한 줄 요약"
    일이 바뀌면 칠판을 지우고, 꼭 지킬 규칙은 칠판이 아니라 벽 게시판(CLAUDE.md)에 붙여요.

!!! note "★ 한 걸음 더 (심화)"
    자동 요약이 시작되는 시점을 앞당기는 `/autocompact`와, 요약이 끝난 뒤에 내용을 다시 넣는 `SessionStart` 훅도 있어요. 중요한 안내를 요약 뒤에도 꼭 다시 넣어야 하면 훅으로 해요. 5.6의 훅 페이지에서 배운 "AI의 판단에 맡기지 않는 약속"이 여기서도 쓰여요.

## 직접 해보기

1. 대화 중간에 `/context`를 보고 `/compact 지금 하는 일의 결정 사항만 남겨 줘`를 실행해요.
2. 다시 `/context`를 봐서 책상이 얼마나 비워졌는지 확인해요.
3. 대화로만 말했던 규칙 하나가 요약 뒤에도 지켜지는지 확인하고, 사라졌다면 CLAUDE.md로 옮겨 봐요.

## 오늘 바로 써먹기

- 일이 바뀌면 `/clear`, 같은 일이 길어지면 `/compact 남길 것`
- 계속 지켜야 하는 규칙은 대화가 아니라 프로젝트 맨 위 CLAUDE.md에
- 스킬 맨 위 몇 줄에 가장 중요한 지시 쓰기

## 자주 하는 오해

- "요약하면 모든 게 그대로 남는다?" 요약은 줄이는 일이라 세부가 사라질 수 있어요.
- "`/clear`하면 CLAUDE.md도 사라진다?" 새 대화에서도 CLAUDE.md는 다시 읽혀요.
