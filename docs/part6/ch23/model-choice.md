# 모델은 어떻게 고를까

!!! abstract "이 페이지에서 배우는 것"
    - 모델은 ==크기·속도·비용의 거래==예요. 기본값이 대부분의 일에 충분해요.
    - 이름이 아니라 **별명(alias)** 으로 고르면 모델이 바뀌어도 따라가요.
    - 고르는 법: 일상 → 기본, 가벼운 일 → 작은 모델, 가장 어렵고 긴 일 → 가장 큰 모델

## 1. 자전거, 자동차, 비행기

가까운 가게에는 자전거, 도시 사이에는 자동차, 먼 나라에는 비행기를 타죠. 비행기가 항상 좋은 건 아니에요. 가게 가는 데 비행기를 타면 비싸고 번거로워요. AI 모델도 같아요. 큰 모델은 어려운 일에 강하지만 느리고 비싸요. 작은 모델은 빠르고 싸요.

## 2. 별명으로 고르기

공식 문서가 알려 주는 별명이에요(Anthropic API로 연결한 경우, 2026-11-07 확인).

| 별명 | 뜻 | 이 날짜의 결과 |
|---|---|---|
| `default` | 내 계정의 기본값으로 되돌리기 | 계정마다 달라요 |
| `sonnet` | 평소 코딩과 일상 작업용 | Sonnet 5.5 |
| `opus` | 복잡한 추론용 | Opus 5.5 |
| `haiku` | 빠르고 가벼운 일용 | Haiku 5.5 |
| `fable` | 가장 어렵고 가장 오래 걸리는 일용 | 직접 골라야 해요(기본값이 아니에요) |
| `opusplan` | 계획할 때는 opus, 실행할 때는 sonnet | 5.9의 계획 모드와 이어져요 |

별명이 가리키는 버전은 연결 방식(Anthropic API, Amazon Bedrock 등)마다 다를 수 있어요. 그래서 모델 이름을 외우기보다 별명과 `/model`로 확인하는 습관이 좋아요.

## 3. 고르는 법

공식 모범 사례의 요약을 쉬운 말로 줄이면 이래요.

- **기본 모델**은 대부분의 코딩을 잘 다뤄요. 처음에는 바꾸지 않아도 돼요.
- **Sonnet**은 평범한 작업에서 비용이 덜 들어요.
- **Haiku**는 단순한 일을 맡는 서브에이전트에 어울려요(5.8의 `researcher`처럼요).
- **Fable**은 한 번에 끝나지 않는 큰 일에 쓰라고 문서가 설명해요. 조사하고, 확인하고, 오래 일하는 데 강하다고 해요.

우리 채널 예시로 보면, 책 페이지의 링크를 조사하는 `researcher`는 Haiku나 Sonnet으로, 장면표를 쓰는 `scriptwriter`는 기본 모델로, 큰 구조를 바꾸는 계획은 `opusplan`이나 Fable로 정하는 식이에요. 이건 이 책의 제안이고, 내 환경과 비용에 맞춰 직접 시험해서 정해야 해요.

## 4. 바꾸는 법

- 대화 중: `/model sonnet`처럼 입력해요. `/model`만 입력하면 고르는 창이 열려요. 창에서 `Enter`를 누르면 기본값으로 저장하고, `s`를 누르면 이번 대화에서만 바꿔요.
- 시작할 때: `claude --model sonnet`
- 서브에이전트: 5.8에서 본 `model:` 칸

!!! tip "10살 눈높이 한 줄 요약"
    가까운 길은 자전거, 먼 길은 비행기. 일에 맞는 모델을 타요.

!!! note "★ 한 걸음 더 (심화)"
    공식 문서에는 모델이 갑자기 쓸 수 없거나 안전 분류기에 걸릴 때 다른 모델로 자동으로 넘어가는 "자동 대체" 기능도 설명돼 있어요. 또 조직 관리자가 쓸 수 있는 모델을 제한할 수도 있어요. 내 `/model` 목록이 이 책과 다르면 그 때문일 수 있어요.

## 직접 해보기

1. `/model`을 열어 지금 쓰는 모델과 고를 수 있는 목록을 확인해요.
2. 같은 작은 일(예: 페이지 요약)을 `haiku`와 기본 모델로 한 번씩 시켜 보고, 결과와 걸린 시간을 비교해요. 이때 `s`를 눌러 이번 대화에서만 바꿔 보세요.
3. `/usage`로 사용량 변화를 확인해요.

## 오늘 바로 써먹기

- 가벼운 반복 일은 작은 모델로, 헷갈리는 큰 일은 큰 모델로
- 모델 이름 대신 별명을 쓰고, `/model`로 확인하기
- 비교는 "같은 일, 두 모델"로 직접 해 보기. 남의 평가는 내 일에 안 맞을 수 있어요.

## 자주 하는 오해

- "비싼 모델이 항상 낫다?" 일에 따라 낭비일 수 있어요.
- "별명은 영원히 같은 모델이다?" 별명은 최신 버전을 가리켜서 시간이 지나면 바뀌어요. 그래서 이 페이지에 날짜를 적었어요.
