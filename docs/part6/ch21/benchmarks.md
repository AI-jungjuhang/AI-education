# 벤치마크의 함정 ★

<p class="ep-meta"><span>21장 · 21.1 · 심화</span><span>읽는 시간 약 8분</span><span>2026-11-07</span></p>

!!! abstract "이 페이지에서 배우는 것"
    - **벤치마크**는 AI를 공통 시험지로 비교하는 점수표인데, ==점수가 곧 "내 일에서의 실력"은 아니다.==
    - 시험 문제가 학습 자료에 새어 들어가는 문제(오염), 점수 매기는 방식(잣대), 사람의 선호와 정확성의 차이 같은 함정이 있다.
    - 점수표를 읽는 체크리스트를 가지면 "1등 모델" 뉴스를 차분하게 볼 수 있다.

## 1. 전교 1등의 시험지

전교 1등이 수학 시험에서 100점을 받았다고 해서 그 학생이 요리도 잘하고 노래도 잘 부르는 건 아니죠. 시험이 **무엇을 재는지**가 중요해요. 게다가 시험 문제를 미리 알았다면 점수는 의미가 줄어들어요.

AI 모델도 마찬가지예요. 새 모델이 나올 때마다 "○○ 시험에서 1등"이라는 소식이 있지만, 그 시험이 내 일과 얼마나 닮았는지는 별개예요.

!!! tip "10살 눈높이 한 줄 요약"
    점수는 **그 시험을 잘 본다**는 뜻이에요. 내 일을 잘한다는 뜻은 아니에요. 시험 문제가 미리 새어 나갔다면 더 그래요.

## 2. 대표적인 시험지들

| 시험 | 무엇인가 (논문 초록 기준) |
|---|---|
| **MMLU** (2020) | 초등 수학, 미국사, 컴퓨터 과학, 법 등 **57개 과제**로 모델의 다분야 정확도를 재는 시험. 큰 GPT-3도 평균 약 20%p 정도 무작위보다 나았을 뿐이었고, 모델들의 성능이 **들쭉날쭉**하고 **자기가 틀린 걸 자주 모르며**, 도덕과 법 같은 분야는 거의 무작위 수준이었다고 보고했어요 |
| **HELM** (2022) | 정확도 하나만 보지 않고 **7가지 지표**(정확도, 보정, 강건성, 공정성, 편향, 독성, 효율)를 **16개 핵심 시나리오**에서 재요. 30개 모델을 같은 조건으로 비교했는데, 이전에는 모델들이 핵심 시나리오의 **평균 17.9%에서만** 평가됐고 공통 시나리오가 하나도 없는 모델 쌍도 있었다고 해요 |
| **Chatbot Arena** (2024) | 사람들이 **두 챗봇의 답을 나란히 보고 더 좋은 쪽을 고르는** 방식. 24만 표 이상이 모였고, 사람 투표가 전문 평가자의 판단과 잘 맞는다고 보고했어요 |

## 3. 함정 다섯 가지

**① 시험 문제가 새어 나갔다 (오염/누출).** *Don't Make Your LLM an Evaluation Benchmark Cheater*(2023)는 평가용 데이터가 우연히 모델 학습에 쓰이는 **벤치마크 누출**을 다뤄요. 사전 학습 자료를 시험보다 먼저 준비하는 경우가 많아서 이 현상이 점점 흔해졌고, 실험해 보니 누출이 **평가 결과를 극적으로 높일 수 있어서** 모델 성능에 대한 믿을 수 없는 평가가 된다고 해요.

**② 잣대가 결론을 바꾼다.** 20장에서 본 것처럼 측정 방법에 따라 "갑자기 생긴 능력"이 보이기도 사라지기도 해요.

**③ 평균이 숨기는 것.** MMLU에서도 모델 성능이 **들쭉날쭉**했어요. 평균 점수가 높아도 내가 필요한 분야에서 약할 수 있어요. 8장의 "들쭉날쭉한 기술 경계"와 같은 이야기예요.

**④ 사람의 선호 ≠ 정확성.** Chatbot Arena는 **사람이 더 좋아하는 답**을 재는 시험이에요. 자신 있고 매끄럽게 쓴 답이 선호될 수 있고, 사실이 맞는지는 별개예요(9장 사람 피드백의 한계, 3장 맞장구). 이 시험이 나쁘다는 게 아니라 **무엇을 재는지**를 알아야 한다는 뜻이에요.

**⑤ 내 일과 다른 시험.** 영어 객관식 문제 점수는 내가 쓰는 한국어 보고서 작성과 거리가 있을 수 있어요.

!!! note "★ 한 걸음 더 (심화)"
    - HELM 논문은 **무엇이 빠졌는지도 밝히는 것**이 평가의 투명성이라고 봐요(예: 영어의 소외된 방언에 대한 질의응답, 신뢰성 지표가 부족하다고 스스로 적었어요).
    - 벤치마크는 쓰다 보면 **포화**돼요. 모델들이 거의 만점을 받으면 더 이상 구분하지 못해서 새 시험이 필요해져요. 15장 평가에서 본 "시험 문제를 일부 숨겨 두기"가 오염을 막으려는 같은 생각이에요.
    - 사람 선호를 모으는 방식은 질문의 분포(어떤 사람이 어떤 질문을 하는가)에 영향을 받아요. 논문은 질문이 충분히 다양하고 구분력이 있다고 분석했지만, 모든 용도를 대표한다는 뜻은 아니에요.

## 직접 해보기

최근에 본 "○○ 모델이 1등"이라는 소식 하나를 골라 점검해 보세요.

| 점검 | 내 답 |
|---|---|
| 어떤 시험으로 쟀나? | |
| 누가 쟀나? (모델 만든 회사인가, 제3자인가?) | |
| 무엇을 재는 점수인가? (정확도? 사람 선호? 속도?) | |
| 시험 문제가 학습 자료에 들어갔을 가능성은? | |
| 내가 쓰는 일과 닮았나? | |
| 언제 쟀나? (모델과 시험이 최신인가?) | |

칸을 채우기 어렵다면 그 소식은 "참고"로만 읽으세요.

## 오늘 바로 써먹기

1. **점수 옆의 시험 이름과 잣대를 보세요.** "1등"이라는 말만 믿지 마세요.
2. **만든 회사가 직접 낸 점수는 한 번 더 확인하세요.** 같은 모델을 제3자가 잰 결과와 비교하세요.
3. **내 일로 시험하세요.** 15장의 "가벼운 평가"가 내 일에는 도움이 돼요.
4. **사람 선호 순위는 "정확한가"와 같지 않다는 점을 기억하세요.** 정확성은 따로 확인하세요.
5. **오래된 순위는 믿지 마세요.** 모델도 시험도 빠르게 바뀌어요.

## 자주 하는 오해

- "점수가 높으면 모든 일을 잘한다" → 시험이 재는 것만 보여 줘요.
- "벤치마크는 쓸모없다" → 비교의 출발점으로 유용해요. 한계를 알고 쓰면 돼요.
- "사람이 뽑은 1등이 가장 정확하다" → 사람이 좋아하는 답과 맞는 답은 달라요.
