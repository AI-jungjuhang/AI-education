# 열 살도 이해하는 AI

챗봇을 매일 쓰는데도 "왜 이렇게 답하지?" 싶었다면, 이 책이 그 이유를 알려 줘요.
어려운 말은 빼고, 내용 수준은 낮추지 않았어요.

[전체 길 보기](#길){ .md-button }

## 이 책이 도와주는 것

<div class="grid cards" markdown>

-   **그럴듯한 거짓말을 알아본다**

    챗봇이 왜 틀리게 답하는지 알면, 어떤 답을 의심해야 하는지 보여요.

-   **질문이 달라진다**

    답이 엇나가는 이유를 알면, 같은 일을 시키는 질문도 더 잘 쓰게 돼요.

-   **페이지마다 바로 써본다**

    읽고 끝나지 않아요. 페이지마다 2분 실험과 복사해서 쓰는 예시가 있어요.

-   **영상으로도 볼 수 있다**

    모든 주제 페이지는 3~5분 영상으로도 만들 예정이에요. (영상은 v0.2부터)

</div>

## 길 { #길 }

처음부터 끝까지 읽어도 되고, 필요한 부만 골라 읽어도 돼요. ★는 심화예요.

| 부 | 이 부에서 | 상태 |
|---|---|---|
| I 처음 쓰는 AI | 챗봇이 뭘 하는 기계인지, 왜 틀리는지 | **작성 중** (1장) |
| II 일에 붙이기 | 글쓰기·조사·정리에 바로 쓰는 방법 | 준비 중 |
| III 원리 한 스푼 | 토큰, 학습, 확률을 한 스푼씩 | 준비 중 |
| IV 도구와 에이전트 | 검색·파일·도구를 쓰는 AI | 준비 중 |
| V 원리로 쓰기 ★ | 원리를 알고 판단하며 쓰기 | 준비 중 |
| 부록 | 용어와 참고 자료 | 준비 중 |
