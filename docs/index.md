# 챗봇이 왜 그렇게 답하는지 알려 주는 책

챗봇을 매일 쓰는데도 "왜 이렇게 답하지?" 싶었다면, 이 책이 그 이유를 알려 줘요.
어려운 말은 빼고, 내용 수준은 낮추지 않았어요.
