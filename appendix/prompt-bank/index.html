    책에서 만든 질문 틀을 상황별로 모았어요. 칸을 채워서 쓰고, 잘 되면 8장처럼 이름을 붙여 저장하세요. 예시는 시작점이에요. 내 일에 맞게 고치고, 결과는 3장의 방법으로 확인하세요.

    먼저 기억하세요

    • 개인정보, 비밀번호, 회사 기밀은 넣지 마세요(3장).
    • 틀은 결과를 대신 확인해 주지 않아요. 숫자, 이름, 인용은 직접 대조하세요(3장).

    고치기와 다듬기¶

    고쳐 달라고 말하기 (2장) 

    [어디]를 [어떻게] 바꿔 줘. [이유]야. [그대로 둘 것]은 유지해 줘.

    내용은 그대로 고쳐 쓰기 (5장) 

    의미는 바꾸지 말고, 원문에 없는 사실이나 숫자는 추가하지 마.
바꾼 부분은 [원문 → 수정] 형태로 목록으로 알려 줘.

    새 대화로 옮기기 위한 정리 (2장) 

    지금까지 대화에서 정해진 것을 정리해 줘.
- 목적:
- 읽는 사람:
- 꼭 지켜야 할 조건:
- 지금까지 마음에 든 부분:
- 마음에 안 든 부분과 그 이유:
새 대화에서 그대로 붙여 넣어 쓸 수 있게 간결하게 써 줘.

    쓰기와 정리¶

    개요 먼저 받기 (5장, 12장) 

    [목적]에 쓸 글이야. 요점은 1) ___ 2) ___ 3) ___ 이야. 독자는 ___야.
먼저 3문단 이내 개요를 제안해 줘. 글은 아직 쓰지 마.

    요약 (5장) 

    아래 글을 [읽는 사람]을 위해 요약해 줘.
조건: [개수]문장 이내, 숫자와 날짜는 그대로 남기기.
원문에 없는 내용은 추가하지 말고, 원문이 불확실하게 말한 부분은 불확실하다고 써 줘.
<글>(붙여 넣기)</글>

    회의록 (7장) 

    아래 회의 메모를 정리해 줘.
형식: 1) 결정된 것 2) 아직 안 정해진 것 3) 할 일 표(할 일 / 담당자 / 기한)
규칙: 메모에 없는 담당자나 기한은 만들지 말고 "미정"이라고 써 줘.
숫자와 날짜는 바꾸지 마. 해석이 필요한 부분은 "확인 필요"로 표시해 줘.
<메모>(붙여 넣기)</메모>

    두 대상 비교 (2장)

모르거나 확실하지 않은 칸에는 "확인 필요"라고 써 줘.
