# 쇼츠 084 · 강화학습과 추론 모델

- **원본 페이지:** 20.1.2 [강화학습과 추론 모델](../../../docs/part6/ch20/rl-reasoning.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 중간 생각을 쓰며 풀면 어려운 문제의 정확도가 오르지만, 적어 보인 생각이 실제 계산이라는 보장은 없다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 풀이를 쓰며 풀면 어려운 문제도 잘 풀어요 / 시험지의 풀이 공간처럼 중간 생각을 써요 |
| 2 | list | 연구의 흐름: 2022 생각의 사슬 → 단계를 쓰게 / 2024 생각 시간에 계산을 더 / 2025 강화학습으로 생각을 키우기 |
| 3 | split | 수학, 코딩, 다단계 계획 ↔ 간단한 질문, 취향 문제 |
| 4 | speech | 적어 보인 생각이 실제 계산과 같다는 보장은 없어요 → 풀이는 증거가 아니라 참고예요 |
| 5 | check | 오늘의 써먹기: 어려운 문제엔 단계별 풀이 요청 / 풀이를 읽으며 틀린 곳 찾기 / 생각을 적었어도 결과는 확인 |

## 확인할 점
- 연구 흐름은 원본의 Wei 외 2022, Snell 외 2024, DeepSeek-R1 2025를 줄인 말이에요.
