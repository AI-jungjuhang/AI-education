# 쇼츠 025 · 공부 도우미로 쓰기

- **원본 페이지:** 6.1.3 [공부 도우미로 쓰기](../../../docs/part2/ch06/tutor.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** AI 설명만 듣지 말고, AI가 낸 문제를 내가 풀며 떠올리는 연습을 한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 설명만 듣지 말고 문제를 풀어요 / 정답지만 베끼면 시험 때 못 풀잖아요 |
| 2 | split | 다시 설명해 줘 ↔ 나를 시험해 줘 |
| 3 | notes | 세 가지 공부법: 설명 듣고 바로 시험 / 문제 내기 / 내 설명 점검받기 |
| 4 | speech | 정답은 내가 답한 뒤에 알려 줘 → 그래야 머리가 떠올리는 연습을 해요 |
| 5 | check | 오늘의 써먹기: "설명해 줘" 다음에 "나를 시험해 줘" / 간격을 두고 다시 풀기 / 예: 오늘, 이틀 뒤, 일주일 뒤 / AI 설명은 교과서와 대조 |
