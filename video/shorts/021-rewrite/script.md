# 쇼츠 021 · 고쳐 쓰기와 말투 바꾸기

- **원본 페이지:** 5.1.2 [고쳐 쓰기와 말투 바꾸기](../../../docs/part2/ch05/rewrite.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 고쳐 쓸 땐 "의미는 그대로, 없는 사실은 더하지 마"를 붙이고, 바뀐 곳을 보여 달라고 한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 고쳐 쓸 땐 뜻은 그대로 / 옷만 갈아입히고 사람은 그대로예요 |
| 2 | split | 숫자나 뜻이 슬쩍 바뀔 수 있어요 ↔ "의미는 그대로, 없는 사실은 더하지 마" |
| 3 | notes | 이렇게 말해요: 맞춤법만 / 읽기 쉽게 / 말투 바꾸기 / 길이 줄이기 |
| 4 | speech | 바꾼 곳을 [원문 → 수정]으로 보여 줘 → 몰래 바뀐 곳을 찾기 쉬워요 |
| 5 | check | 오늘의 써먹기: 숫자와 부정문은 따로 확인하기 / 예: ~하지 않았다, 거의, 반드시 / 말투는 설명보다 견본으로 / 상대별로 여러 버전 받기 / 예: 팀장님용, 친구용 |

## 확인할 점
- 표의 "분위기 바꾸기" 행과 심화(왜 뜻이 바뀌나)는 뺐어요.
