# 쇼츠 041 · 온도: 얼마나 모험할까

- **원본 페이지:** 12.1.1 [온도: 얼마나 모험할까](../../../docs/part3/ch12/temperature.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 온도는 인기 있는 후보에 얼마나 몰아줄지 정하는 다이얼이고, 낮춰도 틀린 답은 남는다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 온도는 모험 다이얼이에요 / 낮추면 늘 안전한 말, 높이면 가끔 엉뚱한 말 |
| 2 | split | 1등 후보가 거의 매번 ↔ 여러 후보가 고르게 |
| 3 | speech | 1등 후보가 틀린 말이면 더 일관되게 틀려요 → 온도로 환각을 없앨 순 없어요 |
| 4 | list | 질문으로 조절하기: 다양하게: "10개 줘" / 독특하게: "더 독특하게" / 정확하게: 따로 확인하기 |
| 5 | check | 오늘의 써먹기: 정확성은 확인으로 해결 / 중요한 답은 여러 번 받아 비교 / 온도 설정이 보이면 직접 시험해 보기 |
