# 쇼츠 027 · 표와 엑셀 함수 도움받기

- **원본 페이지:** 7.1.2 [표와 엑셀 함수 도움받기](../../../docs/part2/ch07/tables.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 함수를 물을 땐 프로그램·열 이름·예시·원하는 결과를 알려 주고, 작은 데이터로 먼저 시험한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 함수를 물을 땐 내 표를 보여 줘요 / 재료를 알려 줘야 레시피를 주죠 |
| 2 | split | 합계 함수 알려 줘 ↔ 이런 표에서 이런 결과가 필요해 |
| 3 | notes | 알려 줄 네 가지: 프로그램 / 열 이름 / 예시 두세 줄 / 원하는 결과 |
| 4 | speech | 오류 메시지를 그대로 붙여 넣기 → #NAME?, #VALUE! 같은 메시지를 그대로요 |
| 5 | check | 오늘의 써먹기: 받은 함수는 작은 데이터로 시험 / 있는 함수인지 도움말로 확인 / AI가 없는 함수를 지어낼 수 있어요 / 진짜 이름 대신 가짜 데이터 쓰기 |

## 확인할 점
- 메모지 예시는 원본 부탁문(구글 시트, 홍길동/영업/120)에서 가져왔어요.
- 글↔표 바꾸기(2절)는 뺐어요.
