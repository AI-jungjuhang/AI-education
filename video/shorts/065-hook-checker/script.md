- **원본 페이지:** 17.2.2 [실습: 자동 검사관 달기](../../../docs/part5/ch17/hook-checker.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 고칠 때마다 "출처와 기준"을 검사하는 훅은 종료 코드로 답하고(2=문제), 등록 전에 혼자 먼저 돌려 본다.

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 고칠 때마다 검사관이 확인해요 / "출처와 기준" 절이 있는지 자동으로요 |
| 2 | split | 문제없어요 ↔ 문제 있어요 |
| 3 | list | 만드는 순서: 1. check-page.sh 쓰기 / 2. chmod +x로 실행 권한 / 3. 가짜 입력으로 혼자 돌려 보기 / 4. settings.json에 등록 |
| 4 | speech | 가짜 입력을 넣어 혼자 먼저 돌려 보기 → 절이 없으면 2, 있으면 0이 나와야 해요 |
| 5 | check | 오늘의 써먹기: 매번 부탁하던 점검은 훅으로 옮기기 / 새 훅은 혼자 돌려 본 뒤 등록 / 무거운 검사는 답을 마칠 때(Stop)로 |
