# 쇼츠 057 · 되돌리기로 마음 놓고 실험하기

- **원본 페이지:** 16.3.1 [되돌리기로 마음 놓고 실험하기](../../../docs/part5/ch16/checkpoint-rewind.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** Claude Code는 말을 보낼 때마다 자동 저장하니, /rewind로 코드와 대화를 따로 또는 같이 되돌린다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 말을 보낼 때마다 자동 저장돼요 / 게임의 저장 지점처럼 다시 도전할 수 있어요 |
| 2 | split | /rewind ↔ 코드만, 대화만, 둘 다 |
| 3 | list | 되돌리기 선택지: 코드와 대화 모두 / 대화만 / 코드만 / 여기서부터 요약 / 취소 |
| 4 | speech | 한쪽을 시켜 보고 별로면 코드만 되돌리기 → 그다음 다른 쪽을 시켜 보면 돼요 |
| 5 | check | 오늘의 써먹기: 큰 변경 전엔 방금 한 말이 저장 지점 / 입력창에 글자가 있으면 /rewind로 / Esc 두 번은 입력창을 비워요 / 긴 대화는 중간부터 요약 |

## 확인할 점
- 기준: Claude Code 2.1.319(원본 기준).
- 선택지 중 "여기까지 요약"은 목록 5개 한도 때문에 뺐어요.
