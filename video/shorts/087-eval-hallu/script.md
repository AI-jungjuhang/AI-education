# 쇼츠 087 · 환각은 어떻게 재나

- **원본 페이지:** 21.1.2 [환각은 어떻게 재나](../../../docs/part6/ch21/eval-hallu.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 환각을 재려면 틀림과 모름을 따로 채점해야 하고, 내 일의 오답 비율은 작은 시험으로 어림할 수 있다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | "틀림"과 "모름"은 따로 채점해요 / 찍는 게 이득이면 모두 찍잖아요 |
| 2 | split | 오답 0점, 패스 0점 ↔ 오답 −1점, 패스 0점 |
| 3 | list | 세 가지 시험: SimpleQA → 짧은 사실 질문 / TruthfulQA → 흔한 오해를 노린 질문 / FActScore → 긴 글을 사실로 쪼개기 |
| 4 | speech | 내 분야 질문 10~20개로 오답과 모름을 따로 세기 → 오답이 가장 위험한 값이에요 |
| 5 | check | 오늘의 써먹기: 긴 글은 중요한 주장 5개 확인 / "모르면 모른다고 해" 효과를 재 보기 / 모델이 바뀌면 같은 질문으로 다시 |

## 확인할 점
- 채점 예시(+1/−1/0)는 원본 1절 퀴즈 비유예요.
- 시험별 점수 숫자는 낡기 쉬워서 뺐어요.
