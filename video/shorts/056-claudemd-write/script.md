# 쇼츠 056 · 좋은 CLAUDE.md 쓰는 법

- **원본 페이지:** 16.2.2 [좋은 CLAUDE.md 쓰는 법](../../../docs/part5/ch16/claudemd-write.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 메모는 짧고, 확인할 수 있는 말로, 서로 부딪히지 않게 쓴다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 메모는 짧고 확인할 수 있게 / 흐릿한 말은 잘 안 지켜져요 |
| 2 | split | 코드를 깔끔하게 ↔ 들여쓰기는 칸 두 개로 |
| 3 | notes | 잘 지켜지는 메모: 짧게 / 묶어서 / 부딪히지 않게 |
| 4 | speech | CLAUDE.md에서 부딪히거나 낡은 지시를 찾아 줘 → 고치지 말고 목록으로만요 |
| 5 | check | 오늘의 써먹기: 중요한 규칙은 맨 위에, 이유와 함께 / 새 규칙은 무엇을·어디서·어떻게 / 코드로 알 수 없는 결정을 적기 / 예: 이름 규칙 |
