# 쇼츠 020 · 초안 만들기

- **원본 페이지:** 5.1.1 [초안 만들기](../../../docs/part2/ch05/first-draft.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** AI로 첫 초안을 빨리 받되, 요점은 내가 정하고 마무리는 내가 한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 초안은 AI로 빨리, 마무리는 내가 / 빵도 반죽부터 만들잖아요 |
| 2 | list | 네 단계로 써요: 1. 요점은 내가 정하기 / 2. 개요부터 받기 / 3. 문단별 초안 받기 / 4. 내 손으로 고치기 |
| 3 | speech | 3문단 개요를 제안해 줘. 글은 아직 쓰지 마 → 방향이 틀리면 일찍 고칠 수 있어요 |
| 4 | split | 누구나 쓸 법한 글이 되기 쉬워요 ↔ 내 말투에 가까워져요 |

- 말투 예시와 "[여기에 숫자]"는 원본 요령에서 가져왔어요.
- Science 2023 연구(시간 40%↓)는 숫자가 정확하지만 한 실험 결과라 영상에서는 뺐어요.
