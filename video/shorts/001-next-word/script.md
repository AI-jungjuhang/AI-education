# 쇼츠 001 · 챗봇은 '다음 말'을 맞히는 기계

- **원본 페이지:** 1.1.1 [챗봇은 '다음 말'을 맞히는 기계](../../../docs/part1/ch01/next-word.md)
- **형식:** 세로 9:16, 30fps, **35.2초**, 음성 없음. 마무리 장면 없음. `episode.json`을 재료 상자로 조립해요.
- **한 가지 생각:** 챗봇이 하는 일은 다음에 올 말 하나를 고르는 것이고, 그걸 반복하면 긴 답이 된다.
- **상태:** 초안(평가 대기)

| # | 박 | 화면 글 |
|---|---|---|
| 1 | 0–6 | 챗봇이 하는 일, / 딱 하나예요 / 다음에 올 말 고르기 |
| 2 | 6–15 | 오늘 점심은 라면이랑… / 김밥? 만두? 떡볶이? 우주선은 아니겠죠. |
| 3 | 15–23 | 후보마다 점수! / 숫자는 예시예요! |
| 4 | 23–31 | 주사위 뽑기! / 높은 말이 잘 뽑혀요 / 낮은 말도 가끔! |
| 5 | 31–43 | 뽑은 말은 뒤에 붙여요 / 하늘이 파란 이유는 / 또 뽑고, 또 뽑고! / 햇빛이 / 공기에 / 부딪혀 / … |
| 6 | 43–51 | 계속 반복하면? / 문장 / 문단 / 편지 한 통! |
| 7 | 51–63 | 그림은 이해를 돕는 예시예요 / 같은 질문인데… / 답은 매번 달라요! |
| 8 | 63–75 | 오늘의 써먹기 / 중요한 질문은 ==세 번== 물어보기 / 달라지는 부분은 ==더 의심하기== / 겹쳐도 틀릴 수 있어요 ==출처==로 확인 |

## 확인할 점
- 화면 글은 모두 원본 페이지의 내용을 짧게 줄인 거예요. 페이지에 없는 주장은 넣지 않았어요.
- 지어낸 예시는 화면에도 "예시"라고 밝히고, 단정할 수 없는 말은 "~할 수 있어요"로 썼어요.
