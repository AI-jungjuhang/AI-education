# 쇼츠 001 · 챗봇은 '다음 말'을 맞히는 기계 (v2)

- **원본 페이지:** 1.1.1 [챗봇은 '다음 말'을 맞히는 기계](../../../docs/part1/ch01/next-word.md)
- **형식:** 세로 9:16(1080×1920), 30fps, **41.25초**, 음성 없음(자막 + 배경음악·효과음)
- **박자:** 128bpm, 한 박 = 0.46875초, 총 88박. 모든 등장 시각은 박 단위이고 효과음은 `scene.html`의 `data-sfx`로 지정해요.
- **한 가지 생각:** 챗봇이 하는 일은 "다음에 올 말 하나를 고르는 것"이고, 그걸 반복하면 긴 답이 된다.
- **끝에 남길 행동:** 중요한 질문은 세 번 물어보고, 매번 달라지는 부분을 더 의심하기.
- **v2 바뀐 점:** v1(58초, 흰 바탕)이 "별로"라는 평가를 받아 팝 스티커 스타일로 다시 만들었어요(굵은 테두리 글자, 장면마다 색 전환, 박자에 맞춘 등장·효과음, 마스코트 감자).

## 만들 때 지킨 원칙

- 원본 페이지에 **없는 말은 넣지 않았어요.** 숫자는 "예시"라고 화면에도 밝혀요.
- 감자 마스코트는 이 채널용으로 새로 그린 원작 캐릭터예요. 기존 캐릭터를 닮게 하지 않았어요.
- 글자는 가운데 위쪽에 두고 쇼츠 화면 아래쪽(설명·버튼 영역)을 비웠어요.
- 음악과 효과음은 `make_music.py`가 직접 합성해서 저작권 문제가 없어요.
