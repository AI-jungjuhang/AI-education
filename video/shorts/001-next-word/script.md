# 쇼츠 001 · 챗봇은 '다음 말'을 맞히는 기계

- **원본 페이지:** 1.1.1 [챗봇은 '다음 말'을 맞히는 기계](../../../docs/part1/ch01/next-word.md)
- **형식:** 세로 9:16(1080×1920), 30fps, **58초**, 음성 없음(자막 + 배경음악)
- **한 가지 생각:** 챗봇이 하는 일은 "다음에 올 말 하나를 고르는 것"이고, 그걸 반복하면 긴 답이 된다.
- **끝에 남길 행동:** 중요한 질문은 세 번 물어보고, 매번 달라지는 부분을 더 의심하기.
- **기준 날짜:** 2026-11-07 · **상태:** 초안(평가 대기)

## 장면표

자막이 곧 내레이션이라서 한 화면의 글은 짧게 하고 읽을 시간을 줬어요. 아래 "근거"는 원본 페이지의 어느 부분에서 가져왔는지 보여 줘요.

| # | 시간 | 화면 글 | 근거 (원본 페이지) |
|---|---|---|---|
| 1 | 0–5초 | AI 챗봇이 하는 일은 / **다음 말 맞히기** / 딱 이것뿐이에요 | 요약 상자 "챗봇이 실제로 하는 일은 다음에 올 말 하나를 고르는 것" |
| 2 | 5–13초 | 친구가 말했어요 "오늘 점심은 라면이랑 …" / 다음 말은? 김밥 · 만두 · 떡볶이 / ~~우주선~~ | 1절 "문장 이어 말하기 놀이" |
| 3 | 13–22초 | 챗봇은 후보마다 점수를 매겨요 / 김밥 30% 만두 20% 떡볶이 15% 우주선 거의 0% / **숫자는 예시예요** | 2절 점수표. 표 아래 "지어낸 예시" 문구를 화면에도 넣음 |
| 4 | 22–30초 | 그다음 주사위를 굴려요 / 높은 말이 잘 뽑혀요 / 낮은 말도 가끔 뽑혀요 | 2절 "주사위를 굴리듯 하나를 뽑아요" |
| 5 | 30–40초 | 뽑은 말은 글 뒤에 붙고 / 또 다음 말을 골라요 / 하늘이 파란 이유는 → 햇빛이 → 공기에 → 부딪혀 | 3절 "반복하면 답이 된다" 코드 예시 |
| 6 | 40–45.5초 | 이걸 계속 반복하면 / 문장 · 문단 · 편지 한 통 | 1절 마지막 문단 |
| 7 | 45.5–53초 | 그래서 같은 질문도 답이 조금씩 달라요 / **써먹기:** 중요한 질문은 세 번 물어보고, 매번 달라지는 부분을 더 의심하세요 | 2절 마지막 문단 + "오늘 바로 써먹기" 1번 |
| 8 | 53–58초 | 다음 편: 글자를 '토큰'으로 읽는다 / 열 살도 이해하는 AI / 자세히·출처: 책 사이트 주소 | 1.1.2 예고, 사이트 주소 |

## 만들 때 지킨 원칙

- 원본 페이지에 **없는 말은 넣지 않았어요.** 숫자(30%, 20%, 15%)는 페이지에서도 "지어낸 예시"라고 밝혔고, 영상에도 "숫자는 예시예요"를 크게 넣었어요.
- 쇼츠 화면에서 가려지는 영역(아래 약 20%, 오른쪽 가장자리)을 피해 글을 가운데 위쪽에 배치했어요.
- 음성이 없으므로 모든 정보가 글로 전달돼요. 한 화면의 글자는 약 35자 이하로 줄였어요.
- 배경음악은 `make_music.py`로 직접 작곡해서 저작권 문제가 없어요. 유튜브 오디오 보관함 음악으로 바꿔도 돼요.
- 출처는 영상 끝에 사이트 주소로 안내해요. 페이지의 "출처와 기준"에서 Karpathy와 3Blue1Brown 원전을 확인할 수 있어요.
