# 쇼츠 052 · 평가하고 고치기

- **원본 페이지:** 15.1.3 [평가하고 고치기](../../../docs/part4/ch15/evaluate.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 느낌 대신 성공 기준과 시험 문제로 점수를 재고, 한 곳씩 고쳐 다시 잰다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 느낌 대신 점수를 재요 / 운동선수도 기록을 재고 고치잖아요 |
| 2 | speech | 문의 10개 중 9개 이상 정확한 규정 인용 → 기준이 있어야 나아졌는지 알 수 있어요 |
| 3 | notes | 시험 문제 10개: 쉬운 것 6개 / 어려운 것 3개 / 이상한 것 1개 |
| 4 | split | 여러 곳을 한꺼번에 ↔ 한 곳만 고치고 다시 재기 |
| 5 | check | 오늘의 써먹기: 시험 문제 몇 개는 숨겨 두기 / 고칠 땐 보지 않고 마지막에만 / AI 채점도 일부는 사람이 확인 / 모델이 바뀌면 같은 시험으로 다시 |

## 확인할 점
- 성공 기준 예시와 6·3·1 구성은 원본 3절의 예예요.
