# 쇼츠 018 · 무료와 유료는 뭐가 다를까

- **원본 페이지:** 4.1.2 [무료와 유료는 뭐가 다를까](../../../docs/part1/ch04/free-paid.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 유료라고 더 정확한 건 아니니, 내 일에 그 차이가 필요한지 기록해 보고 정한다.
- **상태:** 초안(평가 대기)

| # | 화면 | 원본 페이지의 근거 |
|---|---|---|
| 1 | 유료라고 더 정확하진 않아요 / 차이는 얼마나 많이, 얼마나 큰 일을 하느냐예요 | 1절, 한 줄 요약 |
| 2 | 1. 무료로 충분할 때: 가끔 묻고 글 다듬기 / 2. 유료를 생각할 때: 매일 한도에 자주 걸릴 때 | 3절 |
| 3 | 이걸 비교해요: 사용량 / 모델 / 기능 / 데이터 설정 | 2절 표(안정성 행은 뺌) |
| 4 | 무료로 일주일 쓰며 한도 걸린 날 적기 → 중요한 일이 막혔다면 그때 유료 | 4절 1·2, 직접 해보기 |
