# 쇼츠 085 · 정렬: 사람의 뜻에 맞추기

- **원본 페이지:** 20.1.3 [정렬: 사람의 뜻에 맞추기](../../../docs/part6/ch20/alignment.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 정렬은 AI가 말뿐 아니라 뜻을 알아듣게 하는 일이고, 아직 어려운 문제가 남아 있으니 중요한 규칙은 구조로도 지킨다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 말뿐 아니라 뜻을 알아듣게 / "방 치워"에 물건을 다 버리면 곤란하죠 |
| 2 | split | 사람이 답에 순위 매기기 ↔ 원칙 목록으로 AI가 스스로 비평 |
| 3 | notes | 아직 어려운 것: 진실보다 맞장구 / 그럴듯한 가짜 추론 / 조르면 규칙이 무너져요 / 설명과 속이 달라요 |
| 4 | speech | 말로만 두지 말고 권한과 승인으로도 → 구조로 지키면 더 든든해요 |
| 5 | check | 오늘의 써먹기: 서비스의 사용 정책 한 번 읽기 / 거절을 우회하려 하지 않기 / "해결됐다"도 "망한다"도 근거 확인 |

## 확인할 점
