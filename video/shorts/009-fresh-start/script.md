# 쇼츠 009 · 새 대화가 나을 때

- **원본 페이지:** 2.2.2 [새 대화가 나을 때](../../../docs/part1/ch02/fresh-start.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 32초. `episode.json`을 재료 상자로 조립했어요.
- **한 가지 생각:** 대화가 길어지거나 계속 엇나가면, 정리해서 새 대화로 옮기는 편이 낫다.
- **상태:** 초안(평가 대기)

| # | 화면 | 원본 페이지의 근거 |
|---|---|---|
| 1 | 길어진 대화는 새로 시작해요 / 낙서 가득한 칠판처럼 중요한 게 묻혀요 | 1절 칠판 비유 |
| 2 | (예) 아까 정한 조건 어디 갔어? → 조건이 묻혀요 / 엇나간 답도 계속 영향 | 1절, 2절 표 |
| 3 | 새 대화가 나은 때: 고쳐도 계속 엇나갈 때 / 아주 길어졌을 때 / 주제가 바뀔 때 | 2절 표 1·2·3행 |
| 4 | 1. 정해진 것을 정리해 줘 → 2. 정리한 걸 첫 메시지로(틀린 곳은 고쳐서) | 3절 |
| 5 | 안 된 이유도 적어 줘 → 같은 실수를 피하기 쉬워요 | 오늘 바로 써먹기 2 |
| 6 | 오늘의 써먹기 3개 | 오늘 바로 써먹기 1·3·4 |

## 확인할 점
- "세 번 고쳐도"는 책의 경험칙이라 영상에서는 "몇 번 고쳐도"로 썼어요(정확하지 않은 숫자는 쓰지 않는 규칙).
- 2장면 첫 말풍선과 3장면 "여행 계획 → 보고서"는 지어낸 예시라 "예:"로 밝혔어요.
- 표의 4행(처음 조건을 자꾸 잊을 때)은 2장면 말풍선으로 옮겼어요. 심화(컨텍스트 로트, 자동 압축, 기억 기능)는 뺐어요.
- 첫 장면은 비유 대신 핵심을 바로 말하게 바꾸고, 비유는 스티커로 남겼어요(사용자 피드백, 2026-11-08).
