- **원본 페이지:** 17.1.3 [남의 스킬과 설정을 열기 전에](../../../docs/part5/ch17/skill-safety.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 남의 저장소 .claude/에는 내 컴퓨터에서 실행될 것이 있으니, 열기 전에 읽고 모르는 폴더에서는 claude -p를 쓰지 않는다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 남의 .claude/는 열기 전에 읽어요 / 낯선 집 규칙 쪽지는 따르기 전에 먼저 읽죠 |
| 2 | split | claude -p ↔ 대화 모드로 열고 확인 창 보기 |
| 3 | list | 열기 전 점검표: 1. settings.json의 hooks / 2. .mcp.json의 서버 / 3. 스킬의 ! 줄, allowed-tools / 4. CLAUDE.md의 이상한 지시 |
| 4 | speech | --bare로 실행 → 프로젝트의 훅, 스킬, MCP 서버를 읽지 않아요 |
| 5 | check | 오늘의 써먹기: 열기 전에 설정 파일부터 읽기 / .claude/ 폴더와 .mcp.json / 확인 창의 "믿기"는 이유가 분명할 때만 / 내 스킬도 나누기 전 ! 줄 다시 보기 |
