# 쇼츠 029 · 자주 쓰는 질문 모아 두기

- **원본 페이지:** 8.1.1 [자주 쓰는 질문 모아 두기](../../../docs/part2/ch08/prompt-library.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 잘 통한 질문은 이름을 붙여 모아 두고, 성공 기준으로 시험하며 고친다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 잘 통한 질문은 모아 두세요 / 맛있게 된 요리는 레시피를 적어 두잖아요 |
| 2 | notes | 한 항목에 적을 것: 이름 / 언제 쓰나 / 틀 / 주의할 점 |
| 3 | speech | 성공 기준 한 줄 정해 두기 → 예: 숫자는 그대로, 5문장 이내 |
| 4 | list | 가볍게 시험하기: 시험 입력 3개 준비 / 고칠 때마다 3개로 다시 / 다른 곳이 나빠졌는지 보기 |
| 5 | check | 오늘의 써먹기: 주의할 점 칸 꼭 채우기 / 예: 실수했던 경험 / 한 달에 한 번 정리하기 / 공유할 땐 개인정보 지우기 |

## 확인할 점
- 메모지 예시는 원본 2절 표의 예예요.
- 저장 장소(3절)와 "세 번 쓴 질문"은 010과 겹쳐서 뺐어요.
