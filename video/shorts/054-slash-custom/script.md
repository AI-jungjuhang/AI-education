# 쇼츠 054 · 내 단축 명령 만들기

- **원본 페이지:** 16.1.2 [내 단축 명령 만들기](../../../docs/part5/ch16/slash-custom.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 자주 하는 부탁은 SKILL.md 파일 하나로 저장해 /이름으로 부른다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 자주 하는 부탁은 /이름으로 불러요 / 같은 말을 세 번 쳤다면 버튼으로 만들 때예요 |
| 2 | list | /easy 만들기: 1. ~/.claude/skills/easy 폴더 / 2. 그 안에 SKILL.md / 3. 위엔 설명, 아래엔 지시문 / 4. /easy로 부르기 |
| 3 | notes | SKILL.md 속 칸: 설명 칸 / 받는 말 / 부를 때만 |
| 4 | speech | /easy 토큰이 뭔지 설명한 글 → 뒤에 적은 말이 $ARGUMENTS 자리에 들어가요 |
| 5 | check | 오늘의 써먹기: 이름은 짧게 영어 소문자로 / 예: /easy, /check / 지시문엔 무엇을·모양·하지 말 것 / 같은 부탁 세 번이면 파일로 만들기 |
