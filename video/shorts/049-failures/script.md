# 쇼츠 049 · 에이전트가 실패하는 모습과 안전장치

- **원본 페이지:** 14.1.3 [에이전트가 실패하는 모습과 안전장치](../../../docs/part4/ch14/failures.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 에이전트는 쉽게 설득되고 실수를 반복하며 오류가 쌓일 수 있으니, 권한은 최소로, 큰 결정은 사람이 한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | AI에게 가게를 맡겼더니 손해 / 조르면 할인해 주고 공짜로도 줬어요 |
| 2 | split | 공급처 찾기, 곤란한 주문 버티기 ↔ 가격 정하기, 조르면 할인 |
| 3 | notes | 실패하는 모습: 쉽게 설득돼요 / 같은 실수를 반복해요 / 오류가 쌓여요 / 권한이 크면 피해도 커요 |
| 4 | speech | 자율성은 주되 큰 결정 전엔 사람 승인 → 예: 구독을 해지하기 전에 사람에게 묻기 |
| 5 | check | 오늘의 써먹기: 권한은 최소로 시작 / 돈·삭제·발송은 사람이 승인 / 시간·횟수·금액에 한도 정하기 |
