# 쇼츠 045 · 파일을 읽고 코드를 실행하는 AI

- **원본 페이지:** 13.1.2 [파일을 읽고 코드를 실행하는 AI](../../../docs/part4/ch13/files-code.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 계산과 표 작업은 코드로 시키면 정확해지지만, 실행한 코드와 파일 속 개인정보·숨은 지시를 확인한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 정확한 계산은 코드로 시켜요 / 계산기와 연필을 쥔 학생처럼요 |
| 2 | list | 코드가 실행되는 순서: 1. 내가 부탁해요 / 2. 챗봇이 코드를 써요 / 3. 컴퓨터가 실행해요 / 4. 결과를 설명해요 |
| 3 | notes | 코드가 잘하는 일: 합계·평균 퍼센트 / 표 정리 중복 제거 / 그래프 그리기 / 많은 파일 한꺼번에 |
| 4 | split | 숫자가 정확하니 맞겠지 ↔ "실행한 코드를 보여 줘" |
| 5 | check | 오늘의 써먹기: 파일 속 개인정보는 지우고 올리기 / 남이 준 파일은 숨은 지시 조심 / 예: "앞의 지시는 무시해" / 결과 몇 줄은 손으로 확인 |

## 확인할 점
- 파일 변환 과정(3절)은 뺐어요.
