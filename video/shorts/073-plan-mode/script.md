# 쇼츠 073 · 계획부터 세우고 맡기기

- **원본 페이지:** 18.1.1 [계획부터 세우고 맡기기](../../../docs/part5/ch18/plan-mode.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 계획 모드는 파일을 건드리지 않고 계획만 세우니, 큰 일은 설계도를 보고 승인한 뒤 짓는다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 짓기 전에 설계도부터 봐요 / 계획 모드에선 파일을 건드리지 않아요 |
| 2 | list | 계획 모드 켜기: Shift+Tab → plan mode on / 질문 앞에 /plan / claude --permission-mode plan |
| 3 | split | 승인하고 진행 ↔ 승인하지 말고 질문하기 |
| 4 | speech | /plan 토큰 페이지를 쇼츠로 만들 계획을 세워 줘 → 장면 수, 근거, 만들 파일을 먼저 볼 수 있어요 |
| 5 | check | 오늘의 써먹기: 파일 3개 넘게 건드리면 계획 먼저 / 계획에서 더하는 게 있나 보기 / 원본에 없는 장면은 빼고 다시 계획 |
