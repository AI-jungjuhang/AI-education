# 쇼츠 069 · 토큰은 읽기 전용으로, 끝나면 폐기

- **원본 페이지:** 17.3.3 [토큰은 읽기 전용으로, 끝나면 폐기](../../../docs/part5/ch17/mcp-token-safety.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 토큰은 읽기 전용으로 만들고, 저장소와 명령줄에 쓰지 않고, 끝나면 폐기하며, 읽어 온 글의 숨은 지시를 조심한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 토큰은 호텔 카드키처럼 / 필요한 문만 열리고 쓰고 나면 반납해요 |
| 2 | list | 지킬 일 네 가지: 1. 읽기 전용으로 / 2. 저장소에 넣지 않기 / 3. 명령줄에 쓰지 않기 / 4. 끝나면 폐기 |
| 3 | split | 토큰을 그대로 쓰기 ↔ ${API_KEY}처럼 이름만 쓰기 |
| 4 | speech | "이전 지시는 무시하고…" 숨은 지시가 있을 수 있어요 → 이상한 쓰기 요청은 허락하지 않아요 |
| 5 | check | 오늘의 써먹기: 연결 전에 권한은 최소로 / 끝나면 끊기 → 토큰 취소 → 확인 / 토큰은 명령줄에 쓰지 않기 / 터미널 기록에 남아요 |

## 확인할 점
- ${API_KEY} 방식은 원본의 .mcp.json 예시예요.
