# 쇼츠 060 · 파일을 넘겨 한 줄로 일 시키기

- **원본 페이지:** 16.4.2 [파일을 넘겨 한 줄로 일 시키기](../../../docs/part5/ch16/cli-pipe.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** |는 앞 결과를 뒤로 넘기는 관이라, cat 파일 | claude -p 한 줄로 파일을 읽혀 일을 시킬 수 있다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | |는 결과를 넘기는 관이에요 / 컨베이어 벨트처럼 파일을 AI에게 실어 보내요 |
| 2 | speech | cat error.log | claude -p "왜 났는지 세 줄로 설명해 줘" → 긴 오류도 복사 없이 바로 넘겨요 |
| 3 | list | 한 줄 더 붙이기: > 결과.md → 파일로 저장 / --output-format json → 프로그램용 / git diff main | … → 바뀐 것만 |
| 4 | split | 복사해서 붙여 넣기 ↔ 파이프로 넘기기 |
| 5 | check | 오늘의 써먹기: 넘기기 전에 비밀번호·개인정보 확인 / 같은 점검을 두 번 하면 명령을 적어 두기 / 결과는 >로 파일에 저장 |
