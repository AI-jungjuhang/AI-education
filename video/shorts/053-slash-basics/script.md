# 쇼츠 053 · 자주 쓰는 슬래시 명령

- **원본 페이지:** 16.1.1 [자주 쓰는 슬래시 명령](../../../docs/part5/ch16/slash-basics.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** /로 시작하는 말은 리모컨 버튼이고, 처음엔 일곱 개면 충분하며, 모르면 /help로 찾는다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | /로 시작하면 리모컨 버튼이에요 / 말로 길게 시키는 대신 버튼 하나로요 |
| 2 | list | 처음엔 일곱 개: /help 도움말 / /clear 새로 시작 / /compact 요약해서 자리 비우기 / /context 기억 공간 보기 / /model 모델 바꾸기 / /init 메모 만들기 / /rewind 되돌리기 |
| 3 | split | 칠판을 지우고 새로 시작 ↔ 칠판을 요약해 자리 만들기 |
| 4 | speech | /compact 결정 사항과 남은 할 일만 남겨 줘 → 필요한 것만 남아요 |
| 5 | check | 오늘의 써먹기: 답이 흐려지면 /context부터 / 이름이 기억 안 나면 /만 치고 찾기 / 명령은 외우지 말고 /help로 찾기 |

## 확인할 점
- 기준: Claude Code 2.1.319(원본 기준). 명령 목록은 바뀔 수 있어요.
