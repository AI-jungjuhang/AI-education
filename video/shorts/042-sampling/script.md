# 쇼츠 042 · 샘플링: 뽑는 방법

- **원본 페이지:** 12.1.2 [샘플링: 뽑는 방법](../../../docs/part3/ch12/sampling.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 다음 말을 뽑는 방법만 바꿔도 글 품질이 달라지니, 밋밋하면 여러 버전을 달라고 한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 뽑는 방법만 바꿔도 글이 달라져요 / 늘 같은 메뉴만 시키면 지루하잖아요 |
| 2 | list | 세 가지 뽑는 법: 1등만 → 밋밋하고 반복 / 확률대로 → 가끔 엉뚱 / 후보를 추려서 → 다양하고 덜 엉뚱 |
| 3 | speech | 같은 모델도 뽑는 방법만으로 품질이 크게 달라져요 → 엉뚱한 꼴찌 후보를 빼고 뽑는 방법을 제안했어요 |
| 4 | split | 똑같이 다시 묻기 ↔ "서로 다른 5가지 버전 줘" |
| 5 | check | 오늘의 써먹기: 같은 말이 반복되면 금지어 주기 / 예: '혁신적인'은 쓰지 마 / 엉뚱하면 다시 뽑아 보기 / 정확한 일은 확인 절차로 |

## 확인할 점
- 2019년 연구는 원본의 The Curious Case of Neural Text Degeneration(핵 샘플링)이에요.
