# 쇼츠 043 · 긴 답이 이어지는 과정

- **원본 페이지:** 12.1.3 [긴 답이 이어지는 과정](../../../docs/part3/ch12/long-answer.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 긴 답은 한 토큰씩 뽑아 이어 붙이는 반복이라 앞에서 엇나가면 뒤까지 이어지니, 개요 먼저 받고 나눠 쓴다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 긴 답은 한 토큰씩 이어 붙여요 / 이어달리기처럼 뛴 구간은 되돌릴 수 없어요 |
| 2 | list | 한 토큰의 일생: 1. 다음 말 점수표 만들기 / 2. 하나 뽑기 / 3. 글 뒤에 붙이기 / 4. 전체로 다시 계산 |
| 3 | notes | 그래서 생기는 일: 앞에서 엇나가면 뒤까지 / 앞 표현이 반복되기 쉬워요 / 길면 시간과 비용이 들어요 |
| 4 | split | 한 번에 다 써 줘 ↔ 개요 먼저, 문단별로 |
| 5 | check | 오늘의 써먹기: 끝으로 갈수록 모순과 반복 점검 / 글자 수는 대략으로만 보기 / 중간에 끊기면 "이어서 써 줘" |

## 확인할 점
- "속으로는 앞을 내다보기도 한다"는 연구 이야기는 뺐어요.
