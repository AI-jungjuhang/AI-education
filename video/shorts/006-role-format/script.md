# 쇼츠 006 · 역할, 형식, 예시를 정해 준다

- **원본 페이지:** 2.1.2 [역할, 형식, 예시를 정해 준다](../../../docs/part1/ch02/role-format.md)
- **형식:** 세로 9:16, 30fps, **27.2초**, 음성 없음. 마무리 장면 없음. `episode.json`을 재료 상자로 조립해요.
- **한 가지 생각:** 역할(옷)·형식(그릇)·예시(견본)를 정해 주면 원하는 쪽으로 답이 나올 가능성이 커진다.
- **상태:** 초안(평가 대기)

| # | 박 | 화면 글 |
|---|---|---|
| 1 | 0–6 | 옷, 그릇, / 견본! / 챗봇에게 정해 주세요 |
| 2 | 6–16 | 세 가지 / 역할 = 옷 · 말투와 관점 / 형식 = 그릇 · 결과의 모양 / 예시 = 견본 · 이런 느낌으로 |
| 3 | 16–26 | 역할 / 환각 위험은 그대로! / “초등학교 선생님처럼 설명해 줘” / 말투와 관점이 달라져요 / 단, 모르는 사실이 생기진 않아요 |
| 4 | 26–35 | 형식 / “표로”, “세 줄로” / “번호를 붙여서” / 고쳐 달라는 말이 줄어요 |
| 5 | 35–45 | 견본 보여 주기 / 예시는 3~5개, 서로 조금씩 다르게 / 감자 → 포슬포슬 감자샘 / 우유 → 하얀 구름 한 컵 / 그럼 ‘딸기’로 5개! |
| 6 | 45–58 | 써먹기 4개 / ‘역할·형식·예시’ 틀 저장 / 잘 나온 글을 견본으로 / 예시는 다양하게 / 사실 확인에 역할은 금물 |

## 확인할 점
- 화면 글은 모두 원본 페이지의 내용을 짧게 줄인 거예요. 페이지에 없는 주장은 넣지 않았어요.
- 지어낸 예시는 화면에도 "예시"라고 밝히고, 단정할 수 없는 말은 "~할 수 있어요"로 썼어요.
