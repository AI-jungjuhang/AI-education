# 쇼츠 006 · 역할, 형식, 예시를 정해 준다

- **원본 페이지:** 2.1.2 [역할, 형식, 예시를 정해 준다](../../../docs/part1/ch02/role-format.md)
- **형식:** 세로 9:16, 30fps, **28.6초**, 음성 없음. 마무리 장면 없음. `episode.json`을 재료 상자로 조립해요.
- **한 가지 생각:** 역할(옷)·형식(그릇)·예시(견본)를 정해 주면 원하는 쪽으로 답이 나올 가능성이 커진다.
- **상태:** 초안(평가 대기)

| # | 박 | 화면 글 |
|---|---|---|
| 1 | 0–6 | 옷, 그릇, / 견본! / 챗봇에게 정해 주세요 |
| 2 | 6–17 | 세 가지를 정해 주세요 |
| 3 | 17–27 |  |
| 4 | 27–38 | 아래 회의 메모를 정리해 줘. / 결정된 것은 최대 3개, 다음 할 일은 표로! / ==바로 쓸 수 있는 모양==을 정해 두면 고쳐 달라는 말이 줄어요 |
| 5 | 38–49 | 상품 이름 지어 줘. 이런 느낌으로! / 감자 → ==포슬포슬 감자샘== 우유 → ==하얀 구름 한 컵== / 예시는 3~5개, 서로 조금씩 다르게 주세요 |
| 6 | 49–61 | 오늘의 써먹기 / 예시는 다양하게 고르세요 / 역할·형식·예시를 ==한 줄씩== 적는 틀 만들기 / 잘 나온 글을 ==견본==으로 쓰기 / 사실 확인에는 ==역할을 쓰지 않기== |

## 확인할 점
- 화면 글은 모두 원본 페이지의 내용을 짧게 줄인 거예요. 페이지에 없는 주장은 넣지 않았어요.
- 지어낸 예시는 화면에도 "예시"라고 밝히고, 단정할 수 없는 말은 "~할 수 있어요"로 썼어요.
