# 쇼츠 008 · 고쳐 달라고 말하는 법

- **원본 페이지:** 2.2.1 [고쳐 달라고 말하는 법](../../../docs/part1/ch02/iterate.md)
- **형식:** 세로 9:16, 30fps, 음성 없음. `episode.json`을 재료 상자로 조립했어요.
- **한 가지 생각:** 고쳐 달라고 할 때는 "어디를, 어떻게"를 말하고, 마음에 든 부분은 "그대로"라고 알려 준다.
- **상태:** 초안(평가 대기)

| # | 화면 | 원본 페이지의 근거 |
|---|---|---|
| 1 | 고칠 곳을 콕 집어 말해요 / 미용실에서도 "좀 다르게요"는 어렵죠 | 1절 미용실 비유 |
| 2 | 좀 다르게 해 주세요 ↔ 앞머리만 짧게, 옆은 그대로 | 1절 |
| 3 | 별로야, 다시 해 줘 → 어디가 문제인지 알 단서가 없어요 | 1절 "단서가 없어요" |
| 4 | 고칠 때: 한 번에 한 가지 / 그대로 둘 부분 / 이유 / 여러 버전 | 3절 요령 1·2·3·5 |
| 5 | 딱딱해 ↔ 존댓말은 그대로, 문장 끝만 "~예요"로 | 2절 표 |
| 6 | 오늘의 써먹기 3개 | "오늘 바로 써먹기" 1·2(변경점 확인) |

## 확인할 점
- 요령 다섯 가지 중 "견본 한 줄"은 2.1.2에서 다뤄서 뺐어요.
- 미용실 비유는 원본 페이지에서 지은 비유예요.
- 챗봇 입장의 말풍선("알 단서가 없어요")은 챗봇의 실제 답이 아니라 설명이에요.
- 첫 장면은 비유 대신 핵심을 바로 말하게 바꾸고, 비유는 스티커로 남겼어요(사용자 피드백, 2026-11-08).
