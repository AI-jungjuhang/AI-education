# 쇼츠 058 · 체크포인트와 git은 뭐가 다를까

- **원본 페이지:** 16.3.2 [체크포인트와 git은 뭐가 다를까](../../../docs/part5/ch16/checkpoint-vs-git.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 체크포인트는 빠른 지우개, git은 오래 남는 사진첩이니 "저장 지점+커밋" 두 겹으로 일한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 체크포인트는 지우개, git은 사진첩 / 중요한 건 사진첩에 넣어요 |
| 2 | notes | 체크포인트가 못 하는 것: 명령창으로 바꾼 파일 / 다른 일꾼이 바꾼 파일 / 내가 밖에서 고친 파일 / 바로가기 링크 파일 |
| 3 | list | 두 겹 습관: 1. 시작 전에 커밋 / 2. 작업 중엔 /rewind / 3. 마음에 들면 다시 커밋 |
| 4 | speech | 바뀐 파일을 확인하고 커밋 메시지 초안을 써 줘 → 커밋은 확인한 뒤에 내가 해요 |
| 5 | check | 오늘의 써먹기: 서브에이전트 전엔 반드시 커밋 / 명령창으로 바꾼 건 git으로 되돌리기 / 일 하나 끝날 때마다 커밋하기 |

## 확인할 점
- "일 하나 끝날 때마다 커밋"은 원본의 "이 책 저장소도 페이지마다 커밋"을 일반화한 말이에요.
