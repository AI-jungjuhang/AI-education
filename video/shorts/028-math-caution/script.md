# 쇼츠 028 · 계산을 맡길 때 조심할 것

- **원본 페이지:** 7.1.3 [계산을 맡길 때 조심할 것](../../../docs/part2/ch07/math-caution.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 긴 계산은 AI에게 식만 세우게 하고 값은 계산기로 구하며, 돈과 건강은 전문가에게 확인한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 긴 계산은 중간에 틀리기 쉬워요 / 하나만 틀려도 뒤로 계속 이어져요 |
| 2 | speech | 숫자는 계산하지 말고 식만 단계별로 써 줘 → 잘못 이해한 곳도 찾기 쉬워요 |
| 3 | list | 계산은 이렇게: 평균·퍼센트 → 계산기로 / 날짜·요일 → 달력으로 / 세금·이자 → 공식 계산기 / 약 용량 → 의사·약사에게 |
| 4 | split | 3,800 × 2,900 = 110만 ↔ 크기부터 어림해 보기 |
| 5 | check | 오늘의 써먹기: 값 대신 식을 요청하기 / 날짜와 단위는 따로 확인 / 돈과 건강은 전문가에게 |

## 확인할 점
- 4장면의 "110만"은 원본의 어림 계산 예(3,800×2,900≈1,100만)로 만든 틀린 답 예시라 "예:"로 밝혔어요.
- Faith and Fate 연구와 Karpathy 강연은 뺐어요.
