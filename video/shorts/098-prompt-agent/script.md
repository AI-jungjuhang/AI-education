# 쇼츠 098 · 일을 맡기는 말은 어떻게 다를까

- **원본 페이지:** 23.2.2 [일을 맡기는 말은 어떻게 다를까](../../../docs/part6/ch23/prompt-agent.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 일을 맡길 땐 어디를 보고, 끝이 어떤 모양이고, 하지 말 것이 뭔지 말하고, 가진 것은 설명 대신 건넨다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 일을 맡길 땐 끝의 모양을 말해요 / AI는 폴더는 읽어도 내 머릿속은 못 봐요 |
| 2 | split | 영상 대본 만들어 줘 ↔ tokens.md를 근거로 60초 대본, 원본에 없는 말은 빼고 |
| 3 | notes | 세 줄로 맡기기: 어디를 / 어떤 모양으로 / 하지 말 것 |
| 4 | speech | 답하기 전에 파일을 먼저 열어서 읽어 → 열어 보지 않은 건 모른다고 말하게 해요 |
| 5 | check | 오늘의 써먹기: 설명 대신 @파일·스크린샷 건네기 / 범위는 숫자로 말하기 / 예: 도움말 3군데 / "어디를·모양·하지 말 것" 세 줄 쓰기 |

## 확인할 점
- 분명한 부탁 예시는 원본 2절 표(우리 채널 예)예요.
