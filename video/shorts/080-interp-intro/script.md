# 쇼츠 080 · 왜 모델 속을 봐야 할까

- **원본 페이지:** 19.1.1 [왜 모델 속을 봐야 할까](../../../docs/part6/ch19/interp-intro.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** AI는 학습으로 자라서 만든 사람도 속을 다 모르고, 챗봇이 말한 "생각 과정"은 실제와 다를 수 있으니 결과를 검증한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 만든 사람도 AI 속을 다 몰라요 / 학습으로 스스로 자란 시계 같아서요 |
| 2 | notes | 연구진이 궁금했던 것: 머릿속에선 어떤 언어로? / 앞을 내다보고 계획할까? / 설명한 단계를 정말 거쳤을까? |
| 3 | speech | 36 + 59는 어떻게 95야? → 1을 올려서… → 다른 방법으로 계산하고 있었어요 |
| 4 | split | 증거로 믿기 ↔ 결과를 검증하기 |
| 5 | check | 오늘의 써먹기: "생각 과정" 설명은 참고로만 / "왜?" 대신 "어떤 자료를 근거로?" / AI 속 이야기는 아직 연구 중 |

- "다른 방법으로 계산"은 원본의 "표준 방법과 다른 경로"를 줄인 말이에요.
