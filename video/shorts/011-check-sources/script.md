# 쇼츠 011 · 출처 확인하는 법

- **원본 페이지:** 3.1.1 [출처 확인하는 법](../../../docs/part1/ch03/check-sources.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초. `episode.json`을 재료 상자로 조립했어요.
- **한 가지 생각:** 챗봇이 말한 출처는 있는지, 맞는지, 믿을 만한지 세 단계로 확인한다.
- **상태:** 초안(평가 대기)

| # | 화면 | 원본 페이지의 근거 |
|---|---|---|
| 1 | "어디서 봤어?" / 챗봇이 말한 출처에도 이렇게 물어봐요 | 1절 친구 비유 |
| 2 | (예: 챗봇의 답) ○○ 논문에 따르면요… → 없는 논문이나 링크를 지어낼 때도 있어요 | 1절 |
| 3 | 세 단계: 1. 있나? 링크가 열리나요 / 2. 맞나? 정말 쓰여 있나요 / 3. 믿을 만한가? 누가, 언제 | 2절 |
| 4 | 그 안에서만 계속 읽기 ↔ 옆으로 읽기: 새 창에서 누가 운영하는지 먼저 검색 | 3절, 써먹기 3 |
| 5 | 오늘의 써먹기: 링크 열어 보기 / 원문에서 찾기(예: Ctrl+F) / 날짜 확인 | 오늘 바로 써먹기 1·2·5 |

## 확인할 점
- "전문 팩트체커들이 이렇게 한대요"는 3절의 스탠퍼드 연구 소개를 줄인 말이에요. 원본도 논문 본문은 직접 읽지 못했다고 밝혀 두었어요.
- 4절(근거 인용을 달게 하는 부탁문)과 심화는 뺐어요.
- 3장면은 세 단계가 이 편의 한 가지 생각이라 세 항목 이름에 모두 형광펜을 그었어요.
