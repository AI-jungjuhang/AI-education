# 쇼츠 024 · 긴 자료 읽고 정리하기

- **원본 페이지:** 6.1.2 [긴 자료 읽고 정리하기](../../../docs/part2/ch06/long-docs.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 긴 자료는 질문을 먼저 정하고, 근거 문장을 뽑게 한 뒤 정리한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 긴 자료는 질문부터 정해요 / "정리해 줘"만 하면 평범한 요약이 나와요 |
| 2 | split | 이거 정리해 줘 ↔ 가장 큰 위험 세 가지는 뭐야? |
| 3 | notes | 네 단계 정리법: 1. 질문 정하기 / 2. 자료는 위, 질문은 아래 / 3. 근거 문장 먼저 뽑기 / 4. 그 문장으로 정리하기 |
| 4 | speech | 관련 문장을 그대로 인용하고 번호를 붙여 줘 → 번호로 원문을 바로 찾을 수 있어요 |
| 5 | check | 오늘의 써먹기: 자료는 위, 질문은 아래 / 아주 긴 글은 장마다 나눠 묻기 / 계약서는 AI 말로 결정하지 않기 / 최종 판단은 직접 읽거나 전문가에게 |

## 확인할 점
- "가장 큰 위험 세 가지"는 원본 부탁문의 질문이에요.
- 여러 문서 비교(3절)와 가운데 정보 손실 연구는 뺐어요.
