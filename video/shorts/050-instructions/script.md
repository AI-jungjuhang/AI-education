# 쇼츠 050 · 좋은 지시문 쓰기

- **원본 페이지:** 15.1.1 [좋은 지시문 쓰기](../../../docs/part4/ch15/instructions.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 에이전트 지시문은 새 직원 안내서처럼 역할·목표·한계·모를 때·멈출 때를 담고, 한계엔 대안을 붙인다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 에이전트에겐 첫 출근 안내서를 / 똑똑하지만 우리 사정을 모르는 새 직원이라고 생각해요 |
| 2 | notes | 안내서에 담을 것: 역할과 목표 / 하지 말 것 / 모를 때 / 멈출 때 |
| 3 | split | 결제는 하지 마 ↔ 결제 대신 안내 데스크를 알려 줘 |
| 4 | speech | 이유도 붙이기 → 예: 정확해야 해. 헛걸음하면 안 되니까 |
| 5 | check | 오늘의 써먹기: 첫 세 줄에 역할·목표·이유 / "모를 때" 칸 꼭 쓰기 / 이상한 행동을 보면 한 줄씩 추가 |
