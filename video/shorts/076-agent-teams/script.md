# 쇼츠 076 · 에이전트 팀

- **원본 페이지:** 18.1.4 [에이전트 팀](../../../docs/part5/ch18/agent-teams.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 에이전트 팀은 서로 대화하는 동료지만 실험 기능이고 비싸니, 먼저 서브에이전트로 해 본다.

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 에이전트 팀은 함께 일하는 동료 / 서로 이야기하는 동료는 월급이 비싸요 |
| 2 | split | 부른 쪽에만 보고해요 ↔ 팀원끼리 직접 대화해요 |

| 5 | check | 오늘의 써먹기: 팀 전에 서브에이전트로 먼저 / 작은 일로 시험하고 사용량 확인 / 같은 파일은 한 팀원만 |
