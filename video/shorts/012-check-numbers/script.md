# 쇼츠 012 · 숫자와 인용 대조하기

- **원본 페이지:** 3.1.2 [숫자와 인용 대조하기](../../../docs/part1/ch03/check-numbers.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초. `episode.json`을 재료 상자로 조립했어요.
- **한 가지 생각:** 숫자와 따옴표는 그럴듯하게 틀리기 쉬우니 한 번 더 대조한다.
- **상태:** 초안(평가 대기)

| # | 화면 | 원본 페이지의 근거 |
|---|---|---|
| 1 | 숫자와 인용, 틀리기 쉬워요 / 그럴듯해 보여서 그냥 지나치기 쉬워요 | 학습 목표 1, 1절 |
| 2 | 여기서 잘 틀려요: 숫자(만↔억) / 날짜 / 이름 / 인용문 | 2절 표 1~4행 |
| 3 | (예) 5천만 명의 20%는 2천만 명 → 대충 천만 명쯤인데? 크기부터 이상해 | 3절 ② 어림 계산(원본의 예를 틀린 답 예시로 바꿈) |
| 4 | 계산 값까지 구해 줘 ↔ 식은 챗봇, 값은 계산기 | 3절 ③, 2절 표 5행 |
| 5 | 오늘의 써먹기: 근거 문장 / 따옴표는 원문에서 / 단위와 기준 연도 | 오늘 바로 써먹기 1·4·5 |

## 확인할 점
- 3장면의 "2천만 명이에요"는 원본의 어림 계산 예(답이 2천만이면 이상하다)를 챗봇의 틀린 답 예시로 만든 거예요. "예:"로 밝혔어요.
- 메모지가 4장이라 항목 이름에는 형광펜을 긋지 않았어요. 3장면은 노란 말풍선이라 분홍 형광펜.
- 인용문 확인 절차(4절)는 써먹기 2번으로 줄였고, 직접 해보기(1234×5678)와 심화는 뺐어요.
- 첫 장면은 처음에 "틀린 그림 찾기" 비유였는데, 무슨 내용인지 바로 알 수 없어서 핵심 문장으로 바꿨어요(사용자 피드백).
