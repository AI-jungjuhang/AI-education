# 쇼츠 031 · 팀에서 정하는 규칙

- **원본 페이지:** 8.1.3 [팀에서 정하는 규칙](../../../docs/part2/ch08/team-rules.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 팀은 넣어도 되는 자료, 확인할 사람, 밝히는 방법을 한 장짜리 규칙으로 정한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 팀 AI 규칙은 한 장이면 돼요 / 학급 규칙도 짧아야 잘 지켜지잖아요 |
| 2 | notes | 꼭 정할 세 가지: 넣어도 되는 자료 / 누가 확인? / 어떻게 밝히나 |
| 3 | list | 자료 등급: 공개 자료 → 대체로 괜찮아요 / 내부 자료 → 승인된 도구만 / 민감 자료 → 넣지 않기 |
| 4 | speech | 예시를 같이 보여 주기 → "이건 괜찮고 이건 안 돼요"가 규칙보다 빨리 와닿아요 |
| 5 | check | 오늘의 써먹기: 자료 등급부터 세 가지로 정하기 / 애매할 때 물어볼 사람 정하기 / 외부로 나가는 글은 사람이 확인 |

## 확인할 점
- "공개 자료 → 대체로 괜찮아요"는 원본의 "입력해도 되는 경우가 많지만 확인"을 줄인 말이에요.
