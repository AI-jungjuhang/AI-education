# 쇼츠 048 · 계획하고, 행동하고, 확인한다

- **원본 페이지:** 14.1.2 [계획하고, 행동하고, 확인한다](../../../docs/part4/ch14/loop.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 에이전트는 계획→행동→확인→다음 결정의 고리를 도니, 멈출 조건과 확인 지점을 넣는다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 에이전트는 고리를 돌며 일해요 / 쪽지 읽고, 가 보고, 확인하는 보물찾기처럼요 |
| 2 | list | 한 바퀴: 1. 계획해요 / 2. 도구로 행동해요 / 3. 결과를 봐요 / 4. 계속할지 정해요 |
| 3 | notes | 고리를 짜는 방식: 단계 잇기 / 나눠 보내기 / 동시에 돌리기 / 쓰고 평가하기 |
| 4 | speech | 5번 해도 안 되면 멈추고 알려 줘 → 멈추는 조건이 없으면 계속 돌 수 있어요 |
| 5 | check | 오늘의 써먹기: "계획 먼저 보여 줘" / 단계마다 확인받고 넘어가기 / "성공했어요"라고 해도 결과 직접 보기 |

## 확인할 점
- 다섯 가지 방식 중 지휘자-일꾼은 메모지 4장 한도 때문에 뺐어요.
