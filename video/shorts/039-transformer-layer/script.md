# 쇼츠 039 · 트랜스포머 한 층의 모양

- **원본 페이지:** 11.1.2 [트랜스포머 한 층의 모양](../../../docs/part3/ch11/transformer-layer.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 트랜스포머는 어텐션과 MLP를 번갈아 여러 번 거쳐 마지막에 다음 토큰의 점수표를 만들고, 이걸 토큰마다 반복한다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 트랜스포머는 같은 층을 여러 번 / 컨베이어 벨트 위 작업장을 차례로 지나듯이요 |
| 2 | split | 토큰끼리 정보 주고받기 ↔ 토큰마다 혼자 다듬기 |
| 3 | list | 토큰 하나가 나오기까지: 1. 토큰으로 쪼개기 / 2. 숫자 묶음 붙이기 / 3. 어텐션 ↔ MLP 여러 번 / 4. 마지막에 점수표 |
| 4 | speech | 이 전체를 돌려서 토큰 하나를 뽑아요 → 긴 답이 시간이 걸리는 이유예요 |
| 5 | check | 오늘의 써먹기: 구조가 복잡해도 답은 확인하기 / 답이 매번 다른 건 마지막 뽑기 때문 / 12장에서 다뤄요 / 어려우면 건너뛰어도 돼요 / 질문 요령엔 문맥 이해면 충분해요 |
