# 쇼츠 038 · 어텐션: 중요한 곳을 골라 본다

- **원본 페이지:** 11.1.1 [어텐션: 중요한 곳을 골라 본다](../../../docs/part3/ch11/attention-idea.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 어텐션은 단어마다 지금 어디를 볼지 정해 필요한 정보를 가져오는 장치라서, "그것" 대신 이름을 쓰면 덜 헷갈린다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 어텐션은 어디를 볼지 골라요 / "그것"을 만나면 앞으로 돌아가 찾듯이요 |
| 2 | speech | 푹신한 파란 생물이 숲을 돌아다녔다 → 내 앞에 꾸며 주는 말 있나요? → "푹신한", "파란"의 뜻을 가져와 더해요 |
| 3 | list | 세 가지 이름: 질문(query): 뭘 찾지? / 열쇠(key): 나 여기 있어 / 값(value): 내 내용을 줄게 |
| 4 | split | 그거 고쳐 줘 ↔ 둘째 문단의 첫 문장 고쳐 줘 |
| 5 | check | 오늘의 써먹기: "그것" 대신 이름 쓰기 / 중요한 조건은 질문 가까이 / 헷갈리는 자료엔 이름표 붙이기 / 예: A 문서, B 문서 |

- 예문은 원본(3Blue1Brown의 영어 예문)을 우리말로 옮긴 거예요.
