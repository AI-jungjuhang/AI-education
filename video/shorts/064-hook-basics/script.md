# 쇼츠 064 · 특정 순간에 자동으로 실행하기: 훅

- **원본 페이지:** 17.2.1 [특정 순간에 자동으로 실행하기: 훅](../../../docs/part5/ch17/hook-basics.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 훅은 약속한 순간이 오면 AI 판단 없이 내가 정한 프로그램을 실행하니, 꼭 해야 하는 일은 훅으로 만든다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 훅은 현관 센서등이에요 / 부탁하지 않아도 약속한 순간에 켜져요 |
| 2 | split | AI가 따를지 고르기도 해요 ↔ 약속한 순간에 AI 판단 없이 실행 |
| 3 | notes | 자주 쓰는 네 순간: 도구 쓰기 직전 / 도구 쓴 직후 / 내 입력을 기다릴 때 / 대화를 열 때 |
| 4 | speech | Claude가 내 입력을 기다리면 알림 띄우기 → 처음엔 이렇게 해가 없는 훅부터요 |
| 5 | check | 오늘의 써먹기: 꼭 해야 하는 일은 메모 대신 훅 / 처음엔 해가 없는 훅부터 / 단 뒤엔 /hooks로 확인 |

## 확인할 점
- 기준: Claude Code 2.1.319(원본 기준).
