# 쇼츠 044 · 검색을 붙이면 달라지는 것

- **원본 페이지:** 13.1.1 [검색을 붙이면 달라지는 것](../../../docs/part4/ch13/search-rag.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 검색을 붙이면 오픈북 시험이 되어 최신 정보와 출처가 좋아지지만, 찾은 글이 틀릴 수 있어 출처를 열어 본다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 검색을 붙이면 오픈북 시험이 돼요 / 외워서 답하던 걸 찾아보고 답해요 |
| 2 | list | 이렇게 작동해요: 1. 질문이 들어와요 / 2. 뜻이 가까운 글을 찾아요 / 3. 찾은 글을 함께 넣어요 / 4. 그 글을 보고 답해요 |
| 3 | split | 최신 정보, 출처 보여 주기 ↔ 찾은 글이 틀리면 답도 틀려요 |
| 4 | speech | 출처와 날짜를 같이 알려 줘 → 확인할 길이 생겨요 |
| 5 | check | 오늘의 써먹기: 출처는 열어서 확인 / 검색어에 개인정보 넣지 않기 / 서로 다른 출처 둘 요청하기 |

## 확인할 점
