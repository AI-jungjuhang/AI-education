# 쇼츠 051 · 도구를 잘 설계하기

- **원본 페이지:** 15.1.2 [도구를 잘 설계하기](../../../docs/part4/ch15/tool-design.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** AI에게 주는 도구와 자료는 적게, 이름은 분명하게, 설명을 붙여서 준다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | AI의 도구함엔 이름표가 필요해요 / 서랍마다 이름표가 없으면 헤매잖아요 |
| 2 | list | 도구를 만드는 다섯 원칙: 필요한 도구만 / 이름으로 분명히 구분 / 다음 판단에 쓸 결과 / 결과는 짧게 / 설명서는 정성껏 |
| 3 | speech | AI에게 주는 자료에 같은 생각을 써요 → 필요한 파일만, 이름은 분명하게 |
| 4 | split | 최종_진짜최종 .xlsx ↔ 2026_매출_월별 .xlsx |
| 5 | check | 오늘의 써먹기: AI에게 주는 자료 줄이기 / "이 열은 이런 뜻" 한 줄 붙이기 / 결과는 짧게 받기 |

## 확인할 점
- 다섯 원칙은 원본의 Anthropic 글(2025-09-11) 표를 줄인 말이에요.
- 파일 이름 예시와 "개발자가 아니어도" 적용은 원본이 직접 풀어 쓴 부분이라고 밝힌 내용이에요.
