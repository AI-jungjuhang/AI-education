# 쇼츠 097 · 왜 맥락·예시·형식이 먹힐까

- **원본 페이지:** 23.2.1 [왜 맥락·예시·형식이 먹힐까](../../../docs/part6/ch23/prompt-why.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** AI는 앞에 놓인 글로 답을 정하니 맥락·이유·예시·구조가 먹히고, 강조 표시나 다그치는 말은 이제 필요 없다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | 앞에 놓인 글이 답을 정해요 / 그래서 맥락·예시·형식이 먹혀요 |
| 2 | notes | 먹히는 이유 넷: 분명하게 / 이유와 함께 / 예시 보여 주기 / 구조 표시 |
| 3 | split | 줄임표(…)를 쓰지 마 ↔ 음성으로 읽히니 줄임표는 빼 줘 |
| 4 | list | 이제는 필요 없는 요령: "중요!!" 잔뜩 붙이기 / "깊이 생각해" 주문 / "포기하지 마" 다그치기 |
| 5 | check | 오늘의 써먹기: 부탁에 이유 한 문장 / 형식이 중요하면 예시 2~3개 / 강조 대신 한 줄을 분명히 |

## 확인할 점
- 줄임표 예시는 원본이 Anthropic 지침 예시를 요약한 거예요.
