# 쇼츠 079 · CLI로 자동화 파이프라인 만들기

- **원본 페이지:** 18.2.3 [CLI로 자동화 파이프라인 만들기](../../../docs/part5/ch18/cli-automation.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** claude -p를 반복문에 넣으면 여러 파일을 점검하는 파이프라인이 되고, 좁게 허락·상한·낯선 폴더 안 읽기로 안전하게 돌린다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | claude -p를 반복문에 넣으면 / 파일 100개도 한꺼번에 점검해요 |
| 2 | notes | 안전 스위치: 건너뛰기 / 읽기만 허락 / 움직임 상한 / 문제면 멈추기 |
| 3 | list | 자동화 안전 세 가지: 좁게 허락하기 / 횟수·비용에 상한 두기 / 낯선 폴더는 읽지 않기 |
| 4 | split | > 파일.txt ↔ --output-format json |
| 5 | check | 오늘의 써먹기: 파일 열 개 넘게 점검하면 반복문으로 / 결과 파일 이름에 원본 경로 넣기 / 돌리기 전 비밀 파일 없는지 확인 |

## 확인할 점
- 메모지의 set -e는 원본 set -euo pipefail을 줄인 표기예요.
- --json-schema, --max-budget-usd는 뺐어요.
