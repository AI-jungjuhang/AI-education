# 쇼츠 014 · 개인정보와 민감한 자료

- **원본 페이지:** 3.2.1 [개인정보와 민감한 자료](../../../docs/part1/ch03/privacy.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** 챗봇에 쓴 글은 서비스 회사로 가니, 개인정보와 기밀은 가리고 쓴다.
- **상태:** 초안(평가 대기)

| # | 화면 | 원본 페이지의 근거 |
|---|---|---|
| 1 | 개인정보는 가리고 물어요 / 챗봇에 쓴 글은 서비스 회사로 가요 | 학습 목표 1·2, 1절 |
| 2 | 김민수 씨가 강남구 ○○동에서… ↔ A씨가 서울의 한 지역에서… | 3절 요령 1의 예 |
| 3 | 이런 건 가려요: 나를 알아볼 정보 / 민감한 정보 / 남의 정보 / 로그인 정보 | 2절 표(일터 정보 행은 뺌) |
| 4 | A씨에게 보낼 사과 문구 써 줘 → 받은 뒤 A씨만 실제 이름으로 | 써먹기 2 |
| 5 | 오늘의 써먹기: 보내기 전에 멈추기 / 회사 규정 먼저 / 설정에서 대화 사용 여부 보기 | 써먹기 1·3, 4절 |

## 확인할 점
- "사과 문구"는 지어낸 예시예요(말풍선 이름표에 "가린 글로 묻고"라고만 적음).
- 원본의 "법률 자문이 아니에요" 안내는 각주로 넣었다가 감자·메모지와 겹쳐서 뺐어요.
- "내 컴퓨터에서만 돌리는 모델은 예외", 엽서 비유, 심화(개인정보위 안내서)는 뺐어요.
