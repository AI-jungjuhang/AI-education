# 쇼츠 101 · 확인할 수 있는 검사를 쥐여 주기

- **원본 페이지:** 23.4.1 [확인할 수 있는 검사를 쥐여 주기](../../../docs/part6/ch23/verify-loop.md)
- **형식:** 세로 9:16, 30fps, 음성 없음, 약 28초.
- **한 가지 생각:** AI는 끝난 것처럼 보이면 멈추니, 합격/불합격으로 답하는 검사를 주고 항상 명령과 출력을 증거로 받는다.
- **상태:** 초안(평가 대기)

| # | 모양 | 화면 |
|---|---|---|
| 1 | bigword | AI에게도 정답지를 쥐여 줘요 / 끝난 것처럼 보이면 멈추거든요 |
| 2 | list | 검사의 네 단계: ① 부탁에 쓰기 / ② /goal로 목표 두기 / ③ Stop 훅으로 강제 / ④ 다른 눈이 검토 |
| 3 | split | "다 통과했어요" ↔ 명령과 출력 전체 보여 줘 |
| 4 | speech | 정확성만 봐 줘. 스타일은 빼고 → 찾으라고 하면 항상 뭔가 찾아내거든요 |
| 5 | check | 오늘의 써먹기: 끝의 모양을 합격/불합격으로 / 예: 링크 검사에서 경고 0개 / 검토 범위는 좁게 / 모든 보고에 명령과 출력 요구 |

## 확인할 점
- /goal, /code-review 같은 명령 이름은 원본 기준이에요.
