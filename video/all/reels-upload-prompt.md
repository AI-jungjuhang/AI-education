# 내 컴퓨터의 Claude에게 붙여 넣을 부탁

아래 글을 Claude 데스크톱 앱(브라우저 조작 또는 컴퓨터 사용이 켜진 대화)에 그대로 붙여 넣으세요. zip을 풀거나 파일을 따로 보낼 필요가 없어요.

---

인스타그램 릴스 102편을 Meta Business Suite(business.facebook.com)에서 예약 게시해 줘.

- 영상과 예약표는 GitHub 저장소 AI-jungjuhang/AI-education 의 브랜치 claude/korean-ai-textbook-site-kbmkii 에 있어. 먼저 이 브랜치를 내 컴퓨터로 내려받아 줘(git clone --branch claude/korean-ai-textbook-site-kbmkii --depth 1).
- 예약표: video/all/reels-schedule.csv (열: 편, 예약 날짜, 예약 시각, 영상 파일, 번호, 이름, 설명글)
- 영상 파일: video/shorts/<편 폴더>/out/<영상 파일>. 예: 001-next-word.mp4 는 video/shorts/001-next-word/out/001-next-word.mp4. video/all 의 mp4는 바로가기라서 Windows에서는 열리지 않을 수 있으니 쓰지 마.
- 순서: 표의 위에서부터 한 줄씩. 각 줄마다 "릴스 만들기" → 영상 파일 올리기 → 설명글 칸에 "설명글"을 그대로 붙여 넣기 → "예약"에서 날짜와 시각 넣기 → 예약 저장.
- 처음 1편은 예약 저장 직전에 멈추고 화면을 보여 줘. 내가 확인하면 나머지를 진행해.
- 10편마다 진행 상황(몇 번까지 했는지)을 알려 줘.
- 로그인 창, 결제, 광고 홍보(부스트), 계정 설정 변경이 나오면 누르지 말고 멈춰서 나에게 물어봐.
- 업로드가 실패하거나 화면이 예상과 다르면 그 편 번호를 적어 두고 멈춰.
- 이미 예약된 편은 다시 올리지 마. 시작 전에 Business Suite의 "예약됨" 목록을 먼저 확인해.
